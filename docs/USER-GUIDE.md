# 使用留白

留白用于在本机收藏、学习和复用提示词。浏览、搜索、保存、复制和备份不需要模型；需要改编或设计拆解时，使用你自己的 Codex、Claude Code 或其他模型账号。团队协作、云同步为后续范围。

本文对应 0.8.0 Windows 安装版与源码版。使用旧版时，先备份并关闭留白，再安装新版。个人素材继续保留。

顶栏 **•••** 菜单提供 **中文**、**English** 和 **自动**，也可从同一菜单打开反馈。手动语言选择保存在本机。英文界面优先显示可用的英文内容，另一种语言可按需展开。

## 页面里的使用说明

点击右上角 **使用说明**，或左上角的 **?**。说明与素材库保持灰白、磨砂玻璃和圆角按键风格，点击章节查看：

1. **开始使用**：搜索、阅读、复制。
2. **收藏与版本**：保存原文、补来源、改编留版本。
3. **连接自己的 AI**：复制当前库的 Codex / Claude Code 命令或通用 stdio 配置。
4. **读取、保存与拆解**：复制可直接发给自己 AI 的任务。
5. **数据与备份**：当前资料位置、备份和恢复步骤。

按 `Esc` 或关闭按钮返回素材；键盘方向键可切换章节。连接命令按当前机器和资料目录生成，不要复制别人的路径。

## 第一次使用

Windows 安装版从 [Releases](https://github.com/Shanvision-star/liubai-prompt-library/releases/latest) 下载安装程序，无需系统 Python。程序在 `%LOCALAPPDATA%\Programs\Liubai`，资料在 `%LOCALAPPDATA%\Liubai\library`。首次准备素材显示进度。关闭浏览器窗口后服务仍可能运行，开始菜单“关闭留白”可停止服务。

源码需要 Python 3.11+，在项目根目录运行 `python -X utf8 start.py`（其他系统可用 `python3`）。首次导入该源码附带的公开集；当前公开集为 252 条素材、6 份参考。已有库不会被覆盖，也不会自动补入新版公开集。源码默认资料位于项目根目录；独立目录用：

```sh
python -X utf8 start.py --data-root "/absolute/path/to/my-library" --port 8767
```

源码版新指定目录默认建立空库，需要公开集时加 `--with-collection`。Windows 安装版若要保留旧库并单独打开本版公开集，可在 PowerShell 运行以下命令，使用一个全新目录：

```powershell
& "$env:LOCALAPPDATA\Programs\Liubai\Liubai.exe" --data-root "$env:LOCALAPPDATA\Liubai\public-080"
```

也可直接在 GitHub 阅读 [192 条双语动效素材](MOTION-PROMPT.md)。启动后核对说明页中的“资料位置”。界面采用 macOS 风格，不代表原生 macOS 安装包已经完成验收。

## 查找与使用

按 `Ctrl+K` / `⌘K` 搜索用途、关键词或编号，也可选分类。窄屏用“浏览”菜单切换全部、收藏、最近与分类。

打开任意分类素材，默认查看“原文与译文”。中文界面先显示原文，再显示中文译文。英文界面优先显示英文，另一种语言可展开。主按钮“复制原提示词”始终只复制原文。需要改编时，在复用版点击“复制复用改写”，填写变量后粘贴到自己的 AI 工具。分析、Loop 和来源可分别阅读。**待实测**表示尚无真实任务效果证据。

教学按原文、版本正文的哈希匹配，包括结构解释、具体取舍、单变量反例和迁移练习。没有实际分析的新素材显示缺失状态，不生成占位讲解。

### 所有分类的原文与中文对照

有经核对来源正文的条目，默认打开 **原文与译文**：上方为原语言提示词，下方为对应中文，便于连续阅读。**复制原提示词**只复制原文，不附译文、标题或分析；切到分析或复用改写后，主复制按钮仍复制来源原文，旁边有明确标注的当前内容复制入口。

普通素材的译文单独保存，以实际原文文件 SHA-256 绑定，并校验译文文件自身；原文变化会隐藏旧译文。原文已是中文时直接说明，无需重复生成一份相同内容；没有译文时如实标为待补充，不把复用改写放到翻译区。新建素材不会自动调用模型翻译。

点击 **打开原网页** 或 **作者原帖** 在新页访问来源。原文中的 http/https 链接也可点击；链接显示与复制的提示词文本保持一致。**拆解分析**区分原文要求、整理者推理、缺口与验证建议；文本解读不等于作者解释或生成效果验收。

Prompt Motion 的“仅摘录”表示全文尚未收录，此时全文复制与原文导出不可用；摘录复制明确带有“非全文”说明。**复用改写**保留原来的整理稿和版本选择。来源原文、译文及分析分别校验：原文缺失或损坏时禁用全文复制；仅译文或分析损坏时隐藏相应内容，有效原文仍可阅读和复制。

该阅读区沿用 macOS 风格的侧栏、磨砂玻璃与圆角；中英文正文使用稳定底色和清楚层级。窄屏进入详情时收起搜索与筛选区，点击“返回素材列表”恢复。它仍是运行在浏览器中的本地应用。

## 保存原文、来源与版本

点击“新建素材”，粘贴原文，填标题、分类，可补标签、来源链接和说明；改编版可选。也可导入 UTF-8 `.md` / `.txt`，单个正文最多 256 KiB。导入只预填，点击保存才入库；原文未编辑时保留原始换行。

相同原文重复保存会打开已有条目，不用新标题或新改编覆盖它。新写法用详情中的 **新版本**，填写正文和改动理由。原文与历史保留；并发变化时先读取最新版本，草稿仍保留。新版本不沿用旧拆解。

在 **来源 → 补充来源** 追加作者、链接或背景，保留时间，不覆盖固定来源或许可。关闭编辑窗口保留本页草稿；刷新或关闭页面仍可能丢失未保存内容。

## 让 Codex / Claude Code 读取与保存

1. 先安装并登录你选用的客户端。
2. 打开 **使用说明 → 连接自己的 AI**，选择客户端，复制命令并在所示终端执行。已有同名 `liubai` 配置时按客户端说明更新，避免重复添加。
3. 重载或新开会话，检查 MCP；复制“验证连接”任务，让它实际查询分类、搜索并读取素材。
4. 到 **读取、保存与拆解** 复制任务，填入目标或素材。

例如：

> 请从留白搜索适合【我的任务】的提示词，读取最相关的 3 条，说明用途、输入、来源和限制，再选择一条改编。先不要写入。

> 将下面提示词保存到留白，保留原文、来源和可选改编。保存后回读核对，效果保持 untested。

连接使用本机 **stdio MCP**，网页地址 `http://127.0.0.1:8767` 不是 MCP 地址。MCP 与网页必须指向同一资料目录。安装版使用 `Liubai-MCP.exe`，无需 Python；源码模式使用当前 Python。其他支持 stdio 的客户端可参考通用 JSON，入口以客户端文档为准。普通模型网页没有 MCP 时，使用手动复制。

留白不支付模型费用，不自动收集聊天，也不修改客户端设置。配置成功不代表连接成功；客户端可能需重新加载才能发现新工具。

## 为新收藏生成设计拆解

选择素材及版本，点击 **设计逻辑 → 让我的 AI 生成拆解**，复制任务到已连接的客户端。客户端读取选中版本，用你的模型分析目标、输入、结构、关键句、约束、迁移例、反例与停止条件，再通过 `liubai_save_analysis` 回写。

分析须携带刚读取的版本号与原文/改编 SHA-256，失配拒绝保存。分析修订单独留存，失败不影响原文；完成后回读同一版本核对。只主动提供选中的素材与必要上下文，结果保存本机；外部模型留存以供应商规则为准。

## 备份、恢复与升级

在 **使用说明 → 数据与备份** 点击“导出备份”。ZIP 含条目、版本、来源补充、分析修订、分类、参考、收藏及可选的个人教学资源，附 SHA-256 清单。不含程序、令牌、客户端配置或机器调度记录。

1. 将 ZIP 解压到新的空文件夹，保留原库。
2. 安装版在 PowerShell 使用实际路径启动：`& "$env:LOCALAPPDATA\Programs\Liubai\Liubai.exe" --data-root "D:\Restored Library"`。源码版：`python -X utf8 start.py --data-root "D:\Restored Library"`。
3. 核对条目、原文、历史版本、分析、参考和收藏。
4. 换机或改变目录后重新复制 MCP 配置。

当前没有界面一键恢复。备份不会自动合并；不要用空索引修复缺损目录，也不要执行 `git clean -fdx` 删除私人数据。网页备份上限 256 MiB / 10000 文件；超限或含目录联接时，先停止服务和其他写入工具，再复制资料目录。

升级前先备份并停止旧服务，使用新程序指向原资料目录。安装版升级、卸载保留个人数据。来源定时任务按 [参考更新说明](REFERENCE-UPDATES.md) 单独配置，默认未注册。
