## 后续如何调用

先从史料核对事件年份、人物、古地名和路线，再打开对应年份的地图进行参考。网站支持年份与地点深链接，例如三家分晋时间入口：https://deanchen.me/jiangshan-map/?year=-403 。可用站内人物检索和时间轴查看路线及版图变化。

制作动画时，逐镜记录年份、地点、所用图层和来源链接。先确认权利，再决定网页截图、录屏或导出允许使用的矢量数据。地图是历史疆域示意，不应当作精确测绘边界；地名、年代及叙事仍须结合《资治通鉴》和相关史料复核。

## 许可边界（以制作时的上游条款为准）

官方 README 将代码及作者制作的多类数据列为 GPL-3.0，但不覆盖所有图层：CHGIS 衍生的郡/州/府边界仅限学术非商业用途且禁止再分发；包含该图层的截图也受其条款约束。现代省界另受 DataV GeoAtlas 条款约束。不能因网站可浏览就认为所有画面可商用。

公开发布或商用动画前，逐层核查授权和署名要求；未确认的图层不导出、不搬运。按适用要求注明江山时序、官方仓库及上游数据来源。

许可核查依据：https://github.com/DeanChensj/jiangshan-map#data-sources--license
