# Glasswork / 999 UI 学习 · 04：一排卡片，为什么要有两种看法？

日期：2026-11-21  
来源编号：枯白啃设计 #021（04 是本库学习编号，不是作者编号）  
标签：卡片浏览、空间布局、选中状态、减弱动态效果

## 视觉目标

平时扫一组内容，不必让每张卡都争做视觉中心；挑一篇细读时，反倒需要明确焦点。这期的环形卡片把这两个任务分开：从环内看，左右内容围过来，适合扫读；从环外看，正中卡片清楚、远处卡片减弱，适合选定一项。不是为了给轮播加一圈动画，而是用同一组内容服务两个不同的动作。

## 交互与实现

- 数据只保留一份。每张卡有稳定 ID，当前选中项不随视图切换而丢失；两种视图使用同一个标题和原文入口。
- 两种视图共用一条弧线。实现时可以用一个带符号的曲率变量，从环内过渡到环外；曲率接近零时，直接使用直排位置，避免公式除以零。作者还有景深、翻面和流体渐变，它们都不是让这一交互成立的必要条件。
- 若用于论文封面展示，先试静态封面和低幅度变换，不叠流体背景。减弱动效时直接换视图，保留选中样式和可操作的按钮。移到手机窄屏后仍可以用常规横排或列表完成同一操作。
- 适用于可选的论文发现页、作品集或封面挑选，不适用于 EMC 主表、证据页或需要稳定比较数字的密集界面。作者演示的时长是其视觉选择，不是项目默认值。

## 10 分钟练习

放入 5 张虚构论文封面，用“概览 / 聚焦”两个按钮。先选第 3 张，往返切换两次，再点标题打开同一原文；用键盘重做一次。最后开启系统减弱动效，确认不依赖翻面也能找到选中项。通过标准：选中 ID、标题和原文入口不变，切换不会让键盘焦点消失。
