# 参考库与增量跟踪

参考库提供GitHub仓库搜索、文件链接导入、关注、收藏、来源快照、拆解卡和采用预览。关键词搜索结果是候选，需追溯实际原文件并检查许可、适用条件和使用证据。

来源原文在详情和整卡导出的第一个正文区域；节选标明范围。未知许可只留链接和必要元数据，不能直接采用。分析与原文分开，结构、关键句、模板、示例、反例和Loop需实际阅读后填写；未运行示例标为`illustrative`。

上游变化先进入待分析，旧快照和个人版本保留。选择采用前预览分类、来源、模板和限制；采用到个人素材后保留快照/分析版本关系。下载或检查来源不等于实测提示词效果。

## 手动与定时

点击“立即检查”会实际读取已关注来源。独立安装默认没有已注册的调度器，不会因为显示界面开关就开始后台工作。

可以由现有调度工具调用：

```sh
python -X utf8 desktop/reference_runner.py status --root ./private-library
python -X utf8 desktop/reference_runner.py run --root ./private-library --force --trigger manual
python -X utf8 desktop/reference_runner.py pending --root ./private-library
```

将 `./private-library` 替换为启动界面或 MCP 时使用的同一数据目录；默认在仓库根保存的用户使用 `--root .`。定时任务建议使用绝对路径，避免工作目录变化后维护了另一份空库。

如果使用Codex自动化：先通过Codex创建一个实际运行的本机任务，再把工具返回的任务编号交给`reference_runner.py register --root <数据目录绝对路径> --automation-id <实际编号>`登记。登记命令本身不创建任务。定时任务调用`run --root <同一数据目录绝对路径> --trigger codex_heartbeat`，只处理到期周期。默认上海时间每日09:00，周日额外发现；改为每周时，发现跟随选定星期运行。

网页暂停/频率设置控制采集门禁，外部调度器仍可能唤醒后检查门禁。若要停用整个唤醒，在对应调度器操作。共用运行锁与周期记录，不重入、不重复建档，恢复后只处理最近周期并最多补跑一次。

## 分析与资源范围

检查入口限20仓库、60文件、256KiB/文件、15分钟，最多重试2次。实际分析每次不超过6份，发现与许可检查也计入预算。GitHub匿名请求可能限流，可在本机进程环境设置`GH_TOKEN`或`GITHUB_TOKEN`；不要将令牌提交到Git。

检查脚本不包含模型调用。需要Codex或其他已授权分析者实际读原文，经`ReferenceStore.set_analysis`保存结构化拆解；没有分析能力就保持待分析。无需付费API也能使用本地保存、分类和浏览。

关机、休眠、断网、应用未运行或授权额度不足时不能保证执行。界面的最近尝试、最近成功、错误和待分析状态分别记录；失败不更新成功时间，不覆盖旧原文。首次真实触发必须另行验收，模拟时钟和手动命令不能冒充调度运行。
