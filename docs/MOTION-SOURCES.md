# Prompt Motion 来源层

本说明对应 0.7.1 的 Prompt Motion 网站来源层。GitHub 上的 MIT 项目 [Motion Prompt](MOTION-PROMPT.md) 是独立来源，见其双语目录与逐条许可。

## 这次修正什么

既有公开整理稿包含原创复用方案与来源链接，不能把它直接标成外部作者提示词。现在来源层单独保存原文、中文与分析，不覆盖原 `original.md`、改编版本、历史分析或参考快照。

`record.motion_source` 记录完整性、依据、来源作者、原帖、各文件路径与 SHA-256。0.7.1 起原文、译文和分析分别校验；完整原文校验通过就允许原文复制。译文须由 `translation_source_sha256` 明确绑定当前原文，错配只隐藏译文；分析损坏也不影响有效原文。文件必须位于该条目目录内。

## 阅读与复制

- 默认“原文与译文”：原文在上，中文在下；使用系统字体、浅色稳定阅读面与磨砂导航层。
- 主按钮“复制原提示词”始终复制原文正文，不附标题、中文、分析或整理说明。
- 原网页、原帖及正文 http/https 链接可点击。链接以文本节点与安全 URL 构造，不把提示词当 HTML 执行。
- 缺全文时只显示带标注的摘录及释义；主复制和原文导出禁用。次级摘录复制附带“非全文”前缀。
- 收藏、修改分类、新版本、版本选择、Loop 和复用稿导出继续存在。
- `translation` 旧标签链接转到同一对照页；分析与复用稿另有明确的当前内容复制入口。

## 本机 2026-11-01 核对范围

本轮目标为已有 188 条 Prompt Motion 来源：67 条完整来源原文与中文、120 条摘录、1 个来源索引。**188 条没有全部补齐全文。**其他分类未纳入该次迁移。

67 条完整内容中，65 条来自既有私人来源文件，短提示词与此前保存的来源正文 SHA-256 一致；1 条来自用户本次提供的完整网页截图，1 条为已核对的短西语原文。来源标识与证据分别记录，未把旧摘录自动当成完整正文。

对这 67 条逐条读取全文后，追加 AI 撰写的文本解读：原文明示条件、设计逻辑推导、输入缺口、验证方法。尚未独立人工验收，也未生成或观看对应成片。其余摘录条目仅有历史结构记录与初步建议，不冒充完整原文分析。

长提示词缺失项保留来源网页入口。后续需要用户提供的完整原稿或可复用的授权来源，再追加译文及对应分析；不拿整理稿、推测或续写补成所谓原文。私人全文与译文保存在个人资料目录，没有写入公开素材包。

## 离线修复工具

`tools/repair_motion_sources.py` 使用现存私人来源与显式提供的原稿，不联网抓取全文。参数以 `--help` 为准。默认只产出审阅报告；显式 `--apply` 才写入。

写入使用资料库共用锁与事务；提前读取的记录发生并发变化时中止，不覆盖新版本或新分类。仅合并 `motion_source` 字段，追加独立文件，并先备份原始记录；已存在来源文件时拒绝覆盖。来源文本是数据，工具不执行其命令。

实际验证记录见 [VALIDATION.md](VALIDATION.md)。
