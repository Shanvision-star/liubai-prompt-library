# 留白国际化 PRD 与约束

版本：0.1｜日期：2026-11-05｜状态：实施草案｜负责人：项目维护者

## 目标与现状
让中文和英文用户完成安装、搜索、阅读、保存、复制和备份。当前主线 0.7.1 的本地应用界面主要为中文；已有译文为独立的原文哈希绑定数据，尚非完整英文界面。用户反馈项目有 20 个 Star，尚未在本任务独立核实。

## 已确认需求及验收
| ID | 优先级 | 需求与验收 |
|---|---|---|
| FR-01 | Must | 首次自动选择依次采用浏览器偏好、可获取的系统语言、英文默认；浏览器支持中文或英文即停止。默认不使用 IP。 |
| FR-02 | Must | 可见的中文、English、自动选项；手动选择持久化并优先于自动选择，自动选项清除覆盖。不可用存储时仍可切换。 |
| FR-03 | Must | 英文界面默认优先显示英文，中文可展开且偏好保存在本机；仅中文时展示中文并标明英文未提供。标明原文与译文，原文复制和译文复制分开。 |
| FR-04 | Must | 界面导航、所有交互、表单、无障碍名称、错误、空状态、说明、备份恢复及公开安装指引覆盖中英文；用户内容不被翻译或覆盖。 |
| FR-05 | Must | 公开素材及分类、标题和说明提供英文；译文独立存储并绑定原文版本和哈希。无译文或源变更时明确提示，不伪造或复制不匹配的译文。私人素材不批量翻译。 |

| FR-08 | Must | 已有个人素材、版本、参考、收藏及备份恢复兼容，不覆盖或迁移原文；用户可随时导出备份。 |

## 约束与边界
- 本地服务继续只监听回环地址；语言检测不使用 IP，不放宽 CSP，不添加远程代理。
- 异步系统语言结果不得覆盖用户手动选择；禁止持续切换语言。
- 无语言偏好、存储被拒、离线、超时、异常地区值、浏览器多语言列表、简繁中文、长英文和窄屏均须验证。
- 公开内容翻译须逐条保留原文、来源和许可证边界，标注翻译状态；不得把翻译质量或人工审校写成已完成事实。
- 无云同步、多用户账户、更多语言的翻译或私人素材批量翻译。架构可扩展更多语言，但不能宣传首版已支持。
- 星标、全球用户增长与效果属于待测结果，不设未经验证的增长 KPI。

## 验收和发布门槛
自动测试覆盖语言决策、存储、异步竞态、离线回退、翻译哈希与复制边界；真实浏览器检查双语完整流程、键盘、窄屏及内容；检查公开集翻译覆盖与缺失状态；安装和备份恢复在干净环境验证；README、指南与验证记录同步。应检查不发生外部 IP 查询，并验证浏览器和系统语言回退。未完成这些项目不得宣称发布或所有素材翻译完成。

## 设计待落实的工程选择
确认受支持系统的语言获取方式和沙箱可用性；核算公开集翻译工作量与来源限制；确定英文翻译审校方式。以上均为实施任务而非已完成事实。

## 反馈窗口补充（2026-11-05）
- Original：原 PRD 未定义产品反馈入口。
- Revised：FR-09：提供可通过键盘打开和关闭的反馈窗口，用户可选择发往 rome@chatpaperhub.com 的邮件或公开 GitHub Issues；明确邮件依赖用户的邮件应用、Issue 可能需要登录且公开可见。应用不自动收集或发送素材、日志和个人信息。
- Reason / Impact：让中英文用户反馈问题，同时避免将公开留言误认为私密反馈；验收需要验证窗口、两个链接、键盘和移动端布局。

## 用户变更：简洁入口与语言检测（2026-11-05）
- Original：浏览器语言不支持时查询 IP，界面展示 IP 提示；语言和反馈各占顶栏空间。
- Revised：默认不实现 IP 查询、不展示判断方法；按浏览器、系统、英文回退。语言与反馈收纳为小型折叠菜单；切换具有克制水波动效，并尊重系统减少动态效果设置。保持 macOS 灰白、透明磨砂与现有布局。
- Reason / Impact：减少用户界面负担和网络隐私依赖；需要验证无外部 IP 请求、折叠菜单的键盘与窄屏操作、动效和减少动态效果。
