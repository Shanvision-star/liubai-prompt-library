从这里开始

把好提示词，变成自己的方法。

留白帮助你收藏、理解和复用提示词。先找到适合任务的写法，再读懂设计逻辑，最后带到自己的 AI 工具里使用。

  1. 找到合适的素材

    在“我的素材”按用途浏览，或搜索标题、标签、正文关键词。按 Ctrl + K 聚焦搜索；macOS 使用 ⌘ + K。

  2. 对照原文与中文

    所有分类默认“原文与译文”，原文在上、中文在下。译文对应当前原文；缺失或原文变化时会说明，原本中文则注明无需另译。再阅读拆解分析、Loop 和来源。

  3. 复制正确的内容

    “复制原提示词”始终只复制原文。要使用改编，切到复用版并点击“复制复用改写”，再把 {{变量}} 换成你的任务。需要保存改写时，点击“新版本”，保留原文和已有版本。

基础功能不需要模型账户

保存、搜索、收藏、复制和备份在本机完成。AI 拆解和改写由你连接的客户端与模型执行，使用该账户的权限和额度；留白不提供或代付 Token。

留下原文，也留下你的改写

收藏与版本

  1. 新建或导入

    点击“新建素材”，粘贴原文，填写标题、分类、标签和来源。也可导入 UTF-8 的 .md / .txt，单份最多 256 KiB，确认后才保存。

  2. 保留原文，另存新版本

    优化版可选。以后打开素材，点击“新版本”填写改写和理由；原文不变。在版本选择器中可以回看。相同原文再次用“新建”保存会去重，不会自动追加改编版本。

  3. 补充来源和实际背景

    在“来源”页点击“补充来源”，记录链接和说明。补充记录与已有固定来源分开，保留原作者和版本依据。

“待实测”不等于不好用

它表示还没有实际效果证据。更整齐的文字、AI 的解释和一个成功样例，都不能保证每个任务得到相同效果。新版本的拆解也需要重新绑定，不能直接沿用旧结论。

如何恢复备份
  1. 先保留现有资料，把 ZIP 解压到新的空文件夹。
  2. Windows 安装版：在安装目录运行 Liubai.exe --data-root "恢复目录的绝对路径"，不需要 Python。
  3. 源码版：运行 python -X utf8 start.py --data-root "恢复目录的绝对路径"。
  4. 检查条目、原文、版本和收藏；换机后重新生成 MCP 配置。

当前没有图形化恢复向导，也不会把备份自动合并进已有库。

为什么我和别人的素材数量不同

个人库可以继续新增；公开安装包只包含当次发布的素材。升级程序不会自动覆盖个人资料，也不会自动同步后来新增的素材。当前不提供团队协作或云同步。

关闭浏览器不一定停止本机服务。Windows 安装版可从开始菜单选择“关闭留白”；源码版按原启动方式停止。
