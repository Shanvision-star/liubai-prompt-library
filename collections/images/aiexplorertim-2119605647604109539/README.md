## 导入留白

- 单条文件只包含提示词正文，可在留白“新建素材”导入对应 `.md`，按目录填写标题，分类选择或新建 `images`，并补充上述来源链接。
- `prompts.json` 是 10 个保存请求正文组成的数组，字段遵循 [留白接入文档](../../../docs/INTEGRATIONS.md)。已连接留白的客户端可逐项调用 `liubai_save_prompt`，或由获准的本机客户端逐项提交到 `POST /api/prompts`，保存后逐条回读核对。它不是 ZIP 备份，也不是网页的批量 JSON 导入格式。
- 本目录是 GitHub 中可导入的素材副本，不会自动写入已有电脑资料库，不更改已发布安装包或内置素材集。
