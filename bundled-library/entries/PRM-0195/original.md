# [Prompt Motion] 二十秒自由选题视频

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：任意主题的大胆创意视频。
- **分镜与状态**：建议：先确定一个可清晰展开的单一主题。
- **节奏与时间轴**：原：20秒，未给镜头长度。
- **形变／遮罩／运动**：建议：用尺度变化连接起点、过程与终点。
- **配色与排版**：原：未指定配色排版，只有大胆基调。
- **工具与素材**：原：工具素材没有要求。
- **替换应用**：建议：替换为明确主题再补视觉证据。
- **验证点**：建议：检查短时长内叙事能否独立理解。
- **缺口**：缺口：光子、太阳与科学解释均非原文参数。

## 原创复用提示词

选择一个清晰现象，规划起始、变化与结果，克制使用尺度变化，使观众能跟上概念。
