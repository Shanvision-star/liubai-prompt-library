# [Prompt Motion] 45秒无对白声音叙事短片

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：无对白，但声音参与讲故事。
- **分镜与状态**：建议：环境声埋伏笔，动作声揭示变化。
- **节奏与时间轴**：原：45秒；声音节拍未指定。
- **形变／遮罩／运动**：建议：画外声引导镜头与角色反应。
- **配色与排版**：原：没有配色或排版规定。
- **工具与素材**：原：未指定软件、角色或音效素材。
- **替换应用**：建议：换故事时重做声音线索表。
- **验证点**：建议：分别只看画面、只听声音验收。
- **缺口**：原：故事和音轨缺失；未测试。

## 原创复用提示词

编写无对白场景，以可听线索、可见反应和视听共同揭示的结局完成叙事。
