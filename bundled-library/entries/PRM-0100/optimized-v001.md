# [Prompt Motion] 常见SaaS产品发布片构思

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：专业SaaS产品发布片。
- **分镜与状态**：建议：产品识别、关键功能、用户收益。
- **节奏与时间轴**：原：无明确时长，要求专业剪辑。
- **形变／遮罩／运动**：建议：真实截图与文字重点交替推进。
- **配色与排版**：原：未给色彩字体；建议匹配选定品牌。
- **工具与素材**：原：要求网络素材；建议仅用已获许可资产。
- **替换应用**：建议：改用自有SaaS，提供明确素材包。
- **验证点**：建议：检查素材权利、品牌一致和功能真实性。
- **缺口**：缺口：产品、素材链接、画幅与音轨未给。

## 原创复用提示词

为给定SaaS使用获准品牌素材制作发布概念片，让每段功能画面对应具体用户收益。
