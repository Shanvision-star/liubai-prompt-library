# [Prompt Motion] 15秒自由发挥动效作品集

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：像求职作品集一样展示设计能力。
- **分镜与状态**：建议：建立统一母题后展示不同变化。
- **节奏与时间轴**：原：15秒，未给内部镜头时长。
- **形变／遮罩／运动**：建议：形变和位置变化保持连贯节奏。
- **配色与排版**：原：未规定瑞士风格、字体或配色。
- **工具与素材**：原：没有工具与素材要求。
- **替换应用**：建议：依展示技能调整变化种类。
- **验证点**：建议：检查短片是否表达明确能力。
- **缺口**：原：题材与风格缺失；未测试。

## 原创复用提示词

用可识别视觉母题、多样变化和清楚标明创作者的尾帧制作连贯动效作品集。
