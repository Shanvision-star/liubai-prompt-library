# [Prompt Motion] 十五秒自由创作动态作品集

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：展示优秀动态设计师能力。
- **分镜与状态**：建议：以一个视觉母题串联三段递进变化。
- **节奏与时间轴**：原：15秒，要求每秒都有价值。
- **形变／遮罩／运动**：原：强调有力量的动态表现；未限定技法。
- **配色与排版**：原：大胆艺术指导与引人注目的构图。
- **工具与素材**：原：工具或技术自由选择。
- **替换应用**：建议：换主题时先确定构图主次与节奏重点。
- **验证点**：建议：检查视觉层级，剔除不服务表达的特效。
- **缺口**：原：没有具体关键帧、素材或输出规格。

## 原创复用提示词

制作一段简短动效研究，明确视觉层级、大胆中心母题，以及有目的的节奏与构图变化。
