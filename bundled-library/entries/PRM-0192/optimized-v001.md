# [Prompt Motion] 可见碰撞驱动的45秒音乐机器

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：让音乐与机械碰撞形成可见因果。
- **分镜与状态**：建议：展示碰撞部件及其发声关系。
- **节奏与时间轴**：原：45秒；每个音符须有碰撞来源。
- **形变／遮罩／运动**：原：可见碰撞；建议预留接触与回弹辨识。
- **配色与排版**：原：未指定机械材质、配色或排版。
- **工具与素材**：原：原创音乐，未规定制作软件。
- **替换应用**：建议：换音色时保持部件识别一致。
- **验证点**：建议：逐音符核对接触帧与发声时点。
- **缺口**：原：曲谱、碰撞模型与镜头未给；未测试。

## 原创复用提示词

设计可见发声机构，让每个音乐事件都有可识别接触瞬间，成片前验证同步与因果清晰度。
