# [Prompt Motion] 家的感觉：剪纸影戏竖屏动画

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：主题是一个地方为何像家。
- **分镜与状态**：建议：陌生空间、熟悉物件、归属感。
- **节奏与时间轴**：原：30–60秒，竖屏9:16。
- **形变／遮罩／运动**：建议：分层剪影视差与灯光遮罩。
- **配色与排版**：原：剪纸影戏风格，音频柔和贴切。
- **工具与素材**：原：纯JavaScript；音频也用代码。
- **替换应用**：建议：换物件象征时保留情绪进程。
- **验证点**：建议：检查剪影轮廓和音画情绪对应。
- **缺口**：原：未给故事及调色；未测试。

## 原创复用提示词

在竖屏中以层叠剪影、有意义的家居物件和柔和原创声音，讲述归属感故事。
