# [Prompt Motion] 仅用作品集自有素材的视频

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：介绍用户作品集。
- **分镜与状态**：建议：代表项目、细节、作者署名。
- **节奏与时间轴**：原：20秒；镜头长度未定。
- **形变／遮罩／运动**：建议：在原素材内用裁切和位移组织。
- **配色与排版**：建议：继承作品集现有排版体系。
- **工具与素材**：原：仅用作品集资源；软件未定。
- **替换应用**：建议：替换作品集后重新盘点可用资产。
- **验证点**：建议：逐项核查素材来自限定范围。
- **缺口**：原：作品集和资产清单缺失；未测试。

## 原创复用提示词

仅用作品集所给资产制作短片，挑选代表作品，以克制裁切揭示有意义的细节。
