# [Prompt Motion] 口播素材的节奏剪辑

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：将原始口播剪得有趣有力。
- **分镜与状态**：建议：钩子、核心论点、结尾依次保留。
- **节奏与时间轴**：原：未给时长；按语义断句剪辑。
- **形变／遮罩／运动**：建议：关键字幕进出与手势相呼应。
- **配色与排版**：建议：字幕采用稳定位置和高对比。
- **工具与素材**：原：需口播原片；软件未指定。
- **替换应用**：建议：换素材后重做断句与音乐点。
- **验证点**：建议：核对字幕、音画同步和响度。
- **缺口**：原：原片、音乐及字幕文本缺失；未测试。

## 原创复用提示词

按清晰观点剪辑所提供的口播，准确同步字幕，仅对核心词添加图形强调。
