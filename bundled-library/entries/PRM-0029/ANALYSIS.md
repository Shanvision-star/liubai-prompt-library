# 制作思路

### 目标效果

先让观众看清卡片整体，再看到内部信息，最后用图表描线和背后光效增加层次。动画的阅读顺序来自“外框先稳定、细节再进入”，不必让所有元素同时运动。

### 画面与状态顺序

1. 卡片从 30% 尺寸、不可见的状态开始。
2. 卡片放大至 100%，并变得可见。
3. 等卡片缩放稳定，内部细节按顺序滑入。
4. 图表线条沿路径逐渐显现；卡片细节进入时，后方光晕同时显现。
5. 两个矩形略微错开时间横穿画面，形成扫过的光效。

原文没有指定图表描线与矩形扫光的精确起止时间，也没有给出细节的排列顺序。实施时需要根据现有卡片设计安排这些时间，不能把本次安排视作原文已有参数。

### 动画方法

原文明示的方法是缩放、可见性变化、依次滑入、路径式描线、光晕显现，以及两个矩形的时间错位。它没有要求弹簧运动、固定缓动曲线、镜头运动或循环播放。

可选实现建议：把卡片外框、标题、数值、图表、光晕、两个扫光矩形分成独立图层。让外框的缩放和透明度共享入场区间，再从缩放稳定的时间点启动内部元素。图表可以使用 SVG 路径的描边进度实现；扫光矩形可以放入卡片的裁切区域，以免覆盖周围页面。这些图层和实现方式是便于落地的建议，不是原文指定的技术栈。

### 工具与素材

原文需要已有卡片设计、内部细节、图表路径、后方光晕及两个矩形，但没有指定制作工具、视频格式、尺寸、帧率、时长、音乐或字体。

可选工具建议：已有网页组件可用 HTML/CSS 配合 SVG；需要集中控制时序时，也可以选择项目现有的动画库。无需因为同库其他提示词使用 GSAP、Canvas 或 Playwright，就把它们当作本条要求。

### 落地步骤与验收点

建议先静态还原卡片，确认字号、数值和图表可读；再单独完成 30% 到 100% 的外框入场；接着加入内部元素的顺序滑入；最后叠加描线、光晕和两次错开的扫光。每加一层便检查它是否遮挡已出现的信息。

验收时对照原文检查：卡片确实从 30% 到 100%；起始不可见、最终可见；内部细节没有抢在卡片缩放稳定之前入场；图表呈现连续描线路径；光晕与细节入场相关联；两个矩形的时间有可辨认的差异。扫光不遮住关键数字、文字不越出卡片，是本次补充的可读性检查建议。原文没有数值时序，不能把任意毫秒数宣称为已经满足的原要求。

### 如何替换内容复用

可换成营收卡、进度卡、健康数据卡或设备状态卡：替换标题、单位、关键数值和图表数据，保留“整体入场 → 细节滑入 → 图表描线与光效”的关系。品牌配色可用于图表和背后光晕；换成长标题或较大数值后，应重新检查裁切和扫光遮挡。原文未要求无缝循环，复用时可保留最终静态状态，不必自动加入回到起点的动画。
