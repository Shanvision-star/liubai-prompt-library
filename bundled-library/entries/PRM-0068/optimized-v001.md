# [Prompt Motion] 音乐卡点三维弹跳球

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：追求专业Blender级观感的球体动画。
- **分镜与状态**：原：球下坠、碰撞物件，随音乐换场。
- **节奏与时间轴**：原：动作与点亮需卡音乐节奏；无总时长。
- **形变／遮罩／运动**：原：三维弹跳与碰撞触发亮光。
- **配色与排版**：原：场景带幽默感；色彩未规定。
- **工具与素材**：原：three.js，明确不用Blender；多首纯音乐。
- **替换应用**：建议：替换乐段后重新标记碰撞节拍。
- **验证点**：建议：检查接触点、反弹连续性与节拍误差。
- **缺口**：原：未给曲目、授权、物理参数和帧率。

## 原创复用提示词

让球穿过简洁的三维障碍场景，用定时碰撞触发灯光与富有趣味的场景变化。
