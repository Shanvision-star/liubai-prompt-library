# [Prompt Motion] 十秒个人介绍（需本人信息）

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：根据已有了解介绍本人。
- **分镜与状态**：建议：自我定位→一项代表成果→姓名收尾。
- **节奏与时间轴**：原：10秒；建议只承载少量信息。
- **形变／遮罩／运动**：建议：用关键词入场配合一张获准的成果图。
- **配色与排版**：原：未指定风格、配色或字体。
- **工具与素材**：原：工具未指定；本人事实需授权提供。
- **替换应用**：建议：用确认过的简介替代模型猜测。
- **验证点**：建议：逐项确认身份事实与展示意愿。
- **缺口**：原：缺个人资料，不能据标题补写研究经历。

## 原创复用提示词

仅依据确认可用的事实制作简短个人介绍，突出一项有意义的成果与清晰姓名卡。
