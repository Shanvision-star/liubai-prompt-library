# [Prompt Motion] 字形成为建筑的演说循环

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：20秒方形字效演说循环。
- **分镜与状态**：原：受压→悬重→支撑→平台→遮挡复位。
- **节奏与时间轴**：原：16–18秒停留，18–20秒循环；至少400ms静止。
- **形变／遮罩／运动**：原：真实字形路径、基线形变、孔洞遮罩。
- **配色与排版**：原：深绿、纸白、金黄；衬线与粗黑体分工。
- **工具与素材**：原：SVG/Canvas、HTML、seek(t)、60fps。
- **替换应用**：建议：原创短文先分配字词的结构角色。
- **验证点**：原：查阅读顺序、字腔、平台来源与首尾一致。
- **缺口**：原：音频可选且默认关闭；字体素材待确认。

## 原创复用提示词

给原创演说的关键词分配结构角色，搭成可读的平台，再通过遮挡转场回到开头。
