# [Prompt Motion] 产品介绍与原创音乐同步

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：说明链接产品能做什么。
- **分镜与状态**：建议：问题、产品作用、使用结果。
- **节奏与时间轴**：原：要求音画同步，未给时长和BPM。
- **形变／遮罩／运动**：建议：以主要音符引导信息切换。
- **配色与排版**：原：追求作品集质量，无色字规范。
- **工具与素材**：原：提到Ultracode；具体工作流未说明。
- **替换应用**：建议：先展开并核实产品链接内容。
- **验证点**：建议：检查节拍对齐及产品事实。
- **缺口**：原：仅提供短链接，无产品简报；未测试。

## 原创复用提示词

以简洁叙事与原创配乐介绍产品，让有意义的画面变化对应音乐重音，同时保证信息清楚。
