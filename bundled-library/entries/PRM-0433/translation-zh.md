Motion Prompt #191

定义：摄像机环绕时，时间静止
示例展示：跳跃到顶点附近时，时间几乎停止，而摄像机围绕人物移动。
规格：
- 影像时间：0–1.5 s正常运行；1.5–3.3 s以0.1×运行，1.8 s播放时间只推进0.18 s影像时间；之后恢复正常，影像时间 = u - 1.62。
- 主体：人物位于9 m远处，在影像时间0.6–2.6 s内沿抛物线跳跃，峰值1.1 m、双臂抬起；慢速段看起来悬在顶点附近，处于过程45–54%；九片叶子使用同一影像时间下落。
- 摄像机：慢速段沿人物周围半径6 m的圆从-0.6 rad移至+0.6 rad，约69°，使用三次缓入缓出，约为cubic-bezier(0.65,0,0.35,1)；始终朝向圆心，高度1.6 m，pitch为-0.05 rad。
- 接下来的4.7 s过程反向环绕，从+0.6 → -0.6 rad，使9.4 s循环无缝衔接（#030 Orbit不会停止时间）。
- 地面有半径1.3 m的虚线圆，10 m处有一圈树；右上角读数为“×1.0” → “BULLET ×0.1” → “×1.0”。
何时使用：以三维方式展示决定性瞬间，或作为动作场面的高潮。
