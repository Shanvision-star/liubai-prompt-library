# [Prompt Motion] 不愿被修复的 Bug：九十秒短片

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：以拒绝被修复的bug为故事核心。
- **分镜与状态**：建议：发现问题→躲避修复→动机揭示→结局。
- **节奏与时间轴**：原：90秒；各幕长度未定。
- **形变／遮罩／运动**：建议：通过角色回避动作和界面异常表现冲突。
- **配色与排版**：原：没有指定虫子或软件拟人造型。
- **工具与素材**：原：无制作工具、声音或素材要求。
- **替换应用**：建议：先明确bug的隐喻和角色目标。
- **验证点**：建议：检查行为动机、情节因果和结局可理解性。
- **缺口**：原：未给对白、情绪走向或镜头清单。

## 原创复用提示词

讲述一个带有个人动机的错误的短故事，通过行动与后果让它的抵抗可见。
