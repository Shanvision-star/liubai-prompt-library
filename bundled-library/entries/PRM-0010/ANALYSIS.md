# PRM-0010 逻辑分析与表达设计

## 原文与适用范围

用户在丰田课堂中选中“把功能翻译成客户价值”及总拥有成本段落，并进一步要求先分析完整逻辑与表达方式，再整理为提示词。选段是本次获准收录的原始素材，并非一条已经实测有效的提示词。

适用于售前访谈整理、方案价值说明、价格异议分析和商务沟通草稿。当前只形成可复用模板，不代入用户自己的对接项目，不修改已安装的商务对接 skill。

## 底层逻辑

1. 客户评价的是具体任务结果。先锁定目标和采购标准，避免给错误的指标做优化。
2. 一项功能只有在某些条件下才会改变流程；流程改善能否转成经营收益，还取决于实际采用、需求量和瓶颈。
3. 价值链上的每一步都可能断开。“功能可运行”“受控测试有效”“真实业务改善”“现金收益”应分层核查。
4. 比较基于增量。统一期间、合格产出、规模和服务边界，既看新方案，也看现状与替代方案；新增负担应扣回。
5. 客户值得采用与我方值得承接需要分别核算。潜在客户收益不足以证明我方项目利润。
6. 推荐强度随证据变化。未知时先提出能改变决定的小验证，而不是许诺全部收益。

以上是本次整理者对方法的分析，不是已证实的历史采购因果或普遍客户结论。

## 表达方式

内部先分析完整因果与证据；对外只保留与决策有关的内容。顺序为“结论—客户问题—能力与机制—证据/条件—一个下一步”。

同一能力在不同证据状态下应有不同表述：
- 已核实能力：根据资料可以确认支持某项任务，不延伸为客户经营结果。
- 待验证收益：在明确条件下可能改善某项指标，说明用什么任务验证。
- 已测业务效果：保留样本、期间、基线与范围，避免推广至未测人群。
- 商业承诺：只使用实际批准或约定的价格、交付和验收条件。

## Original / Revised / Reason or Impact

- Original：原样保存用户选段，见 original.md；保留断线自动停机示例和总拥有成本说明。
- Revised：将案例段落转成包含七项输入、五步分析、客户草稿及受限修订的通用提示词，见 optimized-v001.md；不把织机情境或用户项目固化为默认输入。
- Reason / Impact：让方法能用于不同商务对接，同时使事实、价值推断、成本和承诺可核查；不把文字整理完成当作效果验证。

## 六项质量检查（v001）

| 项目 | 文本检查结论 |
| --- | --- |
| 目标清楚 | 聚焦判断能力能否创造值得投入的客户价值，并形成客户沟通草稿。 |
| 输入明确 | 七项变量覆盖角色、目标、流程、能力、证据成本、替代方案与渠道；关键缺口只优先追问一项。 |
| 约束合理 | 分层证据，收益不重复计数，缺失数据保持未知；不自行作出承诺或发送。 |
| 输出可检查 | 一句判断、价值链、同口径替代/成本表、对外草稿和最小验证动作。 |
| 使用证据 | 仅有选段来源、文本审阅及文件完整性检查；没有真实客户使用、模型对照或成交效果。 |

## Loop 提醒

首次输出自查一次，不需要为了优化而反复重写。只有新增真实资料、客户反馈或实测结果时再修订，最多两轮；记录原判断、新证据与变化。没有新证据、关键资料缺失、主要问题解决或达到上限即停止。模型赞同与自评分不证明商业效果。

## 如何验证

固定一份真实但经授权可用的客户材料，比较现用方法与 v001 的输出；记录采用版本、模型（已知时）、输入、误造事实、遗漏成本、价值链缺口、客户可读性和实际反馈。一次样例只支持该样例，不代表普遍需求或提高成交率。没有反馈前 evaluation_status 保持 untested。

## v002：How can I serve them? 服务心态

用户补充原话：“再添加一个how can i serve them的心态”。

- Original：v001 以客户目标、价值证据、替代方案与成本支撑采购判断，尚未单独说明服务心态。
- Revised：在 v002 中把“我怎样才能真正帮助这位客户”放在分析之前，并落实到目标核实、有条件推荐、当前最有用的一步和交付自查。
- Reason / Impact：帮助客户作出更清楚的决定，即使最适合的是现有办法、其他供应商、缩小范围、暂缓或不采购；让服务具有具体行为和可检查的范围，而非仅作为口号。

服务首先尊重客户自己认可的目标与选择权。可以据实提出不同意见；前期帮助不构成采购义务。下一步说明双方投入、预期结果、责任和停止条件，费用与交付范围保持明确，兼顾双方可持续合作。

对外表达仍先给结论，再说明问题、能力、证据与下一步；不机械插入“以客户为中心”等口号，不凭自身判断声称已经建立信任。

### 六项质量检查（v002）

| 项目 | 本版文本检查 |
| --- | --- |
| 目标 | 增加当前最能帮助客户的一步，不预设我方产品必然适合。 |
| 输入 | 保留七项变量，补充客户认可的成功标准、资源和约束。 |
| 约束 | 保留证据边界，并明确自主选择、范围、费用、责任和可持续合作。 |
| 输出 | 服务原则进入结论、推荐及自查，下一步含投入、结果、责任和退出条件。 |
| 使用证据 | 本版尚无实际运行或客户反馈；效果为 untested。 |
| 任务适配 | 适用于商务价值与采购判断；需要客户真实目标，不替客户决定。 |

v001 和原文保持不变，原评审快照保存于 record.json 的 review_history。首次整理无需额外循环；仅在新真实资料或反馈到来后，最多两轮修订。比较版本时固定输入和运行条件，不把“心态表述更完整”当作效果提升证据。

## v003：Be greedy long term, never short term.

用户原话：“并且把Be greedy long term，Never short term加进去”。

- Original：v002 已加入 How can I serve them?，围绕客户认可的目标、适配、可退出的下一步与双方可持续合作。
- Revised：v003 增加长期取向，并落实到承诺、定价回款、前期投入、维护和退出判断中。
- Reason / Impact：让收益建立在持续创造价值与兑现承诺上，保护信誉、能力和合理利润的长期积累，同时保留当前经营约束。

长期价值不等于延长合作或维持客户依赖，一次性交付、推荐其他方案或及时结束也可正确。前期投入有预算、观察期、检查点和退出条件；潜在复购与转介绍只作假设。合理收费、回款与现金流是长期履约基础。发现判断或承诺有误时，应及时说明影响并在职责内纠偏。

六项文本检查：目标增加长期积累；输入沿用七项变量与未知处理；约束保留现金流、范围和退出；输出加入当前与长期影响；使用证据仍不足；任务适配限定在真实商务材料和可核算投入上。详细分项见 record.json 的 v003 quality_review。v001、v002 及对应评审均保留；本版效果为 untested。

首次整理不强行循环；取得真实资料或反馈后，最多两轮修订。长期理念是否改善判断或表达，需要实际运行与反馈，不能仅凭文字认同确认。
