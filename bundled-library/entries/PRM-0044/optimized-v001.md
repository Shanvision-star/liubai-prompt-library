# [Prompt Motion] 以不同影像风格解释递归

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：解释递归并体现自指。
- **分镜与状态**：建议：外层讲解进入内层讲解后返回。
- **节奏与时间轴**：原：节奏快；总时长未指定。
- **形变／遮罩／运动**：建议：用重复构图标记递归层级。
- **配色与排版**：原：每次解释风格显著不同。
- **工具与素材**：原：未指定软件与素材。
- **替换应用**：建议：换概念时保留清楚的层级关系。
- **验证点**：建议：检查基例与返回过程能否读懂。
- **缺口**：原：无脚本与终止规则；未测试。

## 原创复用提示词

用三个视觉不同的层级解释嵌套过程，设置明确终止条件，并回到开场画面。
