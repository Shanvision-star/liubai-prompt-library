# 设计思路拆解

- **目标画面**：原：用白球的连续路径解释一串UI动作。
- **分镜与状态**：原：开关、滑杆、三条通知、回复框、键盘、回返。
- **节奏与时间轴**：原：约10秒；配乐约120 BPM，各事件对齐测得节拍。
- **形变／遮罩／运动**：原：同一场景中移动镜头；弹簧落地并短暂挤压。
- **配色与排版**：原：近黑点阵、炭灰控件、白字和单一蓝色。
- **工具与素材**：原：HTML、Playwright；1920×1080、60fps。
- **替换应用**：建议：换目标数值及回复内容，重排对应按键路径。
- **验证点**：原：球不瞬移，数值贴滑块；首尾含方向与光标一致。
- **缺口**：原缺具体音轨和逐拍时间表；交互与导出未测试。
