Motion Prompt #126

定义：沿自定义曲线移动
示例展示：纸飞机沿虚线路径前进并不断转向，途中完成一次翻环。
规格：
- 每4.7 s走完一次，从屏幕左侧外进入、右侧外离开。路径为x = 270 + 112θ − 150·sinθ，y = 106 − 74·cosθ，θ = −π→π，在顶部中央形成一个环。
- θ与时间成正比推进，因此路径上的实际速度不恒定，环形部分看起来较慢。
- 飞机朝向路径切线，角度 = atan2(74·sinθ, 112 − 150·cosθ)。
- 提前显示路径虚线，线宽6，虚线间隔2/15；飞机身后有24段薄荷色轨迹，每段θ差0.03，越靠后越细、越淡。
何时使用：用于沿规定路线移动的对象，如飞行物、汽车或地图上的旅程。
