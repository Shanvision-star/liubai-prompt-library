Motion Prompt #165

定义：持续运动的波浪形章节分隔线。
示例展示：蓝色区块与白色区块交界处，两层波浪形状缓慢摆动。
规格：
- 视口511×168，上方蓝色渐变区块#3B64E8→#8FA9F7，下方白色区块，边界叠加两层波浪。每4.7 s循环一次，在9.4 s包循环内两次。
- 后层波浪为不透明度0.45的白色，以y = 100为中心，由波长260 px、振幅8 px的正弦波和波长130 px、振幅4 px的正弦波相加。
- 前层波浪为白色，以y = 110为中心，叠加波长300 px/振幅9 px与波长110 px/振幅3.5 px，向下与白色区块相接。
- 令相位a = 2π·t/4.7，后层两波使用a + 1和−2a，前层使用−a和2a + 0.5；每层内两个正弦沿反方向移动，所以形状持续变化，并每4.7 s返回起始状态。
何时使用：用于希望章节边界柔和而非笔直的页面，例如海洋、夏日或儿童主题网站。
