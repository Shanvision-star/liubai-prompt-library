# [Prompt Motion] 可映射品牌色的产品短片重制

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：复现输入框到内容展示的产品宣传节奏。
- **分镜与状态**：原：标题、图标、菜单输入、答案、卡片、标志。
- **节奏与时间轴**：原：29.97fps编号；f72、101、159固定切点。
- **形变／遮罩／运动**：原：定向模糊承接切镜，玻璃文字裁切背景副本。
- **配色与排版**：原：品牌色映射；默认蓝白，Inter，禁紫橙。
- **工具与素材**：原：HTML、SVG、Playwright；59.94fps母版。
- **替换应用**：建议：换产品文案；长名称需整体缩放字标组合。
- **验证点**：原：查4张关键帧，卡片避免叠加素材自带文字。
- **缺口**：原称12秒而音轨12.075秒；成片未测试。

## 原创复用提示词

围绕输入与反馈规划品牌产品演示；先定义可读状态、明确切镜和可独立调整的色彩角色。
