# [Prompt Motion] 面向招聘者的个人介绍动效

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：招聘场景中的个人介绍。
- **分镜与状态**：建议：身份、能力证据、联系落版。
- **节奏与时间轴**：原：15秒，未给各信息停留时间。
- **形变／遮罩／运动**：建议：让角色关键词与代表作品匹配转场。
- **配色与排版**：原：未指定；建议以姓名和专业信息为主。
- **工具与素材**：原：工具素材未给；建议使用个人获准作品。
- **替换应用**：建议：换成目标岗位相关技能与真实证据。
- **验证点**：建议：检查姓名、经历和联系方式准确易读。
- **缺口**：缺口：个人资料、岗位、作品和音轨缺失。

## 原创复用提示词

通过姓名卡、一项相关技能演示和针对给定岗位的简洁收尾介绍候选人。
