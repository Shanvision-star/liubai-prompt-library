```text
请为 {{content_or_artifact}} 设计并选择一致的视觉主题。

使用媒介 {{medium}}，受众 {{audience}}，期望语气 {{desired_tone}}，已有品牌规则 {{brand_constraints}}，可用字体和素材 {{available_resources}}。用户已选主题为 {{selected_theme_or_none}}。

如主题已选定，先核对可取得的定义，再继续应用；不要重复要求选择。未选定时提出 3 个候选，每个写明适合的情境及不适合的情境，不只列‘高级、现代’等形容词。

每个候选包含：
- 主题概念与内容的关系。
- 色彩的语义角色：背景、正文、次要文字、强调、链接与必要状态；提供具体候选值，并区分建议值与已有品牌值。
- 字体角色：标题、正文、数据；包含中文与数字的显示考虑、可用字体和回退方案。不假定商业字体已获授权或本机已安装。
- 层级、间距和装饰原则，以及应避免的用法。

用相同的标题、正文、链接、按钮或表格内容展示候选；有渲染能力就给样张，没有则给文字规格并明确‘未渲染’。推荐一个并解释取舍。未选主题时等待用户选择；只有用户已授权代选才自行定稿并说明依据。

主题确定后，先应用到一个代表性页面，再扩展到已授权范围。保留内容与数据，记录旧样式到新角色的映射。实际测过对比度才能报告数值；未测的可访问性项目列为待验证。

输出候选对照或已选主题说明、完整主题规格、应用样张/规格、变更映射和检查结果。

Loop 与停止条件：
单纯列主题候选时不自动循环。主题已选定并有样张后，最多 2 轮‘应用 → 检查 → 修正’：检查角色映射是否一致、中文与数字是否可读、字体是否真实可用、状态是否只靠颜色表达、长标题是否破坏层级。固定内容后每轮只调整一个问题组。用户已认可且检查通过即停止；缺反馈、需重新选择方向、无法渲染、连续一轮无改善或达到上限时停止并说明。禁止为了继续循环自行更换已选主题。
```
