# PRM-0005 设计逻辑与使用方法

为文档、演示或页面选择主题，用同一内容样张比较语气、层级和可读性。

## 为什么入选

统一页面、PPT、报告或系列内容的语气，避免每次随意换字体和颜色。 源文具有明确任务、具体步骤和可检查的产物，适合作为高质量候选。此处是结构评审，不是效果认证。

## 原作者公开的方法

以下依据[固定版本原文](https://github.com/anthropics/skills/blob/dbd4588f9e1033efb41dad4bef2f7947c8993d44/skills/theme-factory/SKILL.md)归纳：原文提供主题展示、用户选择、应用主题的流程；每个主题包含配色与字体组合，也允许按要求创建自定义主题。

## 我的设计逻辑分析

以下是本次整理者对方法作用的解释，不是作者未公开的内部思考：‘正式、温暖、科技’需要转成可复用的视觉角色。让相同内容穿上不同主题，能隔离主题本身的影响；先确认小样再覆盖全部页面，可以减少返工。语义角色比零散色值更容易维持正文、强调、链接和状态之间的一致性。

## Original / Revised / Reason or Impact

- Original：完整保留 [original.md](original.md)，包括特定工具、占位符与风格约束。
- Revised：提供可单独复制的 [中文优化版](optimized-v001.md)，具体调整如下。
  - 将依赖外置十主题和展示 PDF 改为根据用户材料生成三个可解释的候选主题。
  - 增加中文字体覆盖、字体可用性、语义色彩与代表性内容样张。
  - 保留用户选择的环节；已经指定主题时无需重复确认，读不到主题文件时明确缺口。
- Reason / Impact：让方法能跨项目复用并暴露证据缺口；这不是逐字翻译，也不能视为与原技能流程等效。

## Loop 是否需要、怎样写

**只选主题无需自动循环；小样应用最多 2 轮。**

```text
单纯列主题候选时不自动循环。主题已选定并有样张后，最多 2 轮‘应用 → 检查 → 修正’：检查角色映射是否一致、中文与数字是否可读、字体是否真实可用、状态是否只靠颜色表达、长标题是否破坏层级。固定内容后每轮只调整一个问题组。用户已认可且检查通过即停止；缺反馈、需重新选择方向、无法渲染、连续一轮无改善或达到上限时停止并说明。禁止为了继续循环自行更换已选主题。
```

## 使用示例与边界

- 使用示例：用同一页提示词卡片比较‘安静档案’‘专业工具’‘温暖书桌’三种主题，保留中文正文可读性。
- 不宜直接外推：好看的色板不等于可读的实际版面；必须检查文字与背景的实际组合，不能仅凭看起来顺眼宣称符合可访问性标准。
- 证据现状：公开原文给出可执行的主题工作流程；本次未运行主题渲染，没有比较目标读者对主题的理解或偏好。
- 实际效果状态：`untested`。已完成的检查仅为来源、文件完整性、分类、版本与文本结构；未进行真实模型生成、用户偏好测试或项目运行。

## 如何验证这条提示词是否对你有效

选择一个代表性任务，冻结输入、模型与运行条件，用原版适用环境和优化版各生成一次；原版依赖不齐时，将基线改为你现用提示词并明确标注。记录输出、失败项、可观察指标和你的取舍理由。先看是否达成上述可检查产物，再记录偏好；一次胜出只是样例证据，不能推广为通用结论。把实际结果写入本条反馈并保留失败样例后，再决定是否生成 v002。
