# [Prompt Motion] 面向零基础的 Git 中文讲解

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：让计算机零基础者理解Git。
- **分镜与状态**：原：介绍概念及常用指令；建议先用版本类比。
- **节奏与时间轴**：原：无总长；建议一条命令一段。
- **形变／遮罩／运动**：建议：用文件版本与分支图展示状态变化。
- **配色与排版**：原：深入浅出；未指定美术风格。
- **工具与素材**：原：JavaScript、中文声音；允许工具但本次未执行。
- **替换应用**：建议：换命令集时补充小型可复现示例。
- **验证点**：建议：核对术语、命令效果与字幕同步。
- **缺口**：原：未给命令清单、旁白稿和工具版本。

## 原创复用提示词

用简单的文件历史故事解释Git，每次展示一条命令，并让清晰的中文旁白对应状态变化。
