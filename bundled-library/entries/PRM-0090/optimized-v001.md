# [Prompt Motion] 20秒以内品牌功能发布片

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：全部关键功能须纳入品牌一致的发布片。
- **分镜与状态**：建议：将功能按用户任务归成少量连续场景。
- **节奏与时间轴**：原：20秒或更短，节奏快。
- **形变／遮罩／运动**：建议：用同位置界面切换减轻理解负担。
- **配色与排版**：原：符合品牌；具体颜色字体未给。
- **工具与素材**：原：未指定工具或功能素材。
- **替换应用**：建议：先列功能优先级与所需截图。
- **验证点**：建议：核对每项功能出现且字幕可读。
- **缺口**：原：缺功能清单和品牌规范；未测试。

## 原创复用提示词

围绕优先用户任务编排简短发布片，保持品牌字体，并为每项必要功能预留阅读时间。
