Motion Prompt #192

定义：用连续短镜头压缩时间
示例展示：七个短镜头展示三十天训练，以硬切连接，右上角日期不断跳跃。
规格：
- 七个镜头用硬切相连，转场为0帧；时长依次为0.75 / 0.7 / 0.65 / 0.65 / 0.65 / 0.6 / 0.7 s，总计4.7 s；右上日期跳为DAY 1 → 3 → 7 → 12 → 20 → 28 → 30。
- 镜头：1跟随跑者，腿部相位t×14；2公园中的跳跃；3日出，太阳从4 m升至12 m；4低角度拍摄举臂；5城中行走，焦距420 px；6从-0.3至+0.3 rad环绕人物；7在旗帜前举臂。
- 把三十天训练浓缩为4.7 s；每个镜头的相机位置、高度与焦距都会改变（#041 Jump cut保持同一构图）。
- 底部条分成七段，仅当前镜头为蓝色；最后0.3 s交叉淡化回第一个镜头起点。
何时使用：用很短时间表现长期变化或努力过程。
