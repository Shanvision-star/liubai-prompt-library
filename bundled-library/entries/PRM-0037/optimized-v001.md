# [Prompt Motion] 落地页的三维巡游与标题收束

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：把落地页变为可分层浮起的产品展示。
- **分镜与状态**：原：低空巡游、升高俯视、俯冲首屏、标题卡。
- **节奏与时间轴**：原：14.5秒；9.47秒俯冲，9.97秒落到标题卡。
- **形变／遮罩／运动**：原：速度积分驱动镜头；景深随深度变化。
- **配色与排版**：原：明亮展台；Geist与Instrument Serif配字。
- **工具与素材**：原：Playwright截取分层；WebGL2，60fps。
- **替换应用**：建议：换自有页面；先固定版式再重排镜头。
- **验证点**：原：先查7张定时静帧；光流检查速度与变焦。
- **缺口**：页面、品牌和曲目待提供；GPU导出未经测试。

## 原创复用提示词

将自有落地页呈现为分层场景，用连续一致的镜头巡游，最后停在产品最有力的主视觉。
