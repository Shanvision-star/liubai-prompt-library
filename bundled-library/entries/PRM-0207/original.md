# [Prompt Motion] Chain.wtf 30秒推介视频

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：为@chaindotwtf进行简短推介。
- **分镜与状态**：建议：问题、解决方式、证据与行动。
- **节奏与时间轴**：原：30秒；未给段落时间轴。
- **形变／遮罩／运动**：建议：以信息层级控制元素入场。
- **配色与排版**：原：没有配色、字体和画面参考。
- **工具与素材**：原：没有软件或素材要求。
- **替换应用**：建议：先核实账号对应产品和受众。
- **验证点**：建议：检查推介主张是否有可用证据。
- **缺口**：原：产品详情、文案及素材缺失；未测试。

## 原创复用提示词

围绕已核实问题、具体方案、支持证据及一个明确后续行动组织简短推介。
