# [Prompt Motion] 15秒动效设计师作品集

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：以作品集展示设计能力；无指定产品。
- **分镜与状态**：建议：开场标识、两组技法展示、署名收尾。
- **节奏与时间轴**：原：15秒；镜头时长与节拍未给。
- **形变／遮罩／运动**：建议：字体进场后形状接力，减少无关跳切。
- **配色与排版**：建议：固定两种字号与一组主辅色。
- **工具与素材**：原：未指定工具或素材。
- **替换应用**：建议：换为自己的名字与授权案例。
- **验证点**：建议：检查转场承接、字形与首尾停留。
- **缺口**：原：缺比例、音轨、字体；未测试。

## 原创复用提示词

制作紧凑作品集：清晰开场、两组动效研究、可读署名；先定义节奏再制作。
