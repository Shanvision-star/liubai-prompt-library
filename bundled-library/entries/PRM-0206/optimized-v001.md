# [Prompt Motion] 自由主题动效能力展示

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：题材与设计风格自行选择。
- **分镜与状态**：建议：先提出一个可视化概念再分镜。
- **节奏与时间轴**：原：没有时长要求；标题非参数。
- **形变／遮罩／运动**：建议：用连续变化替代静态页面堆叠。
- **配色与排版**：原：没有限定配色与字体。
- **工具与素材**：原：未指定工具和素材。
- **替换应用**：建议：新用途先明确受众与传播目标。
- **验证点**：建议：检查运动是否服务于概念。
- **缺口**：原：具体主题、规格均缺失；未测试。

## 原创复用提示词

选择清楚的视觉概念，发展一连串有意义的变化，并在制作前记录受众与目的。
