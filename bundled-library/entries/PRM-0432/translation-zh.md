Motion Prompt #190

定义：在同时发生的两处场景间交替
示例展示：同一时间发生的两处场景——跑者与汽车——交替出现，切换间隔越来越短。
规格：
- 两处场景共用同一个时钟：A为跑者，左侧0.3 m，深度15 m → 4.5 m，腿部相位u×12；B为城中汽车，右侧1 m，深度17 m → 4.5 m；两者都在4.7 s内接近。
- 切点：在0 / 1.1 / 2.0 / 2.7 / 3.3 / 3.8 / 4.2 / 4.5 s之间对A、B进行硬切；镜头时长逐步缩短为1.1 → 0.9 → 0.7 → 0.6 → 0.5 → 0.4 → 0.3 s，以提升紧张感。
- 当一处场景显示时，另一处仍在继续运行；再次切回时，其主体已经继续前进。
- 摄像机：A高度1.3 m、固定，前景有四根立柱；B高度1.6 m、pitch为+0.06 rad、固定，含城市和太阳。
- 底部条为八段交替的A（灰）与B（蓝），带播放头；最后0.3 s交叉淡化回A的起点。
- 右上角读数显示“SCENE A” / “SCENE B”。
何时使用：在同时发生的事件之间建立紧张感，例如追逐或营救。
