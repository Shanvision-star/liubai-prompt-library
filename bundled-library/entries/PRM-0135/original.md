# [Prompt Motion] 开发者关系工程师网站作品集

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：展示开发者关系工程师的工作。
- **分镜与状态**：原：网页、聊天答复、手机和深色视图。
- **节奏与时间轴**：原：约90至100秒，音乐约120BPM。
- **形变／遮罩／运动**：原：缓动和平滑转场，每镜一个想法。
- **配色与排版**：原：三色、本站字体，1920×1080。
- **工具与素材**：原：Remotion；浏览器捕捉真实网站。
- **替换应用**：建议：替换成自己的可公开职业资料。
- **验证点**：原：只用站内事实；建议核对每次卡拍。
- **缺口**：原：无源素材；禁止额外音效，未测试。

## 原创复用提示词

用真实屏幕和核实表述展示职业网站，每镜围绕一个信息并配合有意安排的音乐节奏。
