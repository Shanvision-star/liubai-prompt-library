# [Prompt Motion] 可编辑的 Remotion SaaS 发布片

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：可编辑并重新渲染的产品发布片。
- **分镜与状态**：原：市场→痛点→解决方式→收益，4至5场。
- **节奏与时间轴**：原：30秒，标题留足阅读时间。
- **形变／遮罩／运动**：原：逐词字效、弹簧缓动、镜头推进与摇移。
- **配色与排版**：原：沿用真实字体、颜色和标志。
- **工具与素材**：原：Remotion；需落地页、代码库、logo素材。
- **替换应用**：建议：先确认品牌资产和各段事实再替换产品。
- **验证点**：原：检查重叠、裁切和节奏过急后修正。
- **缺口**：原：具体产品为占位符；素材及音效未提供。

## 原创复用提示词

用核实的品牌素材制作可编辑产品片，清晰串联问题与价值，保留阅读停顿并明确逐帧检查项。
