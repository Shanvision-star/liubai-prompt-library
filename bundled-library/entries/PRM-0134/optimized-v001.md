# [Prompt Motion] 纸面字效与手绘注释的产品说明片

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：15秒产品说明，无配音和实拍片段。
- **分镜与状态**：建议：痛点→产品学习对象→价值→真实标志。
- **节奏与时间轴**：原：每1.5–2秒新想法，每个落点有声音。
- **形变／遮罩／运动**：原：手写描边、形变、错时、拖影；初态可跳转。
- **配色与排版**：原：浅纸底、明暗切换；Anton与Caveat。
- **工具与素材**：原：HyperFrames、GSAP；音频限CC0或生成。
- **替换应用**：原：替换定位文档、品牌字体、禁用词与配色。
- **验证点**：原：禁虚构成果；AAC后重测−14 LUFS、−2 dBTP。
- **缺口**：原：占位参数及素材未提供，工具未安装。

## 原创复用提示词

把已核实的产品定位变成纸面字效、手绘笔记和物理转场，配合声音落点，不虚构效果数据。
