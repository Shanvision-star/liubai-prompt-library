# [Prompt Motion] 将文章转成教育视频

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：把文章转换成教育视频。
- **分镜与状态**：建议：核心问题→图解→例子→回顾。
- **节奏与时间轴**：原：时长未指定；建议按学习目标分段。
- **形变／遮罩／运动**：建议：用逐步显现替代整段文字堆叠。
- **配色与排版**：原：未给美术风格；建议标题层级清晰。
- **工具与素材**：原：工具未定；文章是必要输入。
- **替换应用**：建议：换文章时先提炼可验证的学习目标。
- **验证点**：建议：核对图解与原文观点一致。
- **缺口**：原：缺文章链接、受众、配音和语言要求。

## 原创复用提示词

把提供的文章转成教学序列，包含一个学习目标、视觉解释、演示例题与回顾。
