# [Prompt Motion] 导数概念教学动效

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：导数教学须易懂、有例子、能引发思考。
- **分镜与状态**：建议：平均变化率、割线趋近、切线斜率、提问。
- **节奏与时间轴**：原：时长未给；建议给推导留阅读停顿。
- **形变／遮罩／运动**：建议：连续移动取样点，保持函数图像稳定。
- **配色与排版**：建议：用同色绑定公式与对应几何量。
- **工具与素材**：原：Manim制图、edge-tts配音。
- **替换应用**：建议：替换函数时同步检查导数域。
- **验证点**：建议：核对斜率、公式、配音时序。
- **缺口**：原：缺受众水平及例题；未测试。

## 原创复用提示词

通过一幅图示和一个例题讲解数学概念，同步配音、符号，最后设置推理问题。
