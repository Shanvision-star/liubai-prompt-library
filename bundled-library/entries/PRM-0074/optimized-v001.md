# [Prompt Motion] 二十秒迷幻催眠动效

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：展示动态设计能力与迷幻氛围。
- **分镜与状态**：建议：中心图形聚焦→循环变形→回归中心。
- **节奏与时间轴**：原：20秒；建议周期变化保持连续。
- **形变／遮罩／运动**：建议：以同心缩放和重复形变建立催眠感。
- **配色与排版**：原：迷幻风格；配色和字体未定。
- **工具与素材**：原：无指定工具、音轨或素材。
- **替换应用**：建议：更换中心符号形成不同主题。
- **验证点**：建议：查循环接缝及闪烁是否过强。
- **缺口**：原：页面标题有眼睛，提示词未指定眼睛。

## 原创复用提示词

用一个中心母题、重复放射变换和受控色彩变化制作催眠式抽象循环，避免突兀闪烁。
