# [Prompt Motion] Taxtello：真实财务界面的克制发布片

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：最长15秒、1080p、60fps产品片。
- **分镜与状态**：原：标志→财务→票据→发票→税务→品牌。
- **节奏与时间轴**：原：约14–15秒；约2秒内出现产品。
- **形变／遮罩／运动**：原：共享几何、错时到位、小于约2%过冲。
- **配色与排版**：原：深海军蓝与金色；Plus Jakarta Sans、JetBrains Mono。
- **工具与素材**：原：Remotion、真实仓库与品牌素材。
- **替换应用**：建议：用自家核实界面及安全演示数据。
- **验证点**：原：查真实功能、可读性、解码帧与现有作品保留。
- **缺口**：原：依赖指定私有项目；本次未访问或执行。

## 原创复用提示词

用已核实的界面介绍记账产品，以共享几何连接票据和付款状态，最后安静呈现品牌。
