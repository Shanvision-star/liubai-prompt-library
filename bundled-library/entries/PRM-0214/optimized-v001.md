# [Prompt Motion] 人声节拍同步歌词动效

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：歌词与动画须精确同步人声和节拍。
- **分镜与状态**：建议：按歌词句组划分段落，副歌形成视觉变化。
- **节奏与时间轴**：原：音乐时长未提供，须从实际音轨确定。
- **形变／遮罩／运动**：建议：逐词高亮与节拍变形分开控制。
- **配色与排版**：建议：先保证歌词可读，再增加装饰。
- **工具与素材**：原：依赖所附音乐；未指定工具。
- **替换应用**：建议：替换为有权使用的音轨与核对歌词。
- **验证点**：建议：检查起音、换行及每个重拍的对齐。
- **缺口**：原：音频、歌词与时间码未提供；未测试。

## 原创复用提示词

将核对后的歌词对齐授权音轨，区分人声强调与节拍重音，并在动画转场中保持可读。
