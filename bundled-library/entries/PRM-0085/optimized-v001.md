# [Prompt Motion] Spotify：同一专辑贯穿的音乐产品短片

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：18秒音乐产品片，1920×1080、60fps。
- **分镜与状态**：原：标志→界面→搜索→封面→歌单→标志。
- **节奏与时间轴**：原：15.2–18秒结尾；音乐约120 BPM。
- **形变／遮罩／运动**：原：匹配位置交接、遮罩、受控透视；禁反复弹跳。
- **配色与排版**：原：暗色圆角舞台、绿色重点、Geist或Inter。
- **工具与素材**：原：确定性seek(t)；帧内3–5次时间采样。
- **替换应用**：建议：换自有音乐品牌及同一张原创封面。
- **验证点**：原：查封面一致、播放器稳定、字距、帧时间。
- **缺口**：原：需制作封面和可商用音乐；未实测。

## 原创复用提示词

让同一封面和次要播放器贯穿发现、搜索与收听流程，最后收束为品牌标识。
