# [Prompt Motion] 带背景音乐的星期说明

## 设计思路拆解

- **目标画面**：原：通过动效传达当天星期。
- **分镜与状态**：建议：日期线索、星期揭示、结果停留。
- **节奏与时间轴**：原：30秒，包含BGM。
- **形变／遮罩／运动**：建议：用日历页或字形转换建立揭示。
- **配色与排版**：原：要求酷炫，未指定色彩字体。
- **工具与素材**：原：工具未给；建议使用获准背景音乐。
- **替换应用**：建议：换成节日或倒计时并先确认日期。
- **验证点**：建议：核对日期、时区与最终星期文本。
- **缺口**：缺口：原帖执行日期和时区无法由指令确定。

## 原创复用提示词

按明确提供的日期与时区制作日历式星期揭示，保留可读尾帧并使用获准背景音乐。
