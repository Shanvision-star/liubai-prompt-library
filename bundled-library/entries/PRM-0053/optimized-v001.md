# [Prompt Motion] 列车窗外的四季

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：车窗外四季流转。
- **分镜与状态**：建议：室内连续，窗外春夏秋冬依序更替。
- **节奏与时间轴**：原：未给总长；建议每季保留识别停顿。
- **形变／遮罩／运动**：建议：窗框作遮罩，远近景分层横移。
- **配色与排版**：原：温馨氛围及《布达佩斯大饭店》参照。
- **工具与素材**：原：工具未指定；建议自制风景素材。
- **替换应用**：建议：替换旅行地点，保留咖啡作固定参照。
- **验证点**：建议：检查窗内外遮挡及季节辨识度。
- **缺口**：原：未给镜头速度、色值和帧率。

## 原创复用提示词

保持温暖车厢稳定，让四季风景从车窗遮罩后经过，并用分层景物表现纵深。
