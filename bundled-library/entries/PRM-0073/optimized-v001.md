# [Prompt Motion] 美食需求到下单的连续变形发布片

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：15秒二维产品发布片。
- **分镜与状态**：原：输入→锅具思考→菜品卡→下单→配送标志。
- **节奏与时间轴**：原：130 BPM、32拍约14.8秒；第12拍落点。
- **形变／遮罩／运动**：原：遮罩抬字、按钮扩页、色块铺满再收缩。
- **配色与排版**：原：暖白、黑、青柠、橙；实拍食物。
- **工具与素材**：原：HTML seek(t)、Playwright、ffmpeg；Mixkit音效。
- **替换应用**：建议：换成自家需求、候选项与成交状态。
- **验证点**：原：查共享元素、图层、闪帧与快速运动重影。
- **缺口**：原：需照片、音乐、品牌；15秒与14.8秒需对齐。

## 原创复用提示词

通过共享形状把客户需求变为推荐与确认，再让配送符号变成品牌标志。
