# [Prompt Motion] 15秒推荐计划宣传

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：介绍推荐计划；未提供具体规则。
- **分镜与状态**：建议：发出邀请、朋友加入、回报出现。
- **节奏与时间轴**：原：15秒；奖励环节建议留清楚停顿。
- **形变／遮罩／运动**：建议：以连接线和状态变化表达邀请关系。
- **配色与排版**：建议：奖励与条件用不同层级排版。
- **工具与素材**：原：未要求吉祥物，未指定工具素材。
- **替换应用**：建议：换入真实奖励、资格与限制条件。
- **验证点**：建议：核对奖励触发条件及文案准确性。
- **缺口**：原：缺规则、品牌与CTA；未测试。

## 原创复用提示词

用邀请、合格操作和奖励三个环节解释推荐流程，让资格条件可见且无歧义。
