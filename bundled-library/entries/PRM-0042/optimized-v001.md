# [Prompt Motion] 真实竖屏素材驱动的UGC工具宣传片

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：用真实视频展示UGC工具的生成与筛选价值。
- **分镜与状态**：原：钩子、UI、视频墙、轮播、手机结果、标志。
- **节奏与时间轴**：原：120 BPM，10小节，每节2秒；切镜落强拍。
- **形变／遮罩／运动**：原：遮罩出字、匹配切镜、甩镜；单帧按时间计算。
- **配色与排版**：原：留白、单强调色，Geist或Inter，拒绝杂乱特效。
- **工具与素材**：原：10至20段自有竖片；ffmpeg、numpy、Playwright。
- **替换应用**：建议：换真实业务结果，别让演示统计冒充实绩。
- **验证点**：原：先查至少20帧；声音峰值对齐交互。
- **缺口**：原含游离http://片段；素材、节拍、导出未验证。

## 原创复用提示词

用清晰问题、自有视频、一段工作流演示和真实结果介绍创作工具；让转场与获授权的音乐同步。
