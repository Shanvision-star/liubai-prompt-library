# [Prompt Motion] 核心作品级动效集锦

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：作品集核心片，展现能力广度。
- **分镜与状态**：建议：以统一母题连接不同技法片段。
- **节奏与时间轴**：原：总时长和段落节奏未指定。
- **形变／遮罩／运动**：建议：让技法切换保持形状位置连续。
- **配色与排版**：建议：控制色彩与字体数量。
- **工具与素材**：原：未指定工具和素材。
- **替换应用**：建议：按个人强项替换展示模块。
- **验证点**：建议：检查每个片段是否体现不同能力。
- **缺口**：原：缺规格与具体内容；未测试。

## 原创复用提示词

围绕一个母题设计连贯展示，以不同动效技法体现能力，同时保持统一视觉和可读节奏。
