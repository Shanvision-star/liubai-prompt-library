# [Prompt Motion] Tented 品牌图片生成功能展示

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：展示Tented图像生成能力。
- **分镜与状态**：原：用户请求品牌图片→图片加入内容。
- **节奏与时间轴**：原：仅称短片，未指定秒数。
- **形变／遮罩／运动**：建议：用同一图片卡片跨状态移动保持连续。
- **配色与排版**：原：品牌图片是内容对象；界面配色未定。
- **工具与素材**：原：无指定工具；需真实界面与获准示例图片。
- **替换应用**：建议：替换案例时保留输入与最终用途关联。
- **验证点**：建议：核对生成结果与插入状态可辨认。
- **缺口**：原：没有失败状态、等待时长或规格。

## 原创复用提示词

展示品牌图片请求变成获准视觉素材并进入内容版面，跨转场保持同一对象的识别连续性。
