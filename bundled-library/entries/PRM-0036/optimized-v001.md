# [Prompt Motion] 照片冲印应用的连续变形发布片

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：用照片冲印流程串起连续二维发布片。
- **分镜与状态**：原：字标、相册、玻璃控件、下单、挂画再归位。
- **节奏与时间轴**：原：120 BPM、54拍；每拍有变化，首尾相同。
- **形变／遮罩／运动**：原：虹膜遮罩与形变接力；玻璃复制背景后位移。
- **配色与排版**：原：暖白底黑界面，Archivo字标、Geist控件。
- **工具与素材**：原：HTML、Playwright、ffmpeg；9至12张照片。
- **替换应用**：建议：换自有照片和品牌，逐项确认影音授权。
- **验证点**：原：逐拍检查；60fps、每帧4子帧合成。
- **缺口**：原需输入品牌与歌曲；玻璃效果及素材许可未测试核实。

## 原创复用提示词

设计照片服务故事，用一个视觉对象连接浏览、下单与展示；先规划转场，再选用获授权的素材。
