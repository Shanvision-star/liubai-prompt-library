# [Prompt Motion] 五场景商业介绍动画

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：面向指定客户介绍所售业务。
- **分镜与状态**：原：痛点→业务→三步流程→证据→名称。
- **节奏与时间轴**：原：总长30秒；未分配各段秒数。
- **形变／遮罩／运动**：原：平滑转场；建议沿用同一视觉对象串联。
- **配色与排版**：原：粗体文字与品牌颜色。
- **工具与素材**：原：单一HTML页；业务信息为待填参数。
- **替换应用**：建议：先替换受众、销售内容和品牌色。
- **验证点**：建议：检查五段齐全且证据可核实。
- **缺口**：原：未给具体业务、素材和输出比例。

## 原创复用提示词

呈现一个客户问题、三步解决方案和可核实证据，最后以品牌名称收尾并使用克制的转场。
