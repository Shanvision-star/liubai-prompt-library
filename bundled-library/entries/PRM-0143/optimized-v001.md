# [Prompt Motion] Reflex 品牌节奏化技法展示

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：品牌宣传兼动效能力作品集。
- **分镜与状态**：原：钩子开场、技法序列、清晰终帧。
- **节奏与时间轴**：原：第一秒吸引注意，总长15秒。
- **形变／遮罩／运动**：原：字体、图形、镜头及色彩变化。
- **配色与排版**：原：强调自信、干净尾帧，未给品牌色。
- **工具与素材**：原：不默认旧工具最佳；未指定具体软件。
- **替换应用**：建议：替换品牌并统一所有技法的视觉识别。
- **验证点**：建议：检查首秒辨识、节奏与尾卡停留。
- **缺口**：缺口：品牌规范、音轨和画幅未提供。

## 原创复用提示词

围绕可辨视觉母题构建品牌作品片，经字体与图形变化推进，最终回到克制的品牌标识画面。
