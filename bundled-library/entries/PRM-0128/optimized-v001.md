# [Prompt Motion] 10秒产品动效展示

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：围绕指定链接制作作品集式视频。
- **分镜与状态**：建议：一个主张、一项演示、一个尾帧。
- **节奏与时间轴**：原：10秒；未给镜头时长。
- **形变／遮罩／运动**：建议：用局部放大强调核心功能。
- **配色与排版**：原：仅要求动态感，无配色字体约束。
- **工具与素材**：原：只有短链接，未指定制作软件。
- **替换应用**：建议：先核实产品和可公开素材。
- **验证点**：建议：确认短时长内产品价值可读。
- **缺口**：原：功能、品牌资料及成片规格未附；未测试。

## 原创复用提示词

把产品介绍压缩为一个益处、一次可见演示和清楚尾帧，并统一运动风格。
