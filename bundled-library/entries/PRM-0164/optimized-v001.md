# [Prompt Motion] 按时间计算的代码动画成片流程

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：以代码驱动动画并导出成片。
- **分镜与状态**：原：计算帧、浏览器捕捉、组装MP4。
- **节奏与时间轴**：原：状态由时间决定；未给时长帧率。
- **形变／遮罩／运动**：原：成片包含运动模糊。
- **配色与排版**：原：没有主题、配色和排版要求。
- **工具与素材**：原：HTML/JS、Chrome、Playwright、ffmpeg。
- **替换应用**：建议：用纯时间函数组织任意视觉场景。
- **验证点**：建议：抽查重复时间采样及声画对齐。
- **缺口**：原：无场景内容和编码参数；未测试。

## 原创复用提示词

将每个动画状态定义为时间函数，检查帧采样可重复，并在导出前记录渲染及音画同步设置。
