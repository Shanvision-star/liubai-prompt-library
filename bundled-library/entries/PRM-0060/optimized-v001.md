# [Prompt Motion] MotionSites百万月访问里程碑

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：展示上线8个月后的百万月访问里程碑。
- **分镜与状态**：建议：上线起点、增长进程、百万数字定格。
- **节奏与时间轴**：原：8个月是业务历程，非视频时长。
- **形变／遮罩／运动**：建议：用计数和路径增长表达阶段进展。
- **配色与排版**：建议：大数字为主，品牌标识为辅。
- **工具与素材**：原：未指定工具；访问量须由数据证实。
- **替换应用**：建议：换为自己的真实指标与日期。
- **验证点**：建议：区分月访问量、用户数和累计量。
- **缺口**：原：缺统计口径、总时长；未测试。

## 原创复用提示词

使用核实后的日期与指标设计里程碑短片，区分统计周期，并在尾帧保留清楚背景说明。
