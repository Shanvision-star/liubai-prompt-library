# [Prompt Motion] 网站产品的15秒动效短片

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：为网站制作动效展示。
- **分镜与状态**：建议：产品名、单一价值、操作反馈。
- **节奏与时间轴**：原：15秒；各段长度未定。
- **形变／遮罩／运动**：建议：从主视觉过渡到一个界面动作。
- **配色与排版**：建议：采用网站现有品牌规范。
- **工具与素材**：原：网站地址占位；工具未指定。
- **替换应用**：建议：替换网址后重新核对产品内容。
- **验证点**：建议：核对品牌和功能是否有依据。
- **缺口**：原：真实网址及界面素材缺失；未测试。

## 原创复用提示词

通过一个经核实的用户收益和一个界面动作介绍网站，以清晰品牌画面结束。
