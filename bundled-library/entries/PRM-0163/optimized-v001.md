# [Prompt Motion] 15秒以上自我宣传短片

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：自我宣传短片。
- **分镜与状态**：建议：身份、可验证能力、联系入口。
- **节奏与时间轴**：原：15秒以上；上限未指定。
- **形变／遮罩／运动**：建议：用一条视觉主线连接证据片段。
- **配色与排版**：建议：以姓名或品牌名建立层级。
- **工具与素材**：原：工具、素材均未指定。
- **替换应用**：建议：替换主体时重选能力证据。
- **验证点**：建议：检查宣传表述与实际能力相符。
- **缺口**：原：主体、脚本和规格缺失；未测试。

## 原创复用提示词

用清晰角色、一项可证明成果和简短结尾邀请介绍自己，保持统一视觉语言。
