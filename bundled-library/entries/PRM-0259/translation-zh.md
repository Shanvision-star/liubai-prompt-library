Motion Prompt #017

定义：下一个场景出现在逐渐扩大的形状内部。
示例展示：圆形或星形的“窗口”逐渐扩大，在其中露出下一个场景。
规格：
- 白昼场景 → 夜晚场景 → 白昼场景，每段 2.35 s；每个半周期的 0.45–1.6 s 进行切换，历时 1.15 s，采用三次 ease-in-out。
- 将下一个场景叠画在当前场景上，并用一个形状裁剪；形状扩大直至覆盖全画面。
- 白昼 → 夜晚：以太阳中心（112, 104）为起点的圆，半径从 0 扩至 470。
- 夜晚 → 白昼：以月亮中心（427, 104）为起点的五角星，外半径从 0 扩至 1150，扩大时同时旋转 1.2 rad，约 69°。
- 扩展过程中，形状边缘带有线宽为 7 的白色描边。
何时使用：用于以画面中的太阳、标志或按钮等对象为起点切换场景。
