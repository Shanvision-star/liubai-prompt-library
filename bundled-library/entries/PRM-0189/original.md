# [Prompt Motion] 手绘素材欢乐动效短片

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：高清、创意、俏皮愉快，尽量使用输入手绘。
- **分镜与状态**：建议：手稿出现、局部苏醒、共同动作、回到纸面。
- **节奏与时间轴**：原：未给片长；声音需匹配画面。
- **形变／遮罩／运动**：建议：保留笔触，用局部形变替代全图拉伸。
- **配色与排版**：原：强调输入手绘的真实感。
- **工具与素材**：原：JavaScript及本地示例路径；素材未提供。
- **替换应用**：建议：换入自己的手绘，并记录使用许可。
- **验证点**：建议：检查笔触一致、声画同步与原创性。
- **缺口**：原：缺输入图片与参考文件；未测试。

## 原创复用提示词

用克制的局部运动和匹配声音让原创手绘活起来，保留纹理并避免复制既有段落。
