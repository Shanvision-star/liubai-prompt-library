# [Prompt Motion] 令牌桶限流器的确定性 Canvas 图解

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：解释令牌桶限流器。
- **分镜与状态**：建议：令牌补充→请求取令牌→不足时拒绝。
- **节奏与时间轴**：原：每帧由时间决定；未给总长与帧率。
- **形变／遮罩／运动**：建议：以令牌数量和请求流同步表达状态。
- **配色与排版**：原：未指定配色；建议区分通过和受限状态。
- **工具与素材**：原：Canvas、不用库；已有截图渲染器上下文。
- **替换应用**：建议：替换容量与补充率演示不同负载。
- **验证点**：建议：同一时间重复求值应得到相同画面。
- **缺口**：原：未给容量、速率、请求序列及渲染器接口。

## 原创复用提示词

用确定性的时间状态可视化令牌桶，在明确的请求序列下清楚展示补充、消耗与拒绝。
