# [Prompt Motion] Ora 2：语音驱动的玻璃界面发布片

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：白底影像模型发布片。
- **分镜与状态**：原：拼贴→风格结果→情绪板→设置→标志。
- **节奏与时间轴**：原：22秒；图片按十六分音符切换，尾卡2秒。
- **形变／遮罩／运动**：原：缓慢推镜、逐词字幕、边缘折射玻璃。
- **配色与排版**：原：Geist、黑墨色、品牌渐变强调词。
- **工具与素材**：原：Canvas、Playwright、ffmpeg、ElevenLabs、Whisper。
- **替换应用**：建议：换自有输出示例与真实设置项。
- **验证点**：原：查闪跳、语音与音乐比例、转场缩放连续性。
- **缺口**：原：需图片、配音与音轨；建议先核素材授权。

## 原创复用提示词

用一个输入、变化的结果和可调控件展示影像工具，让字幕与已获授权的配音同步。
