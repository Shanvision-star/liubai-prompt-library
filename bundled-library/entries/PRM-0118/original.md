# [Prompt Motion] 徽章解锁与金色粒子庆祝

本公开版为整理者的原创复用方案与设计拆解；非网站提示词原文或逐句翻译，效果未实测。

## 设计思路拆解

- **目标画面**：原：精确复现解锁界面，只添加动效。
- **分镜与状态**：原：建立徽章场景，再释放金色粒子。
- **节奏与时间轴**：原：快速流畅，不要弹跳。
- **形变／遮罩／运动**：原：实体3D徽章随光标物理式倾斜。
- **配色与排版**：原：沿用Figma素材、光照、字体和布局。
- **工具与素材**：原：依赖链接Figma帧，软件未限定。
- **替换应用**：建议：替换徽章标识并保留视觉层级。
- **验证点**：建议：检查倾斜幅度、遮挡和基准设计。
- **缺口**：原：Figma帧未提供，互动与视频导出未分；未测试。

## 原创复用提示词

为现有奖励界面加入克制的立体倾斜与短暂庆祝粒子，保持布局并避免多余弹跳。
