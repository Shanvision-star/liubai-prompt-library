# 留白学习路线

先完成一个小练习，再选择下一条。这里的解释和对照属于 AI 教学分析；没有把文字检查当成生成效果证明。

1. [令牌桶图解：先算清，再画清](/?entry=PRM-0218&tab=analysis)。读事件表，自己算一次拒绝请求后的余额，再核对参考解答。
2. [Git 中文讲解：让一个动作对应一个状态](/?entry=PRM-0084&tab=analysis)。先画出修改、暂存、提交的区别，检查每一步输入与结果。
3. [卡片时序：区分开始、持续与错峰](/?entry=PRM-0016&tab=analysis)。写出三层元素的起止时间；只改错峰间隔，预测阅读顺序如何改变。
4. [界面连续变形：跟踪同一个对象](/?entry=PRM-0013&tab=analysis)。列状态、触发和身份线索，区分动作连续与含义连续。
5. [响应式适配：用任务核对屏幕变化](/?entry=PRM-0008&tab=analysis)。选择一项真实任务，分别检查小屏阅读、触控与键盘路径；模拟视口不等于真机验收。
6. [界面加固：给失败状态设计恢复动作](/?entry=PRM-0009&tab=analysis)。检查空结果、长文本和重复提交，写出用户下一步能做什么。
7. [声音叙事：通过可听事件建立因果](/?entry=PRM-0221&tab=analysis)。先列可见动作和对应声音，检查没有对白时是否仍能理解变化。

每次留下四项笔记：原文已有要求、自己的推断、只改一个变量的对照、真实结果或尚未验证。实际制作由使用者自己的工具与模型执行；未运行时状态保持 untested。
