# Motion Prompt #064｜分页 · Pagination

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 页码标记的位移体现页序，内容在透明度最低时替换，避免旧新行文字叠加。
- 列表变化与页码变化是独立但相关的过渡，真实网络加载应优先表达实际状态。

## 实现思路

- 网页用分页导航及aria-current标记当前页；数据更新可采用淡出→替换→淡入。
- 不要用固定淡入时间掩盖请求尚未完成；处理加载、空页、错误及返回上一页的滚动位置。

## 建议检查点

- 1→2和2→3位移44 px，3→1位移88 px，每次0.2 s。
- 内容只在透明度低点更换，没有两页文字重叠。
- 真实点击后的当前页与实际数据页一致，不能标记新页却展示旧数据。
