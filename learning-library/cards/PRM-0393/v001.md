# Motion Prompt #151｜回到顶部按钮 · Back-to-top button

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 只在离开顶部后出现，减少初始页面噪声；橙色圆形将返回动作与正文区分。
- 出现由滚动距离驱动，点击返回由时间驱动，两者不应混成一个不可交互循环。

## 实现思路

- 实际网页按钮调用平滑滚动，透明度和位移依据scrollY计算；给按钮明确可访问名称。
- 用户启用减少动态效果时可直接返回顶部；需处理滚动中用户再次操作导致的中断。

## 建议检查点

- 80–140 px区间完成淡入和10 px上移，位置最终(472,138)。
- 点击后0.6 s到scrollY=0，而不是只滚到按钮出现阈值。
- 悬停颜色在0.2 s内变深，回到顶部按钮隐藏且不占键盘焦点。
