# Motion Prompt #052｜折叠面板 · Accordion

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 高度变化参与布局，而非覆盖后续行，因而能看清内容属于哪个标题。
- 箭头转角和内容高度同用ex，状态指示与实际展开量连续对应。

## 实现思路

- 网页可用details/summary或按钮+受控区域，再用测量高度或网格行实现展开；不要仅scaleY拉伸文字。
- 真实组件添加aria-expanded并按内容高度计算目标，不把示例92 px当所有正文的固定高度。

## 建议检查点

- 展开后第一行92 px，下方行同步下移58 px。
- 展开中正文不越出裁切区域；完全展开箭头恰为180°。
- 3.62 s回到34 px且正文隐藏，不残留空白。
