# Motion Prompt #165｜动态形状分隔线 · Animated shape divider

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 双层不同透明度形成浅层纵深，前层与白底融合而不是一条独立描边。
- 每层内部反向波相加让轮廓持续变形，区别于整张波形图片水平平移。

## 实现思路

- Canvas或SVG可逐点求和生成封闭路径；真实页面应与区块背景连接，避免底边出现透明缝隙。
- 低性能或减少动态效果模式可冻结在代表帧，但仍保留两层色差和柔和边界。

## 建议检查点

- 后层中心y=100、前层y=110，后层alpha0.45。
- 波长和振幅按四组数值保留，不把两层做成同一波形。
- 4.7 s首尾连续，前波与下方白区无接缝。
