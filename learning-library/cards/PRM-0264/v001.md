# Motion Prompt #022｜扫光 · Light sweep

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：光移动而物体不动，把注意集中在表面材质而非物体位置。
- 分析：宽柔光与细亮线构成主次，末尾角星将视线收束到扫光终点。

## 实现思路

- Canvas 2D 使用 clip + gradient；网页可在 overflow:hidden 的徽章内移动倾斜渐变伪元素。
- 光带应按徽章圆角裁剪，不能从圆角外漏出；角星可单独绘制在顶层。

## 建议检查点

- 徽章全程固定，只有光带和右上四角星在变化。
- 光带在 0.45–1.5 s 完成 660 px 位移，徽章外看不到光带泄漏。
