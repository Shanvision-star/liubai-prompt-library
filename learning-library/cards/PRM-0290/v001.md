# Motion Prompt #048｜L 型剪辑 · L-cut

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：声音保留上一场景的情绪与语义连续性，画面可以自由转向反应或补充信息。
- 分析：与 J-cut 的区别是音频切换在后，而不是所有声音都要淡出得更慢。

## 实现思路

- 官方 Canvas 2D 是声画时间线示意；在剪辑软件中保留 A 音轨，让 B 画面先进入，0.72 s 后再切 B 音轨。
- 真实制作中应检查 A 语句是否完整、B 环境声是否自然接入，不能只按示例延迟量机械截断对白。

## 建议检查点

- 约 2.38–3.10 s 期间，画面标签为 B、声音标签仍为 A。
- B 音频入点比 B 画面晚 0.72 s；有实际音轨的交付还应听检对白或环境声连续性。
