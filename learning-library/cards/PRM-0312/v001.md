# Motion Prompt #070｜加载转圈 · Spinner

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 旋转弧表达不确定等待，不显示虚假的百分比；勾号明确标识状态结束。
- 完成反馈与加载反馈在2.95 s附近交接，减少空白无响应的间隙。

## 实现思路

- CSS/SVG可绘制圆环并旋转，成功图标另用缩放与透明度；实际状态应由请求结果而非固定2.95 s触发。
- 另补错误和超时状态；若白罩阻止交互，应明确忙碌状态并防止重复发送。

## 建议检查点

- 弧长243°，转速468°/s，不误做成整圈无缺口。
- 只有请求成功才切到勾号；失败必须有不同反馈。
- 结束后遮罩与加载层彻底移除，不能留下不可点击页面。
