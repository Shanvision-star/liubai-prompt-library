# Motion Prompt #134｜中继器 · Repeater

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 副本从上一槽位过渡到新位置，让数量增加有生成过程而非整圈突然出现。
- 整体转动和副本错相缩放叠加，分别提供全局方向和局部韵律。

## 实现思路

- Canvas/SVG可共享一个形状并按极坐标变换；AE Repeater可复现结构，但新增副本的进场仍需额外控制。
- 将副本计数、槽位过渡和脉动相位分开计算，避免数量变化时所有相位重置。

## 建议检查点

- 1.7 s达到12份，4.45 s退回1份。
- 相邻槽位30°，副本朝外且原始副本有白描边。
- 环每4.7 s转一圈，缩放脉动每周期两次并逐份错相0.55 rad。
