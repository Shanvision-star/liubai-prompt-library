# Motion Prompt #034｜手持镜头 · Handheld

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：多频率小幅叠加比单一正弦摇摆更不规则，但仍具有可重复的确定性。
- 分析：主体静止，所有晃动来自相机，区别于主体颤抖或画面中的物体各自乱动。

## 实现思路

- Canvas 2D 参考按时间计算多个旋转轴；三维相机可直接叠加这些角度，二维后期可近似平移与旋转但缺少真实透视变化。
- 预留安全裁切边缘，并在网页中为减少动态效果偏好提供静态版本。

## 建议检查点

- 震动保持小幅，三个角度分别不超过所列约量级，不能变成大范围摇晃。
- u=0 与 u=4.7 s 的姿态一致，循环接缝不跳变。
