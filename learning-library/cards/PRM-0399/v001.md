# Motion Prompt #157｜悬停图片预览 · Hover image reveal

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 照片由条目决定、位置由指针决定，信息归属和交互跟随是两个独立维度。
- 名称右移与箭头变色先标明选中了哪一行，避免浮动图片遮住后失去对应关系。

## 实现思路

- DOM浮动预览层通常设pointer-events:none，防止图片遮挡后意外触发离开行。
- 预加载图片并限制垂直位置；原例仅说明垂直防溢出，真实窄视口还需加水平避让。

## 建议检查点

- 照片始终对应当前行，切换行时旧图淡出而非骤换。
- 图像在光标右26 px，垂直不超窗口，跟随无延迟。
- 名称右移8 px并变橙，离开0.25 s后复原。
