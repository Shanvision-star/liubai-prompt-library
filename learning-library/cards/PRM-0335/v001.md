# Motion Prompt #093｜平滑滚动 · Smooth scroll

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 目标位置扣除固定页头高度，确保节标题不会被导航遮住。
- 菜单高亮和回顶按钮随真实滚动位置变化，形成定位与返航两条线索。

## 实现思路

- 实际页面使用锚点、scroll-margin-top或计算滚动目标；需允许用户中断平滑滚动。
- 低动态偏好可改为即时跳转，仍应保留哈希地址和键盘焦点逻辑。

## 建议检查点

- 最终scroll=296 px，价格区顶部在页头下方，而非被遮住34 px。
- 回顶按钮在60–100 px之间淡入；回到顶部后正确隐藏。
