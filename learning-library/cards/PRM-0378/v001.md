# Motion Prompt #136｜线条抖动 · Line boil

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 抖动发生在线条控制点而非整幅图的位置，因此画面稳定但轮廓活跃。
- 二次曲线连接中点保留笔触圆滑，避免随机偏移造成尖锐折线。

## 实现思路

- Canvas按离散帧号和控制点索引产生确定偏移；SVG可预计算若干路径姿态切换。
- 不要用整体translate抖动代替线条沸腾，也不要逐显示帧重新随机导致导出不可复现。

## 建议检查点

- 4.7 s内47个线条状态，图形中心和整体布局不漂移。
- 控制点偏移不超±3.5 px，线端保持圆头。
- 相同帧号重复渲染完全一致，云轮廓仍由96点构成。
