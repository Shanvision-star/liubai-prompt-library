# Motion Prompt #082｜悬停图片放大 · Image zoom on hover

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 图像内部变化而容器稳定，既增加关注度又不扰乱网格布局。
- 中心缩放与圆角裁切形成像镜头靠近的局部观察效果。

## 实现思路

- DOM结构分离固定外框和img变换层，外框overflow:hidden，图片transform:scale。
- 预留足够图像分辨率，放大后检查主体未被裁切掉；避免同时缩放文字。

## 建议检查点

- 到位缩放1.15，容器仍为222×118、标题位置不变。
- 圆角外没有图像溢出，0.5 s可平稳回到1。
