# Motion Prompt #010｜过冲回弹 · Overshoot

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：黄色目标刻线和珊瑚色超出区分开表达目标与过冲，避免把最高值误认为最终值。
- 分析：衰减振荡表现惯性；回零也略微越过零，保持同样的物理性格。

## 实现思路

- Canvas 2D 中将 value 映射为圆弧角度；SVG 也可使用弧路径与旋转指针。
- 实际仪表应用须把动画显示值与真实测量值分开；若业务不能显示负值，可在展示上限制范围，但应记录为对原规格的修改。

## 建议检查点

- 目标位置固定在扫过范围 0.7，指针确实越过它再回稳，而非只减速到达。
- 3.7 s 后使用回零曲线，最终为 0，且衰减幅度持续收敛。
