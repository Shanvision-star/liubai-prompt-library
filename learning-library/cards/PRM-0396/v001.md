# Motion Prompt #154｜聚光灯悬停 · Spotlight hover

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 内部白光与边框橙光分层处理，既照亮内容又通过邻边发光显示卡片群关系。
- 光不跨出卡片轮廓，因此这是局部表面照明，不是整页跟随的手电筒遮罩。

## 实现思路

- 真实网页可用CSS变量分别驱动背景径向渐变和边框遮罩；坐标需转换为每张卡片局部坐标。
- 监听器只更新坐标，避免每次指针移动重排布局；按原例不要加平滑滞后。

## 建议检查点

- 白光半径115 px，橙色边光半径120 px，中心与光标重合。
- 内部光不会泄漏到卡片外，远边保留8%白线。
- 快速移动时无可见拖尾或追赶延迟。
