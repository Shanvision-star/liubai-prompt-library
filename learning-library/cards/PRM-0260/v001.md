# Motion Prompt #018｜图形转场 · Shape transition

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：真正的剪切藏在条带完全盖住画面的瞬间，观众看到的是连续的图形运动。
- 分析：四带交错保留节奏，同时避免整块矩形一齐平移的生硬感。

## 实现思路

- Canvas 2D 可分别计算前缘和后缘位置；剪辑软件可将四条带作为遮挡层，把场景切点置于 1.0 s。
- “覆盖”和“揭开”是两个阶段，不应简单用同一个短条从左穿过而留下未遮盖的缝。

## 建议检查点

- 1.0 s 时整幅画面被四带完全遮挡，底层场景切换不可见。
- 揭开于 1.12 s 才开始，各带延迟仍为阶段的 14%，第二次切换方向反转。
