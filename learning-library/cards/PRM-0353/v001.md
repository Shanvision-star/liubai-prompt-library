# Motion Prompt #111｜色差 · Chromatic aberration

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 通道缩放而非全局平移使中心近乎无色边、外缘逐渐增大，符合本例的径向分离逻辑。
- 不同通道仍从同一源图重合，轮廓内容不应生成三个互不相关的物体。
- 源文口径差异：英文定义写红／蓝紫色边，画面摘要写红／青色边；这里分别忠实保留，没有替作者统一。复现时应以本条规格与固定版本代码为准。

## 实现思路

- Canvas可离屏分离RGB通道并加法叠加；着色器可按各通道不同UV尺度采样。
- 生产调色宜控制强度以免损害文字可读性；不要把色差效果当成修复画质。

## 建议检查点

- 中心红蓝边缘保持重合，画面两侧差约11 px。
- 最终红/绿/蓝尺度分别1.04/1.02/1，没有整体位置漂移。
