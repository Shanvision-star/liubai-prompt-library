# Motion Prompt #127｜往返循环 · Ping-pong loop

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 后半段反用同一个进度，确保返回路线和旋转都是原动作倒放，而非另做一次相似运动。
- 播放条把抽象的往返时间可视化，颜色切换明确区分正放与倒放。

## 实现思路

- Canvas可用三角波进度g驱动全部属性；CSS/SVG采用alternate时仍需保证残影按当前方向延时。
- 不要只反转x坐标而让旋转继续正转，否则失去真正倒放感。

## 建议检查点

- 2.35 s到右端447，4.7 s回左端92。
- 同一g值在前进、后退时主体姿态相同，旋转随返回撤销。
- 三段拱形轨迹和四个残影均可辨识，循环无跳切。
