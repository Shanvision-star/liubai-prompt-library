# Motion Prompt #037｜慢动作 · Slow motion

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：人物和叶片都被同一慢时间支配，环境运动证明是整体慢放而不是人物单独慢动作。
- 分析：跳前与落地后静止构成动作边界，使延长的腾空过程仍然有清楚的开始与结束。

## 实现思路

- Canvas 2D 参考直接拉长动作时间；真实素材慢放需足够采集帧率或接受插帧伪影风险。
- 右上角 120fps 是示意标签，不证明某份实际素材真的以 120fps 拍摄；制作说明应区分模拟与实拍。

## 建议检查点

- 人物 0.5 s 起跳、4.3 s 落地，最高 1.1 m，双臂在空中举起。
- 九片叶片同样缓慢下落，并在 4.7 s 循环处保持连续。
