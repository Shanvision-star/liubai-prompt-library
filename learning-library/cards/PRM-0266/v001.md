# Motion Prompt #024｜冲击震动 · Impact shake

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：板、背景物体、灰尘与整幅画面依次响应同一次撞击，使冲击像在场景中传播。
- 分析：不同频率的横纵震动和指数衰减，比持续等幅左右摇摆更接近短时冲击。

## 实现思路

- Canvas 2D 参考可在绘制所有场景内容前施加全局震动变换，板自身仍保留独立落地与压扁时间轴。
- 若在 DOM 实现，给整个场景容器施加 shake、给标题板施加 squash；确保裁剪或扩大背景以防震动露出空白边缘。

## 建议检查点

- 0.62 s 着地才开始全局震动，背景方块比着地晚 0.03–0.06 s 响应。
- 震动在 1.1 s 内指数衰减；板脚底固定，压扁后恢复，1.85–2.2 s 按规定上移退场。
