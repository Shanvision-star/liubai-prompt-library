# Motion Prompt #184｜大特写 · Extreme close-up

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 示例通过固定机位的变焦收紧景别，不是把摄像机真正推向人物；这决定了透视关系保持不变。
- 以眼睛为中心让情绪细节稳定地成为终点，背景逐步被排除而非突然切走。

## 实现思路

- Canvas/3D使用指数形式焦距轨道，锁定相机位置与目标眼睛；直接线性缩放可近似但需声明偏离参考。
- 生成视频提示词宜明确固定位置、缓慢变焦至眼部极近特写；脸部一致性与眼睛结构需人工检查。

## 建议检查点

- 焦距按f = 610 × (2040/610)^p变化，3.4 s达到2040 px。
- 相机位置保持不动，目标右眼持续位于中心附近。
- 末帧只留双眼为主体，树木建筑离开画面而非焦点切回背景。
