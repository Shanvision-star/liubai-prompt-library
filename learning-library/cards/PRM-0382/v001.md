# Motion Prompt #140｜翻页转场 · Page curl

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 翻起部分是原页面关于折线的镜像，因此角部轨迹与纸背形状存在几何一致性。
- 纸背投影和折线渐变阴影分担悬浮与折痕深度，不是单一斜向擦除。

## 实现思路

- Canvas/SVG可按折线做多边形裁切与反射变换；3D软件也可用折页网格，但应对照同一折线轨迹。
- 替换页面内容时需区分正面、纸背和底页，不能把镜像正面当成未经设计的背面文字。

## 建议检查点

- 从右下角启动，沿归一化(−1,−0.42)方向推进600 px。
- 翻片具有2 px白边和(4,4)投影，折线另有50 px渐变阴影。
- 1.75 s切换完成，不残留旧页碎角。
