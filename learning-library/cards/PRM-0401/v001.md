# Motion Prompt #159｜实时校验 · Inline validation

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 边框、背景、图标与文字共同表达状态，错误与成功不仅是颜色不同。
- 示例用固定字符阶段演示验证，并非完整邮箱校验算法；逐字报错是否合适需按真实表单情境决定。

## 实现思路

- 真实网页应把视觉状态绑定实际校验结果，并通过描述关联/实时区域传达错误；不能按字符数16判断有效。
- GSAP elastic.out(1, 0.3)在规格中是缓动名称；原库Canvas实现不要求安装GSAP，其他技术可按对应曲线采样。

## 建议检查点

- 错误色#E5383B与#FFF1F1，成功色#1E9E5A，状态文字和图标同步。
- 成功勾圆半径11，采用给定弹性缓动而非普通淡入。
- 删除开始即撤下提示；真实实现分别验证有效、无效、空值和输入法中间态。
