# Motion Prompt #173｜斯坦尼康 · Steadicam

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 小幅低频正弦摆动保留人的行走质感，但排除手持式高频随机抖动。
- 相机位移、环境重复间距和摆动整数周期共同保证无缝循环，不只靠首尾交叉淡化。

## 实现思路

- Canvas/3D采用确定性的正弦时间函数，各个摇摆轴分开驱动；不要运行时随机加抖动。
- 实拍对应稳定器跟拍；生成视频强调稳定前进与轻柔低频摆动，只能作为风格目标，非精确姿态保证。

## 建议检查点

- 人物始终约在前方5 m，摄像机不在首尾加速减速。
- 4.7 s处树阵、网格、步态和摇摆相位与起点一致。
- 高度摆幅3.5 cm、横向摆幅5 cm，不出现明显高频抖动。
