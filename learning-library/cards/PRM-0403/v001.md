# Motion Prompt #161｜视图过渡 · View transition (shared element)

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 照片是跨页面的连续锚点，其他内容可以更换而不丢失对象身份。
- 列表淡出与详情淡入只在末段短暂重叠，照片运动始终承担主要连续性。

## 实现思路

- 真实网页可使用View Transitions API与相同view-transition-name；需另行实现路由、返回和不支持API时的回退。
- Canvas参考只是演示转场外观和URL变化，不能据此声称已具有真实页面导航功能。

## 建议检查点

- 同一照片从143×80变为479×94，圆角6→8，无换图闪烁。
- 前进与返回各0.6 s；返回精确落回中间列表槽位。
- 路由在转场50%时对应切换，浏览器返回与视觉方向一致。
