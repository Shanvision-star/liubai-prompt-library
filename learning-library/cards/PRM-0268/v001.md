# Motion Prompt #026｜垂直摇镜头 · Tilt

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：由地面人物到高塔顶部形成尺度参照，运动本身也承担揭示信息的顺序。
- 分析：机位高度不变，只改变视线方向，和 crane up 的升高机位是不同动作。

## 实现思路

- Canvas 2D 参考可移植为三维相机 pitch 动画；不能用相机向上平移代替。
- 若为真实拍摄或生成模型写提示，应明确“固定机位、向上仰摇、人物离开下沿、塔顶进入”，数值则作为方向性参考而非生成保证。

## 建议检查点

- 相机高度始终 1.4 m，俯仰从 −0.06 到 +0.36 rad。
- 主体向下离开，塔顶从上部进入，且停留阶段仍维持最终仰角。
