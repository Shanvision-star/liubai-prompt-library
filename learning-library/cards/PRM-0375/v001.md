# Motion Prompt #133｜文字遮罩 · Text mask

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 粗字重提高字内可用画面面积，外部低透明度背景则给遮罩里的局部景象提供上下文。
- 临近结尾的全景揭示让观众从文字形状过渡到完整场景，不只是静态图片填字。

## 实现思路

- Canvas复用离屏画布和source-in；网页可考虑SVG mask，视频软件可用文字轨道遮罩。
- 替换文案后必须重新测量宽度；扩大画布时同步提高离屏分辨率，避免字内画面变软。

## 建议检查点

- 文字总宽不超过500 px，字号按2 px步长调整。
- 字内海景持续运动，外部在普通阶段仅12%可见。
- 3.85 s外部达到100%，4.65 s回12%；白色描边保持4 px。
