# Motion Prompt #029｜跟拍 · Tracking shot

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：主体相对画面稳定，环境的分层移动承担速度表达，因此主体动作容易看清。
- 分析：匀速而非缓动匹配持续行走；示例并非所有背景都无缝循环。

## 实现思路

- 三维实现让人物与相机共享水平位移，场景物体保持世界坐标固定；Canvas 2D 可按深度投影计算。
- 若交付要求无缝循环，需要另行设计建筑与树的周期布局；不能把参考现有的跳变当作渲染故障，也不能声称原样无缝。

## 建议检查点

- 人物保持居中且四肢摆动，柱子相对背景移动更快。
- 相机横移全程无缓入缓出；循环边界需明确记录树与建筑的跳变。
