# Motion Prompt #036｜荷兰角 · Dutch angle

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：重点是倾斜后保持的构图，而不只是转动过程；停留时长让失衡感成立。
- 分析：所有物体同角度倾斜，表明是摄影机滚转，而不是建筑或人物自身歪倒。

## 实现思路

- Canvas 2D 或二维剪辑可绕中心旋转整幅图像；三维实现仅更新 camera roll。
- 旋转会暴露边角，应扩展背景或安全裁切，但不要通过不同物体独立旋转来补洞。

## 建议检查点

- 0.6–2.2 s 转至约 21°，并保持至 4.2 s。
- 地平线、人物和建筑保持相同滚转角，画面边角不出现未填充空白。
