# Motion Prompt #116｜双色调 · Duotone

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 双调通过亮度映射保留原图的明暗结构，不是把画面左右分别染成两种颜色。
- 指数2.4改变中间调分配，让浅亮区域之间仍有可见色阶。

## 实现思路

- Canvas或着色器可用亮度计算t并在两端色之间插值；照片软件可用渐变映射近似。
- 输入亮度越界时的截断应核对源代码；不要仅凭文字公式对负底数做非整数幂而产生无效值。

## 建议检查点

- 暗部趋向#1F2A5C，亮部趋向#FF9FB2，物体层级不被抹平。
- 所有映射值有效且无黑块、NaN或越界异常颜色。
