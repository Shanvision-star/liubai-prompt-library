# Motion Prompt #145｜滚动时间轴 · Timeline on scroll

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 线头固定在视口内的126 px触发线，页面运动让各事件依次到达，而不是按固定时间盲目播放。
- 填点、年份和正文同时激活，清楚表达已走到哪一阶段；反滚动可逆保留因果关系。

## 实现思路

- Canvas参考把滚动量脚本化；真实网页应由scroll position驱动SVG路径或渐变轨道，并计算每个节点的22 px激活进度。
- 保留正常文本语义和可读顺序，不应为了揭示动画永久隐藏尚未触发的关键信息。

## 建议检查点

- 线头在视口中始终y=126，五节点页面坐标准确。
- 每节点越过后22 px内完成内圆0→4及文字右移16 px的入场。
- 向上滚动按同一进度撤销，不累积已经激活的状态。
