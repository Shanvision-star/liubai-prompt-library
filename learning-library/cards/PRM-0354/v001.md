# Motion Prompt #112｜暗角 · Vignette

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 边缘渐暗压低周边竞争，同时保留中央主体原有亮度。
- 椭圆比例适配横幅画面，避免普通正圆暗角只压住左右而忽略上下。

## 实现思路

- Canvas用椭圆径向渐变或缩放上下文绘制蒙版；图像编辑可用羽化椭圆暗角。
- 中心应与构图主体关系协调，非居中主体可另调整中心，但必须标为对原例的修改。

## 建议检查点

- 334 px水平半径的内45%不被压暗。
- 角部平滑过渡至最高70%，不出现硬边或全画面统一变暗。
