# Motion Prompt #138｜百叶窗转场 · Blinds transition

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 条带同步开合把一次全屏揭示拆成七个局部揭示，产生百叶窗节奏。
- 画面内容本身不位移，便于观看者比较同一位置的前后变化。

## 实现思路

- Canvas或SVG用七个裁切矩形揭示新图；CSS可用分片容器，但所有片应对齐同一完整场景坐标。
- 不可把每条图像分别缩放到条带内，条带只是遮罩而非七张独立缩略图。

## 建议检查点

- 七条均在0.4 s开始，1.65 s同时完全打开。
- 开口从各条顶部向下扩大，无交错延迟。
- 新旧画面全程固定，条带边界没有错位。
