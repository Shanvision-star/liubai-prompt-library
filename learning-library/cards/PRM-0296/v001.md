# Motion Prompt #054｜文字提示 · Tooltip

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 无点击的悬停反馈保持操作轻量；短延迟减少光标掠过时的无谓闪现。
- 小幅上移和指向三角建立说明与图标的归属，不能当成可操作弹窗。

## 实现思路

- DOM实现可用定位浮层和opacity/translateY；同样应在键盘focus时显示，不仅响应鼠标。
- 说明内容不应承载必须点击的按钮；移动端需提供不依赖hover的替代说明。

## 建议检查点

- 没有任何点击动作也会出现；1.35 s到最终位置。
- 3.45 s气泡完全隐藏，箭头仍指向图标而非标签。
- 键盘聚焦可读说明，离焦后隐藏。
