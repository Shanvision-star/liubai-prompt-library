# Motion Prompt #090｜懒加载 · Lazy loading

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 保持占位尺寸避免图像到达后布局跳动；首排预加载与下排按需加载区分优先级。
- 列间短延迟展示资源陆续到达，而不是所有图片同时切换。

## 实现思路

- 真实网页可用loading=lazy或IntersectionObserver触发请求，onload后淡入；延时应来自实际加载而非强迫等待0.45 s。
- 生产环境通常缓存已加载图片，不应照搬演示中回滚后卸载重置；设置宽高或aspect-ratio。

## 建议检查点

- 第一排无需重新等待；后排进入168 px边界才触发。
- 图片淡入前后151×92占位尺寸不变；失败状态不能永久旋转。
