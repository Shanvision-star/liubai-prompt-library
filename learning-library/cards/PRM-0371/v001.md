# Motion Prompt #129｜文字乱码效果 · Text scramble

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 随机变化与单向锁定构成信息逐步确定的过程，而非整词同时闪烁。
- 黄色短暂强调新锁定字母，底部状态线进一步说明已完成与即将完成的位置。

## 实现思路

- Canvas或DOM均可按离散时间选择随机字符，但应使用确定性种子以保证逐帧输出稳定。
- 使用等宽字槽固定布局；更换品牌文案时按字符数重新计算槽位与总时长，勿沿用五字假设。

## 建议检查点

- 锁定间隔0.18 s，最后一位1.17 s锁定。
- 锁定后黄色维持0.22 s再变白；没有I或O出现在随机字符池中。
- 退出按右到左解除锁定，不是同时清空。
