# Motion Prompt #001｜弹性入场 · Pop-in

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：先让主体出现、再让角标出现，建立主次关系，而不是两个元素同时争夺注意。
- 分析：缩放与旋转使用不同衰减弹簧，产生有弹性但不完全同步的回稳；阴影被限制在 0–1，避免跟随过冲夸张膨胀。

## 实现思路

- 参考是时间驱动的 Canvas 2D 绘制；移植到 DOM/CSS 或 Remotion 时可把两个弹簧函数分别用于 scale 和 rotate，角标使用独立的局部起始时间。
- 若改用动画库的默认 spring，需要对照峰值和回稳时间调参，不能把任意弹簧预设当成同一效果。

## 建议检查点

- 图标在 0.28 s 启动，角标在 0.62 s 才启动，且角标相对主体固定在右上。
- 图标峰值约 1.26，旋转最终回到 0；退场在 1.86–2.12 s 先鼓起后归零。
