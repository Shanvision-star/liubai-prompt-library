# Motion Prompt #155｜悬停切换图片 · Image swap on hover

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 仅照片变化、其他信息锚定，用户仍可比较价格与名称，不因预览打乱列表。
- 整卡触发避免指针从图片移到标题时预览突然复位。

## 实现思路

- DOM以两张预加载图片叠放并交叉改变opacity，卡片统一处理hover/focus。
- 移动端需要显式换图入口，不能只依赖hover；图片替换前确保尺寸一致防止布局跳动。

## 建议检查点

- 0.3 s完成正反面交叉淡化，无瞬时白屏。
- 指针位于商品名称上仍显示背面。
- 圆点状态与照片一致，名称、价格和图片框均不位移。
