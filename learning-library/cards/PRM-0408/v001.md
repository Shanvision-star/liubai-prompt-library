# Motion Prompt #166｜点赞动画 · Like button animation

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 按压预缩、弹起过冲和粒子释放构成触感链条，计数同步把动作与数据结果联系起来。
- 撤销仅轻缩且无粒子，视觉强度低于添加，避免把取消也误表现为庆祝。

## 实现思路

- 真实网页可用SVG心形、独立粒子层与DOM计数；0.1 s预压适合绑定pointerdown而非预知未来点击。
- 如采用乐观计数更新，需在请求失败时回滚状态；演示计数不代表已经保存到服务器。

## 建议检查点

- 点赞从0.78×到1.45×用0.12 s，之后按阻尼公式收敛。
- 六粒子方向完整，红环半径15→33，计数128→129。
- 撤销回128与空心，无粒子，最低缩放0.84×。
