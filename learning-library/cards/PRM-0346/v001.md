# Motion Prompt #104｜蓝调时刻 · Blue hour

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 冷环境与暖人工光建立色彩对比，是蓝调时刻的主要辨识点。
- 太阳先降落再消失，灯光浮现与环境转暗相互补充。

## 实现思路

- Canvas按效果进度控制太阳的高度及透明度；照片合成分别调整环境蓝调和窗灯暖色，避免全图统一染蓝。
- 真实时刻依地点季节而变，18:35只是此示例读数；生成模型不保证准确天文状态。

## 建议检查点

- 效果80%后太阳不可见，窗灯仍呈琥珀色。
- 顶部和地平线附近保留两层不同蓝色，人物比背景更暗。
