# Motion Prompt #025｜水平摇镜头 · Pan

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：核心是固定机位的转向，不能与横向移动机位的 tracking 混为一谈。
- 分析：人物向左滑动而镜头向右转，显示了镜头坐标与画面运动方向相反的关系。

## 实现思路

- 官方参考是 Canvas 2D 投影示意；三维引擎可固定 position，只插值相机 yaw。
- 此示意强调同角度变化；真实透视下同角度不应简单理解为画面所有位置都具有完全相等的像素平移。

## 建议检查点

- 相机位置和焦距不变，只在 0.5–3.4 s 改变 yaw。
- 角度读数从 −18° 到 +18°；不存在由机位平移引起的近景相对远景加速掠过。
