# Motion Prompt #175｜固定镜头 · Locked-off shot

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 近处人物与远处汽车反向运动，强化固定背景与运动主体的对比。
- 锁定机位不是冻结画面：背景投影不动，但步态与交通持续进行。

## 实现思路

- Canvas或3D将相机矩阵固定，只更新人物和汽车；后期合成以同一稳定背景层为基准。
- 不能添加常见的自动推近、手持摇晃或Ken Burns缩放；这些都会破坏Locked-off定义。

## 建议检查点

- 固定背景上的任意地标在整个4.7 s内坐标不变。
- 人物左向右、汽车右向左，且人物和车均从画面外进出。
- 循环点没有主体瞬移出现在画面中央，也没有相机抖动。
