# Motion Prompt #098｜轮廓光 · Rim light

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 双侧亮缘建立物体边界，而大面积暗部保留体积的剪影感。
- 与逆光示例的暖雾不同，这里重点是定向边缘分离，背景不需要被整体照亮。

## 实现思路

- Canvas参考通过偏移形状副本模拟边缘；实际合成应以边缘蒙版控制亮部，而非给整个主体加外发光。
- 摄影/三维中可用后侧轮廓灯验证两侧边界；生成模型只接受方向和视觉目标，不承诺±135°精确物理灯位。

## 建议检查点

- 人物中央维持暗色，亮边集中在左右头肩外缘。
- 平面图、±135°读数和画面双侧亮边对应。
