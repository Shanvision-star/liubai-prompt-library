# Motion Prompt #044｜交叉溶解 · Cross dissolve

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：两幅画面有一段共存时间，因此比硬切更适合连续、回忆或时间流动的感觉。
- 分析：下层保持不透明可避免中间透明度同时降低而露出黑底。

## 实现思路

- Canvas 2D 先绘 A，再以 alpha 绘 B；CSS 可将 B 叠在 A 上，仅动画 B 的 opacity。
- 真实剪辑需检查两镜头中间重叠时的构图与明度，避免关键人物或文字形成难读的重影。

## 建议检查点

- 2.25 s 上层 B 的 alpha 为 0.5，底层 A 仍完全不透明。
- 1.5 s 前只有 A、3.0 s 后只有 B，过程无意外黑场或透明背景。
