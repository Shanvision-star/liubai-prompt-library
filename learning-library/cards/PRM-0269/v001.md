# Motion Prompt #027｜推镜头 · Dolly in

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：固定焦距但改变距离，使不同深度的物体呈现不同倍率变化，这才是推轨镜头的空间感来源。
- 分析：用柱和石头作为近景参照，让观众清楚看出相机真的穿过空间。

## 实现思路

- 官方 Canvas 2D 参考通过投影示意相机前移；三维实现应动画相机位置而保持 focal length 不变。
- 只有一张照片时普通 scale 无法恢复遮挡变化；可用分层深度近似，但应标为 2.5D 改编而非真实 dolly。

## 建议检查点

- 机位前移 5.8 m，人物大小约为初始 3.6 倍，而焦距读数仍为 24mm。
- 前景柱和石头掠出画面，远山不能像人物一样整体等比放大。
