# Motion Prompt #096｜悬浮动画 · Floating animation

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 不同周期与初相避免三件物体像捆绑一起移动，营造轻盈而非机械节拍。
- 阴影把竖直位移解释为离地高度变化，而不只是图层随机摇摆。

## 实现思路

- 可用正弦时间函数直接绘制或CSS关键帧模拟；保留2.4/1.6 s公倍周期与相位。
- 阴影作为独立层同步计算，文字内容不要随浮动模糊；低动态偏好时固定在静态位置。

## 建议检查点

- 手机振幅8 px，徽章和标签6 px；4.8 s首尾状态一致。
- 手机升高时阴影缩小变淡，不能错误地加深扩大。
