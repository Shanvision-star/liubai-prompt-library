# Motion Prompt #055｜气泡卡片 · Popover

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 与Tooltip不同，面板内包含可点击操作，因此由点击打开、由确定按钮关闭。
- 右侧近距离位移不打断原页面位置关系；三角尖角强调这是按钮的局部扩展。

## 实现思路

- 可用HTML popover配定位逻辑，保留锚点关系；边缘空间不足时需另设翻转/避让规则。
- 真实UI处理焦点、点击外部关闭以及触发按钮的展开状态，Canvas示例未提供这些语义。

## 建议检查点

- 1.28 s面板到(156,62)，指向三角对准按钮。
- 3.5 s关闭完成，确定按钮可实际接收操作。
- 视口较窄时面板不裁掉操作按钮。
