# Motion Prompt #049｜模态对话框 · Modal dialog

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 背景压暗降低页面竞争；居中及轻微放大共同把确认事项设为当前焦点。
- 遮罩和窗口都由同一个a驱动，避免窗口已经可见而背景尚未退后的不同步。

## 实现思路

- 原例是Canvas 2D演示，不是可直接投入生产的对话框；网页宜用语义化dialog配合CSS透明度/缩放。
- 生产版需另外实现焦点进入、焦点限制、Escape关闭和关闭后焦点归还；这些不是该Canvas规格已有的功能。

## 建议检查点

- 1.32 s窗口应达到280×140、缩放1，遮罩最大不透明度0.42。
- 3.58 s关闭完成；背景内容不能被残留遮罩挡住。
- 移植为真实UI后检查键盘焦点不跑到被遮挡背景。
