# Motion Prompt #156｜悬停文字翻滚 · Text roll on hover

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 上下两份同词保持字形连续，橙色用于区别激活状态，而不是替换为无关文案。
- 0.035 s逐字错峰带出滚动方向，39 px裁切窗口隐藏运动中多余的一份。

## 实现思路

- DOM将每字置于固定宽度槽内，内含原字和橙色副本，以translateY实现；辅助技术仅读取一份标签。
- 快速移入移出需从当前进度反转，避免每次重置关键帧造成文字跳切。

## 建议检查点

- 每字移动40 px、持续0.36 s，邻字延迟0.035 s。
- 39 px盒外无字形露出，完整悬停后仅一行橙色文字。
- 离开后恢复原词及原颜色，链接点击区不随字母移动。
