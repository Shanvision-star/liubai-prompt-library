# Motion Prompt #076｜滚动固定 · Pinning

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 固定画布把纵向浏览转为步骤进度，使读者无需追踪不断移动的解释区域。
- 数字、照片和进度线同步，三种线索共同表达正在展示哪一步。

## 实现思路

- 真实页面可用sticky容器或ScrollTrigger固定；内部内容根据归一化滚动进度切换。
- 固定区间必须有真实滚动占位；退出后恢复文档流，避免覆盖后续白色分区。

## 建议检查点

- 固定从scroll=110到410 px，区间外正常滚动。
- 两次步骤切换分别围绕p=1/3和2/3，数字与照片不脱节。
- 进度完成后竖线填满124 px，解除固定无跳位。
