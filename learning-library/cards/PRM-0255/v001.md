# Motion Prompt #013｜液态动效 · Liquid motion

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：不同大小圆的延迟跟随构成拉伸尾巴，模糊加阈值使相邻圆看起来像液体相连。
- 分析：停留阶段保留小液滴运动，避免形体完全静止时丢失流动性。

## 实现思路

- 参考为 Canvas 2D 的离屏掩模处理；网页可用 SVG filter 的 blur 与 alpha 阈值近似，但需对照边缘是否过软。
- 所有圆的位置应由当前时间直接计算，避免每帧累加造成帧率变化时液体分裂时序漂移。

## 建议检查点

- 前导圆去程位移 300 px，跟随圆依次延迟 0.065 s，返程为 2.7–3.8 s。
- 相邻圆接近时应融合、分开时成为独立液滴；不是几个半透明圆简单叠加。
