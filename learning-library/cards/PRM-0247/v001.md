# Motion Prompt #005｜遮罩显现 · Mask reveal

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：上下文字从同一分隔线向相反方向展开，既建立层级，也把分隔线变为动作起点。
- 分析：遮罩而非透明度控制可见性，形成利落的几何切口。

## 实现思路

- Canvas 2D 用 clip 实现；网页可用两个 overflow:hidden 的容器配合 translateY。
- 分隔线、上标题和副标题分别计时，保证文字不会在未到裁剪区时露边。

## 建议检查点

- 检查标题在遮罩边界处硬裁切，整个过程中不存在额外淡入。
- 上标题起于 0.35 s，副标题起于 0.55 s；两段文字分别停留在分隔线两侧。
