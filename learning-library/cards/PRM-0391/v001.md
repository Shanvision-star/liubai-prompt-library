# Motion Prompt #149｜滚动隐藏页头 · Hide-on-scroll header

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 判定依据是最近滚动方向而非累计位置，用户回看内容时可迅速重新获得导航。
- 顶部34 px内强制显示避免在页面起始处误隐藏；阴影提示页头浮在内容之上。

## 实现思路

- 真实网页需比较当前和前次scrollY来确定方向，再切换translateY(0)/translateY(−36px)。
- 参考文字将隐藏/显示共同描述为36 px上移范围，移植时显示应回到0，不应再次向上移动；还需处理快速方向反转。

## 建议检查点

- 下滚隐藏、上滚显示，距顶部≤34 px时保持显示。
- 状态切换耗时0.3 s，隐藏位置为上移36 px。
- 滚动30 px时阴影alpha达到0.14，回到顶端渐退。
