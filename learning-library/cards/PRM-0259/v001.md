# Motion Prompt #017｜遮罩转场 · Mask transition

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：遮罩起点与场景物件重合，使转场像从物件内部生长，而不是独立覆盖画面的装饰。
- 分析：圆与星所需覆盖半径不同；星形的旋转维持方向变化和视觉张力。

## 实现思路

- Canvas 2D 可先绘当前场景，再 clip 后绘下一场景；网页可用 clip-path，SVG 可用 mask/clipPath。
- 结束半径必须覆盖最远角，尤其五角星的凹部也不能留下旧场景缝隙。

## 建议检查点

- 圆起于（112,104），星起于（427,104）；切换在各半周期 0.45–1.6 s 发生。
- 转场结束时旧场景全部被替换；白边跟随遮罩轮廓，不围住整个画布。
