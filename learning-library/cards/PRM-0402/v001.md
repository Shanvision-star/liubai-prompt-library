# Motion Prompt #160｜加载按钮 · Loading button

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 同一按钮在操作、等待、成功三个形态间连续转变，反馈留在操作发生的位置。
- 先收起文字再缩圆，成功后先画勾再展开文字，避免狭窄圆形中出现挤压标签。

## 实现思路

- 真实组件由请求状态驱动加载时长，不应在固定2.25 s就宣告成功；失败状态需另行设计。
- DOM可动画宽度、背景和SVG描边；加载期间防止重复提交并保留可访问的状态名称。

## 建议检查点

- 收缩220→36 px用0.3 s，标签在前1/3已淡出。
- 转圈每0.7 s一圈；成功宽150 px，勾左移26 px。
- 真实请求完成前不能显示成功，失败不误用绿色完成态。
