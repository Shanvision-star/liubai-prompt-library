# Motion Prompt #137｜推入转场 · Push transition

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 旧新画面共享同一位移，接缝就是连续空间的边界，不是覆盖式擦除。
- 返回时反转方向，强化前后步骤或往返浏览的空间记忆。

## 实现思路

- Canvas将两场景相邻绘制后统一平移；DOM可用两个绝对定位面板并同步transform。
- 切勿同时加入交叉淡化或缩放，否则会改变原例的无重叠推移机制。

## 建议检查点

- 切换期间两画面无间隙、无重叠，接缝线宽6。
- 每次1.15 s平移539 px，终点完整显示新场景。
- 返回方向与去程相反，不瞬移到另一侧。
