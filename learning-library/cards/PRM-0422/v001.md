# Motion Prompt #180｜过肩镜头 · Over-the-shoulder

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 左侧肩部作为前景遮挡框架，既保留对话者存在，又把注意力引向清晰的远侧人物。
- 微弱推进增加亲近感，但不改变越肩构图的基本关系。

## 实现思路

- Canvas可将近肩与远人物分层，仅对前景施加2.6 px模糊；3D则用相机景深并保持远人物焦点。
- 实拍或视频提示词应明确左侧虚焦肩部、对面清晰胸像；不要把OTS误写成从主体背后持续跟随。

## 建议检查点

- 前景后脑与肩膀位于左边缘，不能完全挡住另一人物。
- 前景模糊2.6 px而远侧人物保持清晰，焦点不来回拉动。
- 3.4 s推进仅0.35 m，随后保持至4.2 s。
