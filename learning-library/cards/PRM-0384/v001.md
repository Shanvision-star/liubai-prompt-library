# Motion Prompt #142｜玻璃碎裂 · Shatter

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 先裂后碎把冲击分成蓄势与释放，0.82 s才真正位移的停顿对力度很重要。
- 碎片来自原图裁切，破裂后仍能辨认旧画面；径向速度加重力构成飞散后下坠。

## 实现思路

- Canvas按固定碎片多边形裁切原场景并逐块变换；AE可预切图层，必须稳定保存随机参数。
- 高分辨率重绘时按同一比例缩放位置和速度，时间、角速度及各环延迟保持原值。

## 建议检查点

- 共52块碎片，撞击中心固定在(304,92)。
- 0.3–0.65 s只有裂纹扩展，0.82 s后才飞散。
- 外环按每环0.035 s延后，碎片0.55–1.0 s内淡出并显露下层场景。
