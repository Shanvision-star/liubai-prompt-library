# Motion Prompt #083｜光标跟随 · Cursor follower

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 按剩余距离比例逼近产生平滑拖尾，不是固定时间差复制光标坐标。
- 保留系统箭头使装饰与准确指针并存，避免牺牲操作定位。

## 实现思路

- 真实站点可用pointermove更新目标、逐帧插值跟随；高刷新率设备要做时间归一化，不能盲目每帧12%。
- 圆层设置pointer-events:none并在触屏或低动态模式禁用；Canvas示例路径不是实际用户输入。

## 建议检查点

- 在60 fps参考下每帧只走剩余距离12%，不会瞬移到指针。
- 箭头可见且点击不被装饰层截获。
