# Motion Prompt #100｜分割光 · Split lighting

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 光角从前侧移到正侧时，阴影边界逐步变直，帮助理解“分割”来自方向而非后期随意遮一半。
- 左右明暗差传达张力，外轮廓和正中分界比表面纹理更关键。

## 实现思路

- Canvas可按给定圆截面公式分割亮暗区域；三维或真实灯光应移动主光而不机械贴平面半遮罩。
- 照片/生成图任务可描述单侧光与面部中线分割；无五官示意不能替代复杂鼻梁与颧骨阴影。

## 建议检查点

- 角度90°时头部明暗边界位于x=270且为直线。
- 20°到90°过程中阴影逐渐扩大，而非瞬间替换半张脸。
