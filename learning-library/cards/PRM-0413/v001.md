# Motion Prompt #171｜移动延时 · Hyperlapse

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 前景透视推进与昼夜时间压缩叠加，构成Hyperlapse；仅让云变快仍只是固定机位延时。
- 阴影随太阳转向是时间变化的辅助证据，远山恒定则稳定空间参照。

## 实现思路

- 可在Canvas或3D中分别建立相机路径与太阳、云、人物时间轨；保持统一进度但各轨道使用各自量程。
- 真实摄影需规划移动采样与稳定；生成视频可描述街道推进和12小时压缩，但不保证精确22 m或建筑排列。

## 建议检查点

- 3.7 s运动段内相机推进22 m且时钟从06:00变到18:00。
- 建筑近大远小并从视野边缘经过；太阳移动时阴影同步改变方向。
- 云每80 m循环不产生明显断裂，终段交叉淡化而非突然复位。
