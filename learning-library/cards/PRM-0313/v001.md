# Motion Prompt #071｜徽标 · Badge

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 数字变化承担信息，局部缩放与波纹只用于吸引注意，不移动铃铛主体。
- 白色描边将小徽标从底图隔开，保证叠放时轮廓清楚。

## 实现思路

- 实际DOM徽标相对铃铛定位，计数状态与到达事件分离；多个快速事件可合并动画但不能丢计数。
- 清除未读应符合业务规则，打开通知列表不一定意味着所有条目已读，不能照抄演示的清零逻辑。

## 建议检查点

- 计数依次1、2、3，铃铛位置保持(482,27)。
- 每次波纹0.5 s消失且不会遮住数字。
- 真实未读状态与徽标一致，辅助技术能获知数量。
