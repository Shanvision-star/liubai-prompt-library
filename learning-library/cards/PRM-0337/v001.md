# Motion Prompt #095｜动态渐变 · Animated gradient

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 不同椭圆半径与初相让颜色重叠持续变化，避免四块颜色整齐同步转圈。
- 前景固定保留阅读稳定性；运动只发生在低频背景层。

## 实现思路

- 可用Canvas径向渐变或多个CSS渐变层进行位移；保留各自相位和半径，不把整个背景统一旋转。
- 背景随时间改变亮度，要逐相位检查白字和按钮对比度；复杂大面积模糊需关注重绘成本。

## 建议检查点

- 4.8 s首尾轨迹闭合，标题及按钮不随背景漂移。
- 检查四组椭圆半径和相位正确，任何时刻文字仍可读。
