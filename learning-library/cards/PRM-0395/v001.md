# Motion Prompt #153｜3D 倾斜 · 3D tilt on hover

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 朝向由光标坐标连续决定，不是固定的hover姿态；反光和反向阴影进一步表达表面朝向。
- 进入/离开用0.4 s渐进，防止指针跨过边界时卡片立即倾倒或弹平。

## 实现思路

- Canvas参考做透视绘制；DOM可用perspective、rotateX/rotateY与径向渐变，正确换算局部坐标。
- 0.32 rad是倾斜上限而非每帧增加值；触摸端和减少动态效果模式应提供静态替代。

## 建议检查点

- 光标归一化偏移在−1…1时转角不超约18°。
- 离开0.4 s后平整，反光消退且阴影回位。
- 光标所在侧向远处倾斜，不因坐标轴符号错误反向。
