# Motion Prompt #123｜弹跳 · Bounce

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 反弹衰减由速度比例决定，强调物理能量损耗，而不是等幅反复上下移动。
- 压扁幅度与碰撞速度挂钩，第一次重碰撞和后续轻碰撞因此具有不同力度。

## 实现思路

- Canvas可按重力和恢复系数计算各段轨迹；SVG/AE移植需保留实际碰撞时间，不能统一间隔打点。
- 将阴影尺寸与高度关联，将变形与碰撞关联，避免把两者都简单绑到整体缩放。

## 建议检查点

- 球从190 px高度开始，反弹速度逐次乘0.56，低于35 px/s停止。
- 碰撞附近0.045 s范围才出现压扁，空中不持续扁平。
- 1.95–2.25 s以backIn退出，不在弹跳未稳时突兀消失。
