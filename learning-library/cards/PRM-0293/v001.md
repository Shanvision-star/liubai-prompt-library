# Motion Prompt #051｜底部面板 · Bottom sheet

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 底部进入配合顶部把手，既说明面板层级，也暗示向下拖动可逆操作。
- 示例用固定时间模拟手势；真实交互应由拖动位移驱动，而不是始终按脚本播放。

## 实现思路

- 可用DOM固定底部面板加transform，手势层将pointer位移映射为展开比例；Canvas仅提供视觉参数。
- 需定义拖动阈值、取消手势回弹及键盘关闭路径；保留顶部圆角与上投阴影。

## 建议检查点

- 展开完成时顶部y=55，底部贴住191。
- 3.0–3.6 s面板与手指方向一致地向下，不穿过把手。
- 实际手势取消后能回到完整展开态，不留半透明遮罩。
