# Motion Prompt #182｜深焦镜头 · Deep focus

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 前后景一起清晰表现的是景深范围扩大，不是把焦点从一个物体移交到另一个。
- 同时出现的双组对焦框将“都清楚”显式可视化，辅助光圈读数解释。

## 实现思路

- Canvas演示用两层模糊参数插值；3D或实拍的深焦还受焦距、对焦距离、光圈及曝光影响，不能把像素模糊直接当物理光圈公式。
- 视频生成可以要求前后景同时清晰，但不保证f/16物理效果和逐时模糊量完全相符。

## 建议检查点

- 相机及所有对象位置不变，只有清晰度与标记透明度变化。
- 3.4 s前景5 px与背景6 px模糊都降至0。
- 不能出现一边变清晰、另一边反而变糊的拉焦效果。
