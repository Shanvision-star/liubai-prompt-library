# Motion Prompt #073｜视差滚动 · Parallax scrolling

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 前景快、远景慢的速度差提供深度线索，而不是简单地移动整张背景图。
- 内容保持正常滚速，保证阅读路径稳定；下一节覆盖背景也划清了首屏边界。

## 实现思路

- 参考为Canvas 2D分层位移；网页可用独立图层和滚动进度映射transform，保留各层0.15/0.4/0.7的比例。
- 应给慢速层足够的越界余量，避免滚动时露出空白；低动态偏好下可取消差速而保留内容。

## 建议检查点

- 滚动120 px时，天空/远山/近山的位移量分别为18/48/84 px，正文为120 px。
- 白色下一节覆盖背景，不与背景一起慢速漂移。
