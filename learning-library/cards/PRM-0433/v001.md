# Motion Prompt #191｜子弹时间 · Bullet time

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 主体时间与相机时间分离：人物近乎凝滞，但视点仍运动，这是子弹时间区别于普通慢动作和环绕的核心。
- 叶片同用慢速影像时钟，使环境细节也与人物同步慢下来，避免时间逻辑断裂。

## 实现思路

- Canvas/3D建立影像时钟和相机轨道两套驱动；影像时间分段连续，不在1.5 s或3.3 s发生突跳。
- 实拍需要多机位或重建等手段，生成视频只可要求近停顿与环绕，不能保证69°轨道与0.1×准确。

## 建议检查点

- 1.5–3.3 s主体只推进0.18 s影像时间，但相机完成-0.6至+0.6 rad环绕。
- 人物停留跳跃过程45–54%附近，九片叶子的运动同样减慢。
- 第二次4.7 s过程反向环绕，9.4 s起末相机方向与动作相接。
