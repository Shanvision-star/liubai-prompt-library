# Motion Prompt #030｜环绕镜头 · Orbit (Arc shot)

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：主体不动而视角改变，背景横移与脸部细节变化共同证明是在绕行，不是背景平移特效。
- 分析：半径固定、持续看向主体，使主体大小和位置较稳定，注意力集中在立体形态上。

## 实现思路

- 三维实现可用环绕相机轨迹和 lookAt；Canvas 2D 参考是这套关系的示意投影。
- 只有单张平面人像不能凭水平移动生成真实侧面；需要多视图、三维资产或生成补全，并明确这与精确参考实现不同。

## 建议检查点

- 相机与人物距离保持 6 m，人物稳定居中，视角从 −54° 到 +54°。
- 12 棵背景树随环绕产生正确的相对运动，脸上的白点也随视角变化。
