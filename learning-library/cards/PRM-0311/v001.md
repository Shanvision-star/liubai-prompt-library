# Motion Prompt #069｜骨架屏 · Skeleton screen

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 与实际内容等尺寸的占位减少布局跳动，比未知结构的转圈更能预示结果。
- 亮带裁切到骨架形状内，避免整页被大面积闪光打断。

## 实现思路

- DOM占位与最终组件共用布局，渐变背景位移动画仅在加载期间运行。
- 真实加载完成后再移除骨架；提供减少动态效果版本，并避免对读屏朗读每一个占位块。

## 建议检查点

- 骨架与原图/文字位置尺寸完全对应，恢复时不跳版。
- 亮带周期0.9 s、宽160，只在灰块范围可见。
- 数据已加载后骨架停止，不持续占用动画资源。
