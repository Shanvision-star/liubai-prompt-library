# Motion Prompt #097｜逆光 · Backlighting

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 主体正面变暗、外缘变亮与全局暖雾共同指示光源在后，不应只给背景加太阳。
- 图形是无五官的布光示意，以极简明暗关系解释逆光，不是摄影级皮肤和光学模拟。

## 实现思路

- Canvas可用人形描边再填充、背景日轮与暖色覆盖层复现；合成照片时须用主体蒙版区分背光边缘和正面。
- 生成图提示可描述后方光源、轮廓亮边、暗面和暖雾，但不能保证像素半径或相同光照物理。

## 建议检查点

- 效果到位时太阳位于(270,56)，人物正面比初始更暗。
- 外缘约3.5 px可见，而非整个人物均匀发光。
