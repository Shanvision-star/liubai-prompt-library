# Motion Prompt #147｜堆叠卡片 · Stacking cards

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- sticky停靠的12 px错位留下层叠边缘，暗示之前内容仍在下方。
- 下层围绕顶边中点缩小，避免卡片上缘漂移破坏整齐堆叠感。

## 实现思路

- 真实网页可用sticky叠层、transform-origin: top center与滚动驱动缩放；控制每层z-index。
- 卡片内容超过固定高度时需重新设计滚动空间，不能把371×124示例尺寸硬套给任意正文。

## 建议检查点

- 三张停靠顶部依次14、26、38 px，间隔保持12 px。
- 最底卡在两张覆盖后缩小9%，最深遮罩不超16%。
- 回滚正确解除堆叠，不让下层卡跳到前景。
