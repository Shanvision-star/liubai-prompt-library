# Motion Prompt #176｜穿越镜头 · Fly-through

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 窗口先作为构图框，再随靠近扩张并退出视野，让穿越产生明确的空间门槛。
- 停止绘制墙体的时刻被安排在窗缘已出画之后，以避免近裁切造成可见穿帮。

## 实现思路

- 3D相机路径需穿过真实开口，检查近裁剪面；Canvas参考的0.25 m停止绘制是示意实现策略。
- 若转为生成视频，强调一次连续穿窗、方向固定、墙后人物逐渐接近，不能保证精确距离或无几何错误。

## 建议检查点

- 摄像机高度1.3 m，路径穿过窗孔而非穿过实墙。
- 墙体停止绘制前，窗边已完全离开画面，无突然消失的可见边缘。
- 3.6 s前进至12.5 m，人物剩余距离2 m，随后保持至4.2 s。
