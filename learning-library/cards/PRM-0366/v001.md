# Motion Prompt #124｜随机抖动 · Wiggle

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 多频正弦叠加制造不规则观感，却仍是确定性的可循环运动。
- 铃舌反向摆动和两侧振动弧共同强化声音联想；不能将它误做成一次衰减抖动。

## 实现思路

- Canvas或AE表达式可直接计算多频叠加；CSS可使用预采样关键帧而非每帧随机数。
- 真实UI不宜无限强烈抖动；应另设减少动态效果版本，此为应用层适配而非原例参数。

## 建议检查点

- 4.7 s循环接点的位置、转角与起点一致。
- 整个循环无静止段，角度峰值保持约0.235 rad范围。
- 铃舌与主体反向，白弧持续闪烁但不改变铃铛支点。
