# Motion Prompt #172｜长镜头 · Long take

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 人物路径与摄像机横移、转向连续相接；镜头持续本身而非特殊转场构成效果。
- 底部单条时间带是解释性图形，帮助区分长镜头与动作被拆开的跳切。

## 实现思路

- 在Canvas/3D或剪辑时间线上维持单一连续镜头，按公式驱动位置与朝向，不在中途插入隐藏切换。
- 示例最后0.5 s的回环淡化只是展示复位；实际长镜头成片不必保留这段演示循环。

## 建议检查点

- 前4.2 s人物位置、步态与背景变化连续，无中途画面切点。
- 相机高度1.4 m，横移量总计1.4 m；yaw跟随而不是锁死不动。
- 底部时间条没有分段，NO CUT读数单调到4.2 s。
