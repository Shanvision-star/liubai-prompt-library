# Motion Prompt #021｜翻转 · Flip

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：最窄的侧面瞬间更换内容，让正反面替换有物理理由，而非生硬换字。
- 分析：透视高差、暗面、上浮与阴影共同提供厚度和立体感，即便参考本身是二维绘制。

## 实现思路

- Canvas 2D 参考使用竖条模拟透视；网页可改为 CSS perspective + rotateY + backface-visibility，并对照原时间曲线。
- 背面内容要有正确朝向，不能因整体旋转直接显示镜像文字。

## 建议检查点

- 内容仅在经过 90° 的窄边位置交换，最终 A/Q 均可正向阅读。
- 翻转在 0.45–1.5 s 完成，终点有轻微过冲后回正，而非旋转停在倾斜角度。
