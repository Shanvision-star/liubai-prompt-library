# Motion Prompt #042｜匹配剪辑 · Match cut

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：匹配的是切点瞬间的形状、位置和大小，而不是把球连续变形成太阳。
- 分析：环境突变与圆形连续并存，既跳转叙事空间，又让视线有稳定落点。

## 实现思路

- Canvas 2D 可在两个场景中使用统一屏幕坐标的圆；剪辑或合成时应在切点对齐主体的屏幕位置和尺寸。
- 保持 0 帧硬切；若用形变或交叉溶解会变成另一类转场。

## 建议检查点

- 2.3 s 前后圆均位于中心右 120 px、上 46 px，半径 17 px。
- 环境在切点立即改变，圆却无明显跳位；太阳随后在 2.4 s 内下沉 14 px。
