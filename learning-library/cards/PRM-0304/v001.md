# Motion Prompt #062｜范围滑块 · Range slider

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 蓝色轨道明确表示被选区间，手柄光环则指出此刻操作的是哪一端。
- 数值步长将连续位置转为可读离散价格，防止显示大量抖动小数。

## 实现思路

- 真实组件以pointer拖动和键盘增减共同更新双端值，轨道坐标映射到0–10000并按100取整。
- 必须限制低值≤高值，提供可访问名称和当前值；示例固定轨迹本身不包含完整输入校验。

## 建议检查点

- 收窄后范围为¥3,000–¥8,000，手柄不交叉。
- 拖动中手柄半径15、光环24，松开后回到13。
- 显示值按¥100变化，并与蓝色区间端点一致。
