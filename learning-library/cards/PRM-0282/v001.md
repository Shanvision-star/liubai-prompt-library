# Motion Prompt #040｜定格 · Freeze frame

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：暂停的是整段素材时间，因此人物与叶片同时停住，而界面标识仍可独立淡入。
- 分析：在跳跃最高点停顿，构图稳定且动作意味最清楚。

## 实现思路

- Canvas 2D 中将素材时间封装为分段函数，所有场景对象使用它，冻结标识则使用播放时间。
- 剪辑软件可插入持帧段；恢复时必须接续原来的下一帧，避免跳过 1.4 s 的动作内容。

## 建议检查点

- 1.6–3.0 s 内人物和九片叶子像素位置不变，仅冻结标记允许淡入淡出。
- 3.0 s 后从跳跃最高点继续，而不是突然落地；FREEZE 字样只在暂停区间出现。
