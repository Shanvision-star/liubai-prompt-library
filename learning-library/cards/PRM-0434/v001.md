# Motion Prompt #192｜蒙太奇 · Montage

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 日期跳跃与不同动作、景别组合共同表达时间压缩，不是同一动作的简单加速。
- 七镜头保持训练主题一致，靠空间和姿态变化建立累积感，避免只堆砌无关画面。

## 实现思路

- 剪辑按七个明确时槽组织素材，并让日期标签与各段同时切换；镜头之间用硬切而非统一套转场。
- 若用生成视频，优先每个镜头单独生成再剪辑，逐镜保持人物与服装连续，不能保证一次提示生成全部七段精确时长。

## 建议检查点

- 七段时长合计4.7 s，日期依次为1、3、7、12、20、28、30天。
- 七个动作/场景与源表一致，镜头位置、景别和焦距确有变化。
- 底部仅当前段着蓝；最后0.3 s为演示回环，不应被误认作第八个训练镜头。
