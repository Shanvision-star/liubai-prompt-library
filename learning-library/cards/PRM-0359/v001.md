# Motion Prompt #117｜青橙色调 · Teal and orange

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 冷环境与暖受光部的分工比整体套一个橙青滤镜更明确。
- 阴影人形与亮边用互补色拉开，使主体即便颜色有限仍有立体层次。

## 实现思路

- Canvas可直接替换不同角色的色值；实际影像可用阴影/高光分离调色并保护肤色。
- 此处是平涂色表而非通用LUT，迁移至照片需要按亮度和对象重新映射。

## 建议检查点

- 太阳及人物受光边为橙系，环境与阴影保持青绿系。
- 暗部不被过饱和青色吞没，主体轮廓仍清楚。
