# Motion Prompt #046｜突切 · Smash cut

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：画面尺度、姿态、倾斜、震动和音量表同时跳变，把反差集中在一个切点上。
- 分析：冲击来自两个状态的落差而不是额外花式转场，提前淡化会削弱突然性。

## 实现思路

- Canvas 2D 参考用视觉音量表表达声画反差，不等于源文件含实际音轨；真实成片需另配并校准音频。
- 保持 2.4 s 硬切，不为制造冲击而加入不必要的全屏闪光或过高音量；声音应按交付响度规范控制。

## 建议检查点

- 2.4 s 前后立即从宽静景转为 2.6 倍焦距紧景，音量表同时跳高。
- 激烈段包含 18 条放射线和所列小幅震动；不把视觉表当成已生成真实声音的证据。
