# Motion Prompt #162｜灯箱 · Lightbox

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 暗罩把注意力集中于图像，但缩回原位保留用户在画廊中的位置感。
- 操作控件延后至打开后半段出现，避免在图像高速变化时抢焦点。

## 实现思路

- 真实组件需要模态焦点管理、Escape关闭、键盘切图与滚动锁；Canvas动画本身并不提供这些行为。
- 缩略图与大图应保持对象一致；高清图未加载时用缩略图过渡，避免中途空白。

## 建议检查点

- 第3张放大到261×128，遮罩最大alpha0.82。
- 关闭0.35 s返回第三张原位，计数为3 / 4。
- 键盘可关闭并将焦点归还触发缩略图。
