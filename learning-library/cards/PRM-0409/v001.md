# Motion Prompt #167｜向下滚动提示 · Scroll-down cue

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 鼠标内点和两侧箭头重复同一向下方向，形成无需阅读长文字的操作暗示。
- 淡出后在顶部重现隐藏了回位动作，避免提示看起来上下来回摇摆。

## 实现思路

- SVG/CSS适合独立循环点与箭头；若提示可点击，需要提供实际跳转目标和可访问名称。
- 仅作为装饰时应从辅助技术隐藏重复图形；减少动态效果时用静态下箭头仍可传达方向。

## 建议检查点

- 每4.7 s三拍，圆点前70%下移14 px且45%–75%淡出。
- 两侧箭头相距中心40 px，同侧相差半拍。
- 回位不可见，不出现向上的误导运动。
