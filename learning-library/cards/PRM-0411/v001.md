# Motion Prompt #169｜垂直升降镜头 · Pedestal

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 这里改变的是摄像机高度而非俯仰角；地平线固定是辨别升降与仰拍的关键。
- 近处人物和远处塔楼提供深度参照，使视点升高产生的画面位移可读。

## 实现思路

- Canvas 2D参考通过投影展示升降；在3D引擎中应只改变相机高度，锁定旋转和焦距。
- 若转为视频生成提示词，强调垂直升高且不仰俯、不变焦；数值只作目标，不能承诺模型精确执行。

## 建议检查点

- 0.5–3.4 s高度由1.0 m变为3.2 m，焦距始终330 px。
- 地平线不随上升偏离中心，人物应向下而非向上移动。
- 3.4–4.2 s不继续升高，回环使用最后0.5 s交叉淡化。
