# Motion Prompt #189｜切出镜头 · Cutaway

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 切向观众反应能补充主讲者以外的信息，不等同于放大主镜头中的道具。
- 回到原场景可维持叙事主轴，插入段还可遮盖主镜头内部的时间删减。

## 实现思路

- 剪辑以0帧切换两个机位/主体，先保证视线与情境关系成立，再利用反应镜头遮盖删段。
- 源文“17 Insert shot”是本包局部序号17，对应全局#185，不是全局#017。

## 建议检查点

- 1.7–3.0 s显示五位观众，而非演讲者同场景物件的特写。
- 两次切换为直接硬切，无额外淡化帧。
- 回到A后叙事与动作连贯，不能用不相关反应误导时间或关系。
