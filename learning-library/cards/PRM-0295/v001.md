# Motion Prompt #053｜下拉选择框 · Dropdown (select)

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 选项高亮跟随光标，回填文本则在选中后出现，将浏览态与已选态分开。
- 占位文字先退、所选文字后进的短间隔专门避免叠字。

## 实现思路

- 优先评估原生select；自定义需完整combobox/listbox键盘操作和选择状态，动画仅负责列表位置与透明度。
- 将关闭列表和写入值作为同一次选择事件，生产版不应保留4 s左右的自动重置脚本。

## 建议检查点

- 2.45 s列表已关闭，字段显示名古屋而非仍显示占位文字。
- 逐帧看2.2–2.42 s，两种文字不重叠。
- 实际组件能用方向键选择、Enter确认和Escape退出。
