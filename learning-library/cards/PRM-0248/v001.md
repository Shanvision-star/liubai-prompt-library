# Motion Prompt #006｜打字机效果 · Typewriter

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：打字完成之后才启用蓝色按钮，说明了输入完成—可发送—已发送的状态关系。
- 分析：新字符轻微缩放与持续亮起的光标，让打字可见但不依赖整框闪动。

## 实现思路

- 参考是 Canvas 2D 的操作演示，不会真的发送消息；网页实现应将显示动画与真实提交逻辑分开。
- 用字符计数和局部字符时间驱动缩放；多语言文本应按可见字素切分，避免拆开组合字符。

## 建议检查点

- 九个字符以 0.24 s 的间隔出现，按钮在 2.58 s 才转为蓝色。
- 2.96–3.21 s 的按压先于文字退场完成；约 3.27 s 光标归位，不残留在旧文字末尾。
