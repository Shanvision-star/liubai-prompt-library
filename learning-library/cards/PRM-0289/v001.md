# Motion Prompt #047｜J 型剪辑 · J-cut

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：声音先建立下一场景的期待，画面随后到达；观众在视觉切换前已经获得听觉线索。
- 分析：双轨时间线把看不见的声画错位显式画出，是剪辑关系教学而非一种相机运动。

## 实现思路

- Canvas 2D 参考是声画时序示意，不证明存在可听音轨；实际剪辑应分离视频与音频轨，将 B 音频入点提前 0.72 s。
- 需检查音频交接是否有突变，并按内容决定短交叉淡化；画面仍保持硬切，不要误把视频也提前。

## 建议检查点

- 约 1.66–2.38 s 期间，画面标签为 A、声音标签为 B。
- B 音频入点比 B 画面入点早 0.72 s；如交付为视频，另外验证实际音轨而不只检查图示。
