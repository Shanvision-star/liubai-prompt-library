# Motion Prompt #074｜滚动淡入 · Fade-in on scroll

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 触发条件取决于元素进入视口而非全局时间，因此能跟随阅读进度。
- 同排卡片一起出现，避免额外错峰改变原例的信息分组。

## 实现思路

- 真实网页可用IntersectionObserver触发CSS opacity和translateY；不要把示例的预设滚动时刻写成固定播放时间。
- 需要明确一次播放还是离开后重播；本例是离开底部后重置，应与产品目标区分。

## 建议检查点

- 元素顶边越过143 px触发线后，0.7 s完成28 px上移与淡入。
- 三张卡片同步出现；重置发生在视野外，不在可见区域突然消失。
