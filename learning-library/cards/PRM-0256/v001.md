# Motion Prompt #014｜运动拖尾 · Motion trail

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：拖尾把过去的位置显式留下，观众无需看到完整一圈也能推断运动方向。
- 分析：大小、透明度、颜色同时区分新旧，且本体最后绘制，确保当前对象最清晰。

## 实现思路

- Canvas 2D 可以用同一轨迹函数在 a−i×0.105 处采样；无需实际保存逐帧历史。
- 这里的 a 匀速不等于沿八字路径的弧长速度恒定；移植时若改成按路径长度匀速，应标注为改编。

## 建议检查点

- 始终有 15 个历史副本，顺着八字路径排列而非沿瞬时速度拉直。
- 最旧副本最小最淡且在底层；本体轮廓不被拖尾覆盖。
