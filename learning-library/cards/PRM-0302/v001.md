# Motion Prompt #060｜分段控制器 · Segmented control

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 共用底座表达互斥选择，而非三个独立动作按钮。
- 图表高度与指示块同步变换，使时间范围切换和数据更新产生清晰对应。

## 实现思路

- 可用一组单选按钮或具备相应语义的分段控件，背景滑块与柱高共享进度。
- 真实数据切换需保持坐标轴单位和量纲清楚；原例只展示高度动画，不代表三组数据可直接比较。

## 建议检查点

- 选中块始终92×32，居于每段100 px范围内。
- 每次0.25 s切换期间，七根柱同步变化且第六根仍为蓝色。
- 视觉标签、数据范围和控件选中状态一致。
