# Motion Prompt #020｜穿越缩放 · Zoom through

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：前景孔洞与下个场景的尺度互相抵消，转场结束不产生突然跳变。
- 分析：指数缩放用相对倍率组织速度感；p 的分段曲线再提供冲入与刹停的节奏。

## 实现思路

- Canvas 2D 使用以孔洞中心为原点的嵌套变换和裁剪；在合成软件中可用锚点、预合成和孔洞蒙版。
- 更换字形时必须重新测量孔洞中心及覆盖倍率；不能假设所有字母 O 都有半径 24.5 的圆孔。

## 建议检查点

- 缩放锚点固定在 O 的孔心，孔内下一场景始终对齐。
- 1.65 s 结束时下一场景达到 1 倍，不在切换帧突然跳大或跳小。
