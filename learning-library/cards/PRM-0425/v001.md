# Motion Prompt #183｜定场镜头 · Establishing shot

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 宽景别和小人物先建立整体环境及尺度，缓慢推进不抢夺空间信息的阅读时间。
- 地点字幕晚于镜头启动出现，把视觉建立环境与文字确认位置分成两个节奏。

## 实现思路

- Canvas/3D保持广角与高机位，单独用字幕层做8 px上移与淡入；不应将场景推进误做成长焦变焦。
- 220 px与16mm是原演示的标注对应，不可脱离相机传感器与视口设置当成通用换算。

## 建议检查点

- 画面包含全镇环境与小人物尺度参照，而不是人物近景。
- 0.9 s开始字幕出现，1.3 s到位并继续保留。
- 相机由-5 m至-2.5 m，总推进2.5 m且不改变焦距。
