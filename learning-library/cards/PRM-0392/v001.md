# Motion Prompt #150｜滚动监听 · Scrollspy

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 40 px触发线提前于标题贴顶就切换目录，令高亮更接近正在读的章节。
- 背景、左条与字重提供多重状态信号，比仅更换颜色更容易定位。

## 实现思路

- DOM可用IntersectionObserver或标题位置计算，关键是匹配“最后一个越过40 px线”的规则。
- 目录链接仍需可键盘访问，当前项可设aria-current；不要把动画模拟的文字条当作真实导航。

## 建议检查点

- 标题越过40 px线才成为当前项，多项越过时取最后一个。
- 新旧项同步在0.25 s内交换状态，不出现两个永久高亮。
- 左侧150 px目录保持不动，右侧文章独立滚动。
