# Motion Prompt #088｜离站挽留弹窗 · Exit-intent popup

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 触发来自向上离开视口的意图信号，不是页面任意鼠标移动。
- 遮罩与轻微放大集中注意，但会中断用户，因此关闭出口必须明显。

## 实现思路

- 真实桌面网页可监听mouseleave与clientY，另设本次访问只触发一次等节制规则；移动端不能假装有同样离开意图信号。
- 弹窗须可键盘关闭、正确处理焦点，不阻碍用户退出或伪装浏览器警告。

## 建议检查点

- 只有越过顶部边缘才触发，左右或底部离开不误触发。
- 点击×后在规定区间完全关闭，不立即重复弹出。
