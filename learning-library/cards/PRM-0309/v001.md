# Motion Prompt #067｜巨型菜单 · Mega menu

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 宽幅面板以栏目分组降低长导航的搜索成本，右图作为视觉导向而非每项都配图。
- 关闭延迟给从触发项移入面板留出容错，避免鼠标跨越边缘时立刻消失。

## 实现思路

- DOM实现需把触发项和面板当作一个可保持打开的交互区域，支持focus/点击以兼容触屏和键盘。
- 页面窄屏时应改为合适的分层导航，不把三列130 px和右图硬压进窄视口。

## 建议检查点

- 从产品移入第二列链接时菜单不闪关，1.75–2.9 s正确高亮目标。
- 1.3 s面板到位，3.4 s完全退出。
- 键盘可打开并遍历链接，窄屏无水平溢出。
