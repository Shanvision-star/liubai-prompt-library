# Motion Prompt #061｜筛选标签 · Filter chips

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 多个标签可同时选中，区别于分段控件的单选。
- 示例用降低透明度保留列表位置，便于观察筛选影响；实际产品未必应把不匹配结果继续留在列表。

## 实现思路

- 用可切换按钮表达aria-pressed，多条件组合由真实筛选逻辑计算，勾号占位随宽度变化。
- 明确是否隐藏、禁用或仅淡化不匹配内容；若仍保留可点击内容，需避免0.12透明度造成不可读而仍可交互。

## 建议检查点

- 选中后标签宽度增加18 px，旁边标签不重叠。
- 两个条件能同时生效；取消其中一个不会误清另一个。
- 不匹配卡片示例透明度为0.12，而非直接从DOM消失。
