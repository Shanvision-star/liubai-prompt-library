# Motion Prompt #122｜跟随动作 · Follow-through

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 主体骤停而附件继续运动，表现惯性；若所有层同时停止，就失去跟随动作。
- 旗帜与尾巴采用不同阻尼和频率，尾部逐段延迟让柔软程度与主体区分开。

## 实现思路

- 保留Canvas的预计算查表方式可确保任意跳帧仍得到相同画面；不能依赖上一帧动态状态。
- AE/骨骼动画移植可按同一采样表建立附件关键帧，分别驱动旗杆、旗面和七段尾巴。

## 建议检查点

- 0.85 s主体立即停止，但旗和尾仍有衰减运动。
- 尾部每段的时间差为22/600 s，并按段号放大摆幅。
- 每次结束前0.3 s摆幅平稳归零；同一时间重复渲染一致。
