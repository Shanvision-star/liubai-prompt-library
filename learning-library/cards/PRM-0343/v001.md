# Motion Prompt #101｜伦勃朗光 · Rembrandt lighting

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 核心识别点是阴影侧独立的三角亮区，而非仅仅侧光或半脸亮。
- 约6 px暗带让亮三角与主受光面断开，保留该布光的辨识结构。

## 实现思路

- Canvas以头部明暗分区加三角形蒙版实现；真实摄影应观察鼻影与颊部亮区，示例图形只是简化关系。
- 合成时三角亮区应限制在面部内，不能变成漂浮在旁边的发光装饰。

## 建议检查点

- 三角约13×18 px且与左侧亮面之间有约6 px暗带。
- 灯位图与45°侧向、45°仰角读数一致。
