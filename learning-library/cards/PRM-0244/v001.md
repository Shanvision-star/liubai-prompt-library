# Motion Prompt #002｜交错动画 · Stagger

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：交错的是启动时间，不是各柱的动画时长，因此读者可同时读出统一节奏与各自高度。
- 分析：柱顶白点二次延迟构成跟随反馈；退场的间隔更短，使结束更紧凑。

## 实现思路

- Canvas 2D 参考可移植为 SVG rect 或 DOM 元素的 scaleY；必须将 transform-origin 设在底部。
- 用数据索引 i 计算启动偏移和退场偏移；不要用随机延迟，否则会失去从左向右的阅读顺序。

## 建议检查点

- 七根柱条依次每隔 0.12 s 启动，最终高度分别匹配 52、84、68、112、92、136、158。
- 各白点始终位于对应柱顶上方 16 px，且比柱条晚 0.34 s 入场、早于柱条退场。
