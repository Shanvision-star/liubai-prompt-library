# Motion Prompt #004｜线条描绘 · Line draw

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：先坐标轴、再曲线、再圈出峰值，让观众按结构—趋势—重点的顺序理解图表。
- 分析：消失从起点追向终点，而不是把绘制倒放，保持视觉方向的一致性。

## 实现思路

- Canvas 2D 参考需要按路径长度计算可见区间；SVG 可通过 stroke-dasharray 与 stroke-dashoffset 实现路径修剪。
- 前端圆点位置应按同一条曲线的长度采样；仅在控制点之间匀速直线插值会偏离实际曲线。

## 建议检查点

- 0.4–1.95 s 曲线前端有黄点跟随，圆点不脱离平滑路径。
- 圈注在 2.2 s 后才开始；擦除时起始端前进，终点并非倒退重画。
