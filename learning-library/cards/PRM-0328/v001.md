# Motion Prompt #086｜下划线动画 · Underline animation

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 入场向右生长、离场继续向右消失，形成一致的流向，而非原路倒退。
- 略宽于文字的命中区降低精细定位负担，视觉线仍严格对齐词宽。

## 实现思路

- 伪元素scaleX搭配进入/离开时不同transform-origin；位置不占正文布局高度。
- 为键盘焦点保留可见提示，不只依赖hover；原有超链接语义仍需保留。

## 建议检查点

- 进入从左长出，离开是左端追向右端，不误做向左收缩。
- 厚度3 px、基线下8 px，动画不引起文字位移。
