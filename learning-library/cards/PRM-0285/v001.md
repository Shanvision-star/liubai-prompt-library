# Motion Prompt #043｜甩镜头转场 · Whip pan

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：连续的同向快速运动掩盖场景替换，让两个地点在视觉惯性上相接。
- 分析：时间采样模糊来自运动轨迹，不等同于给画面套一层固定高斯模糊。

## 实现思路

- Canvas 2D 参考对同一时间邻域多次采样求平均；合成软件可用方向性运动模糊配合前后镜头偏航。
- 切点必须与最强模糊同步；生成视频若无法精确控制时间，需要先生成镜头再在剪辑中对齐。

## 建议检查点

- 1.7–2.1 s 甩出，2.1–2.5 s 甩入，切换发生在 2.1 s。
- 切点模糊最强，2.5 s 后画面稳定清晰；往返周期为 9.4 s。
