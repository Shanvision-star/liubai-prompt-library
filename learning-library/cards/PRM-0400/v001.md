# Motion Prompt #158｜浮动标签 · Floating label

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 上浮条件是聚焦或有值，因此输入后即使失焦也不会让标签盖住已有内容。
- 标签背后的白底断开边框，视觉上成为边框的一部分，而不是浮在边框上造成划线文字。

## 实现思路

- 真实DOM保留label与input关联，通过focus与非空状态控制样式，不能用placeholder替代标签语义。
- 输入法组合、自动填充与预填值都需触发正确的浮动状态；这些行为不由Canvas演示提供。

## 建议检查点

- 标签字号15→11.5 px，左间距14→10 px，耗时0.24 s。
- 有值但失焦时标签仍在上边框；仅空且失焦才回落。
- 标签白底遮住边框，文字不被边框穿过。
