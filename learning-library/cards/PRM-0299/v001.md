# Motion Prompt #057｜标签页 · Tabs

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 下划线连续移动保留导航位置感，不是各标签分别闪现标记。
- 下划线宽度也变化，以适应第三项更长的标签；内容淡出淡入将面板切换与导航运动分层。

## 实现思路

- DOM中用tablist/tab/tabpanel语义和独立指示条；根据标签实际布局计算位置与宽度。
- 原Canvas内容切换是定时示意；实际项目应以选中状态更新面板并处理方向键导航。

## 建议检查点

- 每次下划线运动持续0.25 s，第三项下划线宽100而非70。
- 3→1时下划线经过中间，而不是瞬移。
- 选中标签和可见面板一致，隐藏面板不应仍可获得焦点。
