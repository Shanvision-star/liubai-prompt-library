# Motion Prompt #130｜波浪文字 · Wave text

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 固定相位差让波沿文字传播，整体同时上下运动无法形成相同的流动感。
- 拉伸、变色与阴影都跟随单字高度，强调每个字母具有独立的跳跃体积。

## 实现思路

- Canvas逐字绘制或DOM逐字span均可；每字的索引必须稳定，空格处理不能改变后续相位。
- 纵向变形应围绕字母基线或统一锚点，避免视觉上文字在缩放时横向漂移。

## 建议检查点

- 4.7 s恰好三次波动，邻字相位差0.62 rad。
- 垂直幅度28 px；上升时色彩偏黄、阴影缩小。
- 字距4 px保持不变，不因单字拉伸而挤压排版。
