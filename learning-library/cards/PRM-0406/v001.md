# Motion Prompt #164｜倒计时 · Countdown timer

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 只动变化位减少视觉噪声，借位时多位同时更新让计时逻辑可理解。
- 这是演示循环而非真实倒计时；9.4 s硬切回起点不能直接用于真实截止时间。

## 实现思路

- 真实网页应由可信的实际截止时间减当前时间计算剩余值，而不是逐次setInterval减一以免后台节流累积误差。
- 数字格采用等宽排版和overflow裁切；到期、时区和负值归零是应用层需要补足的逻辑。

## 建议检查点

- 0.4 s起九次秒减，4.4 s正确从02:15:00借位到02:14:59。
- 仅变化格动画，0.32 s内完成，静止位不闪动。
- 演示在9.4 s硬切重置；真实版本不会虚假重启优惠倒计时。
