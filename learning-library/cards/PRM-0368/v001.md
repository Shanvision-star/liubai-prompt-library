# Motion Prompt #126｜运动路径 · Motion path

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 预先可见的路线给观看者一个预期，飞机沿切线转向则将运动与路线形状绑定。
- 参数匀速不是弧长匀速，环处减速是原例特征，不应擅自拉成全程同速。

## 实现思路

- Canvas按参数方程直接绘制；SVG motion path或AE路径移植时需核对切线朝向和参数速度。
- 若目标工具默认按弧长匀速，需要采样原θ时间轨迹而非仅复制路径形状。

## 建议检查点

- 4.7 s内完整经过中央翻环并从右侧离场。
- 机头始终与atan2给出的切线方向一致。
- 拖尾恰有24段，逐段向后变细变淡。
