# Motion Prompt #119｜漏光 · Light leak

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 多个不同宽度的叠层形成从浅黄内侧到红边的分级，而不是单一均匀色带。
- 中心放在画框外使漏光有来自边缘的理由，轻摆动增加偶然感。

## 实现思路

- Canvas可叠加透明椭圆；照片处理可用相似渐变漏光蒙版并限制到边缘。
- 不能把漏光宣称为真实相机故障记录；若覆盖主体脸部或重要文字需减弱或重新定位并记录变更。

## 建议检查点

- 四层水平半径最终250/170/95/45 px，颜色由内浅黄到外红。
- 中心始终在右缘外约30±6 px，不漂入画面中央。
