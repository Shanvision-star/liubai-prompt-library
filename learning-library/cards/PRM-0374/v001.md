# Motion Prompt #132｜可变字体动画 · Variable font animation

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 改变的是字形笔画重量而非整体缩放，因此词的情绪增强来自字体结构。
- 滑块把抽象字重映射为可观察数值，便于理解可变字体轴。

## 实现思路

- 参考依赖系统字体的字重支持；真实项目需确认字体有连续wght轴，否则可能离散跳档。
- DOM可动画font-variation-settings或font-weight；导出环境应锁定同一字体并检查字宽变化。

## 建议检查点

- 4.7 s两次完整100→900→100往返。
- 滑块位置与round(100 + 800v)同步，端点在112和427。
- 字重变化不被误实现为文字缩放，字体无明显缺档跳变。
