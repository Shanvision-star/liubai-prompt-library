# Motion Prompt #038｜速度渐变 · Speed ramp

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：速度渐变将观看时间重新分配给腾空关键动作，而不把整段都拖慢。
- 分析：右上角 ×0.3 是显示舍入值，内部目标仍为 0.25×。

## 实现思路

- Canvas 2D 参考需对播放速度积分得到素材时间，不能简单用当前速度乘整个时间，否则会造成位置跳跃。
- 剪辑软件可使用时间重映射曲线；真实视频低速部分的帧率和光流质量应单独验收。

## 建议检查点

- 速度于 1.2–1.9 s 从 2.4× 连续降至 0.25×，人物位置在变速边界不跳变。
- 起跳约 0.94 s、落地约 3.68 s，曲线蓝点与实际速度一致。
