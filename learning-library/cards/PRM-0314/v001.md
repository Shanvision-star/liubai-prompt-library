# Motion Prompt #072｜空状态 · Empty state

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 删除时先表现行离场，再由下行补位，帮助解释列表为何变空。
- 空状态同时提供解释和操作入口，不把无内容处理成无意义空白。

## 实现思路

- 真实网页依数据长度切换列表与空状态，删除需业务确认/撤销策略，不能为看演示真的删用户数据。
- 示例添加按钮一次恢复两行只是循环重置；产品应打开创建流程或显示实际新增项。

## 建议检查点

- 第一行删除后第二行上移58 px，不留空槽。
- 完全删除后空状态显示且有可用的添加入口。
- 真实添加/删除结果以数据为准，不按演示时间自行恢复内容。
