# Motion Prompt #163｜图片热点 · Hotspots

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 呼吸环提示可交互热点，但气泡由点击触发，用户能主动选择关注部位。
- 上下热点的气泡左右布局不同，说明注释位置应服务于图像可读性而非统一覆盖。

## 实现思路

- 真实网页以按钮覆盖在响应式图像上，用相对坐标保持热点与产品位置一致。
- 每个热点需有可访问名称和键盘操作；不要只用无语义的装饰圆点承载必要信息。

## 建议检查点

- 白点半径8、橙芯4，外环在1.57 s内从8扩至20并淡出。
- 点击下方热点后旧说明0.25 s内退场，只保留当前说明。
- 图片缩放后热点仍指向同一产品部位，气泡不遮断关键操作。
