# Motion Prompt #080｜荧光笔标记动画 · Highlighter animation

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 高亮只覆盖下半行且位于文字后方，使强调不以牺牲文字清晰度为代价。
- 笔划宽度取关键词实际宽度，避免变成与内容无关的装饰长条。

## 实现思路

- 可用关键词span的伪元素，transform-origin:left配scaleX；触发由IntersectionObserver或滚动时间线控制。
- 字体替换和换行后重新确认关键词框，不能照抄固定像素宽度覆盖邻词。

## 建议检查点

- 触发线为134 px，笔划0.8 s完成且方向始终从左到右。
- 黄色层在字形后，基线上下8/3 px的覆盖关系保留。
