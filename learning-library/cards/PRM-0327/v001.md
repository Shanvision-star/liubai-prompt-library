# Motion Prompt #085｜涟漪效果 · Ripple effect

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 反馈从实际点击点发源，让用户能确认点击确实发生在预期位置。
- 半径用最远角计算，即使偏边点击也能覆盖全按钮，不留未响应角落。

## 实现思路

- 用pointer坐标相对按钮边界确定波纹原点，独立层绘制圆并裁切。
- 重连点击需支持多个波纹或明确替换策略；波纹不应覆盖文字到无法阅读。

## 建议检查点

- 两次点击波纹中心分别位于左、右点击点，不总在按钮中心。
- 0.6 s能覆盖最远角，0.8 s透明度归零且不越过圆角。
