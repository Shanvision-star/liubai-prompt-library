# Motion Prompt #007｜数字递增 · Count-up

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：四次减速曲线将多数增量放在前段，末段减速有助于读出最终数字。
- 分析：右对齐和等宽数字稳定视觉位置，颜色切换则明确告诉观众计数已经完成。

## 实现思路

- Canvas 参考可移植到 DOM 的文本更新；使用 tabular-nums 或真正等宽数字，并把进度条与数字绑定到同一个 value。
- 动画目标应是业务提供的真实值；不能让视觉计数制造未经证实的营收或用户规模。

## 建议检查点

- 2.9 s 准确显示 2,480，无过冲到更大的整数；此时变黄并轻弹。
- 逐帧检查右边缘不因位数变化移动，进度条填充比例始终等于 value ÷ target。
