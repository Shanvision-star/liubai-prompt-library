# Motion Prompt #170｜横滚镜头 · Barrel roll

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 主体与环境同步转动，表明变化来自摄像机roll，而非人物旋转或环绕拍摄。
- 360°终点与起点同构，回环不需要一次反向旋转。

## 实现思路

- 2D移植可围绕画面中心旋转整层；3D移植只改变相机roll，避免误加yaw或轨道运动。
- 原演示允许四角露白；若成片要求满幅，需要裁切或扩边并明确这与参考不同，注意强旋转可能引起不适。

## 建议检查点

- 3.6 s累计旋转360°，不是180°或绕主体一周。
- 人物、建筑和地平线始终采用同一旋转角。
- 3.6–4.2 s恢复水平静止；循环衔接无可见跳转。
