# Motion Prompt #120｜双重曝光 · Double exposure

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 人形轮廓承担容器、风景承担内在叙事，两层不是简单全画面半透明相加。
- 太阳位于头部右上、山脊穿过颈部的构图安排，使内部景观主动适应人物轮廓。

## 实现思路

- Canvas可用人形clip或destination-in合成缩小风景；图像编辑可用主体蒙版约束第二曝光。
- 检查蒙版边缘和内部地标位置；真实照片要处理肤色与景观层的取舍，本例仅演示轮廓内替换。

## 建议检查点

- 轮廓外为纯白，内部风景不会泄漏到身体外。
- 内部风景缩放0.7倍，太阳在头部右上、山脊经过颈部。
