# Motion Prompt #178｜高角度镜头 · High angle

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 视点升高加俯拍减少人物在画面中的占比，同时露出更多地面关系。
- 与升降长镜头和垂直俯视相比，本例重点是停在斜俯拍构图而非持续升高或完全顶视。

## 实现思路

- 3D中单独设置高度与pitch两条轨道；Canvas演示可复用投影参数，不能只缩小人物图层。
- 源文“13 Bird's-eye view”使用本包局部序号13，实际全局为#181，不是全局#013。

## 建议检查点

- 2.2 s高度4.5 m、pitch为-0.5 rad，随后保持至4.2 s。
- 地平线离开顶部，人物缩小、向下，地面网格可见面积增加。
- 最终不是-90°俯视，也没有升至#031的9 m。
