# Motion Prompt #041｜跳切 · Jump cut

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：背景完全不变使位置和姿势跳跃更突出，观众会将变化理解为省略了中间时间。
- 分析：硬切本身不需要视觉转场，节奏来自五段短时长的排列。

## 实现思路

- Canvas 2D 参考可按 floor(u/0.94) 选择五个静态状态；剪辑时应锁定机位并直接剪掉中间段。
- 不要为人物位置添加补间，也不要给切点加溶解，否则会改变 jump cut 的跳跃性质。

## 建议检查点

- 每隔 0.94 s 立即切换人物状态，背景逐像素不变。
- 五个位置、两次举臂与时钟顺序准确；各镜头内部人物不移动。
