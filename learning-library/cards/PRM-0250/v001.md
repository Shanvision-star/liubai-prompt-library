# Motion Prompt #008｜动态排版 · Kinetic typography

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：效果不是给所有词套相同入场，而是让运动方向和物理质感解释词义。
- 分析：每词时长一致，但字符级交错不同，整体统一节拍与局部变化并存。

## 实现思路

- Canvas 2D 可逐字绘制；DOM/SVG 移植时将词拆成独立字符节点，并保存字符自然排版位置再叠加变换。
- 换成中文或其他语言时要重新评估词义和字数；保留运动结构，不必机械沿用英文排版宽度。

## 建议检查点

- 四段各为 1.175 s，结尾都有 0.2 s 的上移渐隐。
- Bounce 的接地压扁、Spin 的整圈旋转、Slam 的 3.4→1 冲击互相可辨，不退化为同一种弹出。
