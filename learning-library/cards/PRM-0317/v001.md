# Motion Prompt #075｜吸顶页头 · Sticky header

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 先流动、后吸顶保留公告与页头的原始顺序，不一开始就抢占顶部。
- 吸顶后逐渐增加阴影，用层次变化区分固定导航和下面流动内容。

## 实现思路

- 参考Canvas以位置公式演示；网页首选CSS sticky，阴影可由滚动状态驱动。
- 检查祖先overflow和层叠上下文是否破坏sticky，并为锚点定位预留34 px页头遮挡空间。

## 建议检查点

- 滚动22 px后页头y=0，此后不再向上离场。
- 公告条可正常滚走；正文在页头之下，阴影最大不透明度0.16。
