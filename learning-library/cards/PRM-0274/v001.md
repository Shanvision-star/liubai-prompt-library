# Motion Prompt #032｜滑动变焦 · Dolly zoom (Vertigo)

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：机位距离变化与焦距变化互相抵消主体尺度，却不抵消不同深度背景的尺度，制造异常空间压迫感。
- 分析：头脚辅助线提供明确检验：如果人物本身也明显放大，就没有做到这项组合动作。

## 实现思路

- 三维相机应同时更新 position 和 focal length，并保持 d/f 不变；参考 Canvas 2D 用多层深度投影示意。
- 生成模型可接受“后拉机位并同步变焦、保持主体大小”的语义提示，但不能保证精确 2.2×/2.4×，需要回看结果验证。

## 建议检查点

- d 从 3.2 到 8 m，f 从 132 到 330 px，头脚两条线间的人物高度保持不变。
- 建筑与远山明显放大，前方地面缩小；效果不能退化成整画面统一变焦。
