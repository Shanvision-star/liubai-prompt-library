# Motion Prompt #016｜视差 · Parallax

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：层间相对位移而非整体缩放提供深度线索，越近的物体越快掠过。
- 分析：底部近景剪影是高对比的深度锚点，远景颜色接近背景则强化空气感。

## 实现思路

- 参考是 Canvas 2D 分层绘制；网页可将分离的 SVG/图片层放入独立变换容器，用同一 pan 值乘不同系数。
- 原尺寸下最近层最大位移为 108×2.1 = 226.8 px；复现时需按实际图形形状检查裁边，不能仅凭“至少 200 px”的最低规则认定没有露边。

## 建议检查点

- 星星、月亮、山脊、前景的偏移比例顺序正确，近层位移显著大于远层。
- 在左右运动极值处检查所有图层，不能出现背景缺口或可见图层边缘。
