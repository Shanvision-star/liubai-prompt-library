# Motion Prompt #139｜立方体转场 · Cube transition

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 共同中心轴与匹配深度让两个面像同一实体，而不是两张卡片独立翻转。
- 明暗按转角变化强化朝向，即使只有平面图像也能读出立体转动。

## 实现思路

- 原参考用Canvas竖切片近似透视；网页可用CSS preserve-3d，但需校准250深度和820透视距离。
- AE/3D移植应保留两个面随角度相反变化的暗度，阴影宽度也应随投影更新。

## 建议检查点

- 0.45–1.6 s完成90°转动，面宽250、高146。
- 退场面变暗而入场面变亮，端点暗度对应55%。
- 两个面在共同边缘连续连接，阴影不保持固定宽度。
