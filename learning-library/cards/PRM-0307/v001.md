# Motion Prompt #065｜汉堡菜单 · Hamburger menu

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 三横线向关闭符号连续变形，使一个按钮同时承担进入和返回，减少图标跳变。
- 菜单裁切在页头下方，遮住收起过程而非让它穿过品牌区。

## 实现思路

- 网页用三条span或SVG路径配transform，菜单层单独裁切；按钮设置可访问名称与aria-expanded。
- 图标变形仅说明展开状态，实际菜单项需可键盘进入，关闭后焦点回到触发按钮。

## 建议检查点

- a=1时顶底线在同一中心呈±45°，中线完全透明。
- 1.3 s菜单顶部为44，收起时不穿过页头。
- 3.6 s恢复三横线，真实菜单隐藏时其链接不能获得焦点。
