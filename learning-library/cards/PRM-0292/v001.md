# Motion Prompt #050｜抽屉面板 · Drawer (Off-canvas)

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 进入与退出沿同一左边缘往返，保留面板来自何处的空间线索。
- 浅蓝选中条表达当前导航位置，与背景遮罩承担不同职责。

## 实现思路

- Canvas参考可移植为固定定位aside与translateX；遮罩单独绘制并和面板共用进度。
- 真实页面需明确遮罩点击是否关闭、面板是否为模态以及滚动锁定行为，不能只复制示意光标。

## 建议检查点

- a=0时面板x=−210，a=1时x=0；不应缩放成出现。
- 展开结束为1.38 s，外部点击后3.65 s回到左侧。
- 四行间距保持32 px，选中态不随滑动闪烁。
