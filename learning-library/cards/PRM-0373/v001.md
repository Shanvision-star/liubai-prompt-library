# Motion Prompt #131｜路径文字 · Text on a path

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 按弧长而非x坐标间隔排字，能在斜坡和波峰处保持视觉字距。
- 每周期恰好移动一份重复文本的长度，使内容替换与循环接缝相互对齐。

## 实现思路

- SVG textPath可用于基础排布，精确复现需控制文本推进距离并处理首尾重复。
- Canvas按采样弧长查表定位字符，再用切线转角绘制；直接按x等距放字会在曲线处变稀。

## 建议检查点

- 字母朝向随切线变化，弧长间隔保持一致。
- 4.7 s后画面文字排列与首帧一致。
- 深蓝辅助线始终在路径下6 px，黄色圆点与正文同向流动。
