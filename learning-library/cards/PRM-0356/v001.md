# Motion Prompt #114｜低调 · Low-key

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 主体亮边作为暗画面的视觉锚点，低调不等于整张图无差别压黑。
- 隐藏太阳让画面不再有与主体争夺注意力的第二高亮点。

## 实现思路

- Canvas按物体类型调暗并保留右侧亮缘；照片调色可结合局部蒙版，不能只降低全局曝光。
- 暗部仍要保留必要边界；实际输出应在目标屏幕上检查黑位是否糊成一团。

## 建议检查点

- 太阳和光环与天空融为一体，右侧亮缘仍可辨。
- 直方图示意峰中心0.14，画面焦点没有反被背景光点夺走。
