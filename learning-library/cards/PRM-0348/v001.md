# Motion Prompt #106｜移轴效果 · Tilt-shift

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 窄清晰带与远离焦带后递增的模糊制造浅景深缩微暗示，而不是只缩小画面。
- 去掉大前景人、保留小比例人物有助于保持模型尺度读法。

## 实现思路

- Canvas可按纵向带分层模糊；照片处理宜用渐变蒙版过渡，避免硬性横线切断景深。
- 移轴的真实光学涉及焦平面，这里仅为缩微视觉模拟；生成任务应说“移轴微缩观感”而非保证镜头结构。

## 建议检查点

- y=66–176保持清晰，上下最外带达到7 px模糊。
- 汽车和脚部y=172的小人落在焦带内，而不是同样被虚化。
