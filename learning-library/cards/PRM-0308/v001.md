# Motion Prompt #066｜面包屑导航 · Breadcrumbs

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 面包屑尾项随层级改变而出现/消失，强调结构路径而不是用户浏览历史。
- 链接蓝色与当前页黑色粗体把可跳转祖先和当前位置分开。

## 实现思路

- 实际网页用带标签的nav和有序层级链接；页面路由更新后同步更新面包屑及文档标题。
- 示例交叉淡化适合单页过渡，但应尊重真实导航与历史记录，不用动画代替链接行为。

## 建议检查点

- 到列表页后尾项网页设计消失，课程是当前项而非仍呈链接高亮。
- 返回详情后完整三级路径恢复。
- 读屏能区分当前页与祖先链接，分隔符不被重复朗读为内容。
