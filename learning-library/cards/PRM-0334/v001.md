# Motion Prompt #092｜页面转场 · Page transition

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 在完全遮挡时换页，把结构切换隐藏在遮板内，避免旧新页面短暂叠在一起。
- 进入与退出方向一致，形成横向扫过而不是门帘开合。

## 实现思路

- 路由切换须与遮板覆盖节点同步，下一页资源就绪后再揭开；Canvas地址栏变化只是演示。
- 保留浏览器后退、深链接、焦点迁移和低动态替代；网络慢时不能在遮板下无限等待。

## 建议检查点

- URL/页面只在1.3 s全遮挡时切换，1.4 s才开始揭开。
- 页头也被盖住；往返两次都从左进、向右出。
