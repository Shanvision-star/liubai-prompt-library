# Motion Prompt #144｜分屏 · Split screen

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 栏宽变化和栏内运动彼此独立，分屏是容器布局变化，不是让三个场景一起缩放。
- 先二分再三分逐步增加信息量，合回单屏则收束注意力。

## 实现思路

- Canvas按动态栏边界clip并将各场景居中；DOM可用grid或裁切容器，但要决定保留比例还是裁切。
- 不要在分栏变化时重置子场景时钟，否则城市窗户或风车会突然跳回开头。

## 建议检查点

- 0.95 s分隔线在269.5，1.9 s位于1/3与2/3。
- 三场景运动连续，城市窗户每周期8次、风车两圈。
- 4.4 s合回单栏，6 px白分隔线不残留。
