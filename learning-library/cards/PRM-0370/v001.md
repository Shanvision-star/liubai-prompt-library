# Motion Prompt #128｜定格动画风格 · Stop-motion style

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 低帧率保持和逐帧错位共同构成手工质感；单纯降帧但不改变姿态无法完整表达。
- 固定扰动保留可重复性，洋葱皮残像则让离散帧之间仍有可读的运动方向。

## 实现思路

- Canvas渲染时量化到38个离散帧并查固定扰动；输出视频仍可为30 fps，只是重复持有同一姿态。
- AE可采用posterizeTime式离散时间与预设随机种子；不要在每次绘制时产生新随机值。

## 建议检查点

- 4.7 s只有38个独立姿态，中间帧保持而非平滑插值。
- 重复渲染同一帧的抖动一致，范围不超给定值。
- 两个残影透明度为0.28、0.12，顶部底部胶片带均为26 px。
