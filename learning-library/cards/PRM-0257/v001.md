# Motion Prompt #015｜粒子效果 · Particles

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：粒子不是同一时刻爆开，而是错开发射，形成持续喷涌。
- 分析：固定随机种子保留自然分布，又使逐帧渲染和重复预览一致。

## 实现思路

- 参考在 Canvas 2D 按粒子年龄计算位置、旋转和透明度；可移植到 WebGL 粒子系统，但无需为 84 个粒子引入重型物理引擎。
- 将随机参数在初始化时固定，并由时间取模算年龄；不要在 draw 中重新随机。

## 建议检查点

- 84 个粒子的水平速度、竖直速度与重力符合给定范围，轨迹能看到上升后下落。
- 同一时间点重复渲染结果一致；粒子在最后 30% 寿命内淡出而非突然消失。
