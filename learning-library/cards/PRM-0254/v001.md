# Motion Prompt #012｜形状变形 · Shape morph

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：同索引轮廓点建立连续对应，视觉上是一块形体变化，而非两幅图交叉淡化。
- 分析：几何形变、颜色变化与微小膨胀分开控制，轮廓负责识别，颜色负责区分状态。

## 实现思路

- Canvas 2D 参考使用等数量点插值；SVG 移植需统一各路径的点数、方向和起点，防止轮廓扭转。
- 原文关于每段时长 1.175 s、0.62 s 起、结束前 0.04 s 与括注 0.58 s 存在算术口径差异；本译保留原值，精确复现时以对应参考实现核对，不擅自修正。

## 建议检查点

- 每个轮廓均有 240 个对应点，顺序为圆、方形、星形、心形并能闭环回圆。
- 过渡不应断裂或出现交叉折线；四个下方指示点正确标识当前图形。
