# Motion Prompt #019｜液态转场 · Liquid transition

本文是留白对上游示例规格的解读。未运行成片或验收动画效果。

## 设计取舍

- 分析：纯色液体先行、下个场景随后跟上，将一次切换分为遮挡与揭示两层。
- 分析：波形和圆头液滴共同塑造黏稠边缘；中途最强的波动让起止更稳定。

## 实现思路

- Canvas 2D 用离屏 alpha 掩模实现融合；可移植至 SVG 滤镜或合成软件的模糊加阈值遮罩。
- 为下一个场景使用相同液体轮廓体系，但保留第二层的延迟，不能直接给整画面叠一层半透明波浪。

## 建议检查点

- 第一层在 0.35 s 起、第二层在 0.7 s 起，后者最终覆盖全画面。
- 可以辨认七条宽 30–54 px 的圆头滴流，边缘过渡是融合的，而不是重叠圆形的接缝。
