# 教学拆解库

这里保存 AI 逐条阅读后撰写的教学笔记、共享方法与可复现的页面编排。**不是后台自动生成器，也不代表提示词效果已经通过测试。** 原作者公开事实、本库既有整理、这次分析推断与未执行的对照分别标明。

`editorial-notes.psv` 每条六列：编号、方法、本条重点、设计推理、单变量对照、迁移练习及参考思路。方法说明见 `methods.json`。同一方法可用于多个案例，但每条笔记必须解释该例的具体限制，不能由标签批量冒充深入阅读。

`cards/` 是只读教学版本。`manifest.json` 绑定素材编号、版本和原文/优化文的内容哈希；正文不匹配时不会附加旧教学卡。应用升级更新教学资源，不覆盖使用者的原文或保存版本。历史分析保留在素材自身文件内。

新素材默认没有教学拆解。由获得授权的分析者实际读正文并补笔记、证据和绑定后，才能显示为已整理。程序不调用付费模型，也不把空标题或统一评价当分析。

更新既有教学时使用新的 `--revision`，保留旧卡文件。运行方式见 `python tools/build_learning_cards.py --help`；源库未提供时仅绑定公开素材，指定 `--source-library` 可另外绑定经核对的本地版本。内容哈希使用UTF-8正文（保留换行、忽略BOM），与服务实际读取一致。

本次教学内容以公开素材中可分发的原创整理为依据；Prompt Motion不复制未知许可的站点原句或逐句译文。来源位置仍见各素材的“来源”。理论背景仅作为补充，不能冒充原作者设计意图或用户实测证据。
