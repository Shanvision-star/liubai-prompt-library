# 留白教学拆解

本公开教学版为 v002，覆盖本版全部 60 条素材。逐条解释沿用已保存的教学分析，本次重审练习、共享方法与导航；旧的全量目录与不在本版的教学卡不随包分发。

阅读顺序见 [学习路线](learning-route.md)。教学卡显示原文结构、分析理由、单变量对照、迁移练习和有上限的检查方法。分析不代表上游作者未公开的思考，效果均为 untested。

`manifest.json` 绑定素材编号、当前公开版本以及原文、优化文的内容哈希；只有正文匹配才附加教学。`checksums.json` 覆盖本目录全部分发文件。新增或个人修改的内容不会自动获得已整理教学。

`editorial-notes.psv` 保留本版逐条笔记；`methods.json` 只保留本版实际使用的方法。教学修订使用新版本文件，未改变任何提示词原文和保存版本。

留白提供阅读、整理与追溯。AI 执行需要使用者自己的工具、模型与额度；留白不提供或代付模型调用。
